## 2026-08-04（拾壹→拾贰 跨端对齐）· 架构/契约固化 + 客户端对接联调结论

### 1. 服务端范围与架构（§1–§5 全部落地）
- **§1 鉴权 Auth**：`routes/auth.js` + `core/auth.js` + `core/users.js`（注册/登录/刷新/me，JWT + 刷新 token，密码 argon2/bcrypt 哈希，账户隔离到 `user_id`）。
- **§2 同步 Sync**：`routes/sync.js` + `core/sync.js`（六数据块按 `user_id`+日期键 CRUD，本地优先 + last-write-wins 增量合并）。
- **§3 实时 Realtime**：`realtime/ws.js`（手写 RFC 6455 升级 / 帧解码，30s 心跳）+ `realtime/gateway.js`（事件网关：`auth / rooms / presence / chat / music / col`；公共房 `public / silent / sprint`；`presence` 仅同房间广播）。
- **§4 专栏 Columns**：`routes/columns.js` + `core/columns.js`（分区 + 文章 CRUD / 点赞 / 评论；发布经 WS 广播 `col:changed`）。
- **§5 媒体 Media**：`routes/media.js`（列表 / 上传白名单 / 取文件 / 删除；上传为 raw 二进制 + `X-Meta` 头；对象存储可接 COS / S3）。
- 数据根：`src/util/fsjson.js` + `src/util/http.js`；配置 `src/config.js`（端口默认 8787，演示账户 `demo` 在上传白名单）。

### 2. 权威契约（与桌面端对齐）
- REST 同端口同源、Bearer 鉴权；WebSocket 网关 `auth` 为连接后第一帧。
- 上行：`auth / rooms:list / room:join / room:leave / room:admin / presence / chat:msg / chat:history / music:list`。
- 下行：`auth:ok / auth:err / rooms:list / room:joined / room:error / presence / chat:msg / chat:history / music:meta / music:list / col:changed`。
- 客户端帧必须掩码（RFC 6455 §5.3）；服务端帧不带掩码 —— 与 `ws.js` 实现一致，已用 `smoke.js` 的掩码客户端双向验证。

### 3. 冒烟自检（`tools/smoke.js`）—— 46/46 全绿
- 覆盖：健康检查 → 注册 → 登录 → me → 六块同步（推 / 拉 / 合并）→ 单块读写 → 专栏 CRUD / 点赞 / 评论 → WebSocket 认证 / 房间 / 聊天 / 在场。
- 一处 harness 竞态已修复：`inbox` 缓冲 + `waiters` 配对（先尝试唤醒等待者，无人认领则入队），避免丢帧误判。

### 4. ⚠️ 客户端发现的传输层缺陷（跨端结论，协议不变）
- 桌面端实装 §3 时发现：**本环境 WinHTTP 的 WebSocket API（`WinHttpWebSocketCompleteUpgrade`）恒定返回 12152（`INVALID_SERVER_RESPONSE`）**；服务端回包合规、裸 TCP 握手正常、微软官方示例逐字复刻亦失败。
- 客户端遂将 `Realtime` 传输层改为**手写 RFC 6455 over Winsock + bcrypt**（零第三方依赖），与服务端 `ws.js` 口径一致。
- **对服务端的影响：无。** WS 握手 / 帧 / 掩码语义完全符合 RFC 6455，服务端无需改动；桌面端契约测试（`DesktopApp/tools/ws_contract_test.cpp`）已对运行中的本服务端跑通 7 项下行 + §4/§5 REST（全绿）。
- 备注：WebApp 旧 `Net`（`WebApp/assets/js/app.js`）用的是 legacy 后端协议（`hello / room_msg / res_list / res_wl`），**与本文档新协议不一致**；若 WebApp 也要接本服务端需另做协议迁移（不在服务端范围）。

### 5. 运行与自检命令
- 启动：`node server.js`（默认 127.0.0.1:8787）。
- 全量自检：`node tools/smoke.js`。
- 桌面端契约测试：`cd DesktopApp && source tools/msvcenv.sh && cl.exe /nologo /TP /std:c++20 /EHsc /utf-8 /I src /DWIN32_LEAN_AND_MEAN /DNOMINMAX /MD tools/ws_contract_test.cpp src/net/Http.cpp src/net/Realtime.cpp /link winhttp.lib ws2_32.lib bcrypt.lib /out:ws_contract_test.exe && ./ws_contract_test.exe`（需服务端先在 8787 运行）。
