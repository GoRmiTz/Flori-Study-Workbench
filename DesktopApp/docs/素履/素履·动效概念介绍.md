# 素履 · 自律时序（概念 7）· 结案说明

> 落点：芙洛理「复盘」真实界面。隐喻取自《易经》"素履之往，独行愿也"——以最朴素的步履丈量自律之路。
> 一句话：**一根克制的时间轴，把"每天投入了多少"如实刻成可见的刻度。**

## ⚠️ 状态：已冻结（仅保留 V1）

- **V1（Canvas2D 细线时间轴）为唯一保留版本**——克制、可读、零辉光，是用户认可的基线。
- V2（WebGL1 粒子森林）、V3（树形刻度条）、V4（程序化艺术树）、V5（水墨笔意）**经用户终审全部放弃**，原型文件已删除。
- 失败根因已沉淀进 `creative-motion-design` 技能（约束 ⑨ 图表本体+风格层、⑩ 形态优先于特效、⑪ 禁用软圆辉光作主特效）。
- 本概念不再推进，转做下一概念。

## 保留的 V1：动效概念介绍

### 1. 为什么是「素履」
概念 6「流光」被否决根因：**辉光等元素太过夸张**（FBO bloom 把发光推到失控）。素履的设计铁律是**物理上不可能发光**：零 bloom、零加性混合；用 **Canvas2D 细线几何**——线条与实心点天生无辉光，且 headless 鲁棒性最好。

### 2. 视觉语言（克制、现代、非大众化）
- 暗底炭黑 `#0e0f12`，细线、点阵、低饱和几何——接近"现代数据编辑设计"，而非 SaaS 蓝白圆角卡，也非年轮的"古老"。
- 唯一强调色：**克制暖琥珀 `#d8a657`**（今日 / 连续打卡），其余皆为板岩灰 / 近白。
- 三类真实维度用极少量彩色点区分：考公朱 `#c2705f`、考研碧 `#5b9b8f`、事业金 `#c9a24a`——仅作小点，不铺大面。

### 3. 数据映射（意义优先 · 落芙洛理真实场景）
| 芙洛理真实场景 | 可视化元素 |
|---|---|
| F-D1 专注时长 | 竖直刻度高度（归一 180 分钟） |
| F-D5 拖拽收集考点 | 刻度顶端实心点半径（越大收集越多） |
| 练考正确率 | 基线下方短横杠（达标青 / 薄弱暖红） |
| F-D7 连续打卡 | 基线下方琥珀描边段（覆盖连续活跃日） |
| 先公后研倒计时 | 右上角"距国考 N 天" |

### 4. 交互（全部由真实操作驱动 · 确定可控 · 非游戏 · 无 idle 浮动）
- **悬停某日**：该日刻度缓动提亮 + 竖直引导线 + 顶部考点点轻微抬起；右侧面板显示当日数据。离开即回落。
- **滚轮 / ←→ 键**：平移 28 天视窗（数据共 90 天，确定式钳制）。
- **点击「标记今日已复盘」/ 点击今日格 / 空格**：今日专注确定式 +42 分钟增长（缓动），连续打卡段延伸，触发一圈克制脉冲（细线扩张淡出，无辉光）；视窗滚回今日。
- 全程无自动演示、无 idle 浮动。

### 5. 诚实限制
headless 仅能验证"真的在渲染、零报错"，**观感需你在浏览器目视确认**（Chrome/Edge 直开本地文件最稳）。

### 6. 与既往概念的关系
- 承：**意义优先**（概念 5 复盘·生长的数据驱动内核），弃其"年轮/树"的古老视觉。
- 弃：**发光/bloom**（概念 6 流光之败）。
- 别于砚心/墨脉/叠笺：那些是知识库界面的"关系/层叠"动效；素履专攻**复盘时间轴**的"投入度量"，是另一条独立线索。
