## 概念 7 v1（2026-08-16 深夜）· 立项 + 首版原型【唯一保留版本】

### 设计决策
- **彻底放弃发光**：WebGL1 + FBO bloom 推成夸张辉光。改 **Canvas2D 细线几何**——物理上无法产生辉光，headless 鲁棒性最好。
- 仍守铁律：动效为主、非游戏、真实操作驱动、确定可控、落真实界面、非大众化。

### 视觉与元素
- 暗底炭黑 `#0e0f12`；唯一强调=克制暖琥珀 `#d8a657`（今日/连续打卡）；考公朱/考研碧/事业金仅作小点。
- 竖直刻度高=专注(F-D1)、顶端实心点径=收集考点(F-D5)、基线短横杠=练考正确率、基线琥珀描边段=连续打卡(F-D7)、右上角距国考倒计时。

### 交互（全真实操作驱动，无 idle 动画）
- 悬停：刻度缓动提亮 + 竖直引导线 + 考点点轻抬；右侧面板显当日数据。
- 滚轮 / ←→：平移 28 天视窗（共 90 天，钳制可控）。
- 标记今日（按钮/点击今日格/空格）：今日专注确定式 +42 缓动增长、连续段延伸、单圈克制脉冲（无辉光）、视窗滚回今日。

### 校验（已通过 · puppeteer-core + Chrome ANGLE/SwiftShader）
- 默认显示**最近 28 天**（今日在右端），面板 `2026-8/16 · 今日`；零 console/page 错误；距国考 `105` 天正确。
- 点击「标记今日已复盘」→ 专注 99→141 分钟（确定式 +42 缓动增长）。

## 概念 7 v2–v5 · 全部放弃（记录失败根因，不再推进）

| 版本 | 方向 | 用户否决原因 | 根因教训 |
|---|---|---|---|
| v2 | WebGL1 粒子森林（聚合度 c 离散→聚集） | "太散、像一盘散沙、信息量低" | 把数据载体(树/刻度)也打散成粒子，信息蒸发 |
| v3 | Canvas2D 树形刻度条 | "不像树、普通、无特效、无独特" | 梯形+5圆=棒棒糖，形态简陋 |
| v4 | 程序化艺术树 + 生物荧光晕/摇曳/花粉 | "圆球特效很烂、烂大街；不如第一版十分之一" | 叶冠/光晕/微粒全是软边径向圆=cliché |
| v5 | 水墨笔意（宣纸+干笔竖画） | "我放弃了，重新做下一个概念" | 用户在树/森林母题上已耗尽耐心，整体重开 |

**沉淀进 `creative-motion-design` 技能**：⑨ 图表本体+风格层分离；⑩ 形态优先于特效（先像真东西，再叠局部特效）；⑪ 禁用 `createRadialGradient` 软圆辉光作主特效（烂大街）。
