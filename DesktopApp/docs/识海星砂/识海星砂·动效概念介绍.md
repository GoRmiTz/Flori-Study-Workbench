## 一、方向来源
概念 11「气脉·流转」被否（点密度太低→大而空；硬长方形截断→排版丑）。概念 12 是对冲这两条死因的全新非时序方向——**高密度离散星点 + 全幅自然边界**。用户高度认可方向（"完完全全的创新，你做到了"）与三通道配色，并追加升级设想（已实现于 v2）。

> 经 v3→v5 在"卡片形态"上反复堆风格层均被否定，v6 已**整体回退到第二版（v2）**。以下描述均为 v2 现状。

## 二、母题与落点
- **母题**：考公 / 考研的**微观考点** = 漂浮在深空中的**密集星砂云**（每颗星 = 一个题型 / 微观知识点），按学科聚成 8 个**星团**（言语 / 数量 / 判断 / 资料 / 归纳 / 对策 / 公文 / 常识）。
- **落点**：芙洛理·**识海页**（mock 顶栏 tabs：知识库 / 练考 / 复盘 / 识海 + 头像；标题 + 顶部 KPI 条 + 左下颜色图例 + 右侧「图谱」面板）。

## 三、信息可视化（先于动效，图表本体）
**1. 三通道数据着色（用户提议，约束⑰ 数据着色豁免）**
- **色相 = 学科来源**：每学科一个协调色相族（青 / 靛 / 蓝 / 碧 / 琥珀 / 玫 / 紫 / 绿），非彩虹乱炖；
- **纯度（饱和度）= 难度**：高饱和 = 难，低饱和 = 易（`sat = 20 + 54·diff`）；
- **明暗（亮度）= 掌握度**：高亮 = 熟，低暗 = 未掌握（`lig = 15 + 62·m`）；
- 一眼读出"哪科、多难、熟没熟"，是概念 12 通过的关键加分项。

**2. 几何与拓扑**
- **星点大小** = 分值权重（1–5，几何大小区分，不靠撞色）；
- **星座细线**（团内最近邻 2 条预计算，极淡）= 知识关联；**沿连线可溯源同类题型**（用户认可的亮点）。

**3. 全局读数**
- 顶部 **KPI**：星点总数 / 已点亮 / 掌握率% / 平均掌握% / 最暗星团 / 图谱收藏；
- **悬停精确探针面板**：题型 / 来源 / 难度 / 掌握度；
- 左下**颜色图例**（色相 / 纯度 / 明暗释义，自解释信息维度）。

## 四、视觉红线落实
1. **高密度离散**：共 **368 颗星点 + 736 条星座连线**，密度充足，绝不"大而空"；
2. **自然边界 / 不截断**：背景为**全幅深底 + 中央微亮 + 暗角**（减法层次），**无硬矩形框**；
3. **配色克制、零撞色**：颜色用于**系统性编码信息**（合法多色），守协调色相族 + 零辉光；
4. **告别方块堆叠**：全为点 + 细线，无柱无块；
5. **零辉光**：仅普通 alpha 实心小圆 + 细描边 + 细线 + 极淡 twinkle（位置静止，非 idle 漂浮）。

## 五、动效语言（v2 现状 · 真实操作驱动 · 确定可控 · 非游戏 · 零辉光）
- **悬停**某星 → 高亮其星座连线 + 准星环 + 弹出精确探针面板（受控，非自跑）；
- **左键点击**某星 → **正常考点卡**从点击处**弹簧弹入**到屏幕中央（`scale(.5)→scale(1)` 带过冲，无飞出 / 旋转 / 漂浮）；卡正面 **三按钮**：`点亮` / `收入图谱` / `翻面` + 学科信息（学科名 / 子类型 / 难度条 / 掌握度）；背面 `rotateY` 翻面看真题（`backface-visibility:hidden`）；
- **点亮此星** → 掌握度 target 0→1 弹簧插值（由暗转亮），**同团邻星受控脉冲轻微吸引后归位**（阻尼收敛）；触发：点 `点亮` 按钮 或 双击卡面；
- **收入图谱** → **拖拽星卡**向右侧 / 点 `收入图谱` 按钮，生成一张 **mini 卡**入右侧「图谱」面板（横排叠卡、仅露边、最前张用学科色）；松手未入则卡片回弹归位。图谱**非强制常驻**，可 × 关闭、不 pinned；边缘 tab 仅在有收藏时重开；
- **右键**取消掌握；**滚轮**围绕光标缩放（有界）；**拖拽**平移；
- **自动演示**：循环聚焦不同星团（细环，普通 alpha），用户**任一交互即停**——演示动效，非 idle 漂浮。

## 八、诚实限制
