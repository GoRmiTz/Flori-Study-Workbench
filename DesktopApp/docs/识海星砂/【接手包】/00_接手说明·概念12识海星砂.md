## 0. 一句话
「识海·星砂」是芙洛理桌面端「识海页」的一个**动效概念原型**（单文件 HTML：Canvas2D 星海 + CSS 卡片）。当前唯一可信基线 = **v2**：正常考点卡 + 三按钮 + 弹簧弹入 + `rotateY` 翻面 + 拖入/按钮收图谱（非强制常驻）。

## 1. 这是什么 / 不是什么
- **是**：一个**可玩的视觉原型**——浏览器直接打开 `02_动效概念原型.html` 就能体验，用来和用户在「动态 / 审美」上对齐方向。
- **不是**：已落地进 C++ 客户端的功能。它仍停在 `docs/` 原型阶段，**未合并进 `App.cpp` / 任何视图 / 看板娘层**。红线要求不碰它们。

## 2. 当前状态（v6 回退后 = v2）
- 用户曾高度认可概念 12 的**方向**（"完完全全的创新，你做到了"）与**三通道配色**。
- 但 v3 → v5 在"卡片形态"上反复堆风格层（塔罗竖版封面 → 棱镜折射 → 四层独立变换架构），用户连续否定，最终判 v5「又搞砸了」，**命令回退到第二版（v2）**。
- 因此**当前唯一可信基线 = v2**，包含：
  - 星海 **368 星 / 736 连线**，全幅深底 + 暗角，无硬矩形框；
  - **三通道着色**保留（色相 = 学科来源 / 纯度 = 难度，高=难 / 明暗 = 掌握度，高=亮）；
  - 点星 → **正常考点卡**（320×240，非竖版塔罗）**弹簧弹入**（`scale(.5)→scale(1)` 带过冲，无飞出 / 旋转 / 漂浮）；
  - 卡正面 **三按钮**（点亮 / 收入图谱 / 翻面）+ 学科信息（学科名 / 子类型 / 难度条 / 掌握度）；背面 `rotateY` 翻面看真题；
  - 图谱 **非强制常驻**：拖入或点按钮收卡，可 × 关闭，不 pinned。

## 3. ⚠️ 已否决方向（请勿重做，重做必再被否）
这些是用户**明确否定过**的，做过且已回退：
- ❌ 塔罗竖版封面（270×466，无大字无按钮、像收集品）
- ❌ 抽卡稀有度光晕（易青 / 中蓝 / 难紫 / 极金，越难越亮）
- ❌ 棱镜折射层 / 八边 SVG 切角描边 / 太空漂浮 / 透视舞台 / 悬停视差偏转（"四层独立变换"架构）
- ❌ 图谱 pinned 强制常驻（点内部卡片会塌、用户嫌不自由）
- ❌ 去按钮纯交互（v3 想"全靠拖拽/键盘"，但用户后来在 v4/v5 实际回到了"要正常卡片 + 按钮"）

## 5. 设计红线（精炼，完整版见 `01_设计红线_精炼版.md`）
通用（对所有动效原型）：
1. 创新第一、非大众化（拒 SaaS 蓝白渐变圆角卡）；
2. 有意义 + 实用价值优先，不能为动效而动效；
3. 现代感、艺术现代化，弃用古老有机形态（年轮/树/生长）；
4. **零辉光、零 bloom**（最常被否的根因）；
5. **【最高优先级】信息可视化优先、实用性优先**——数据要直观可读，拒绝"好看但读不出数据"；
6. 真实操作驱动、确定可控、非游戏（拒问答/计分/抽测/输赢）；
7. 落真实界面（mock 真实 chrome / tabs）；
8. 高密度离散、告别方块堆叠；
9. 配色克制和谐（单主色 + 灰度层次），靠明度/大小/位置区分维度；
10. 放弃时间轴 / 时序母题；
11. 自然边界，勿硬长方形截断；
12. **数据着色豁免**：仅当颜色**系统性编码数据维度**时允许多色相（概念 12 三通道即此例），仍守零辉光。

## 6. 如何运行与校验
- **运行**：浏览器直接打开 `02_动效概念原型.html`（无需服务器 / 构建）。
- **语法校验**：抽取内联 `<script>` 跑 `node --check`（见开发日志）。
- **无头运行时校验**：Node 22 内置 `WebSocket` + 系统 Chrome 跑 CDP 探针（见 `03_开发日志.md` v6 节），断言：零报错、`stars 368 / edges 736`、开卡可见、翻面 class 切换无错、点亮未掌握星 `lit 139→140 (+1)`、收图谱 `collected 1`。
- **诚实限制**：headless 只能证"能渲染 / 零报错 / 数值对"，**判不了审美**——任何视觉 / 手感改动，必须请在真实浏览器由用户确认。
