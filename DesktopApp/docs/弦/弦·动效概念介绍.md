# 弦 · 时序（概念 8）

> 复盘界面里的一组时间之弦。静止轮廓即数据，拨动才产生振动。

## 1. 设计意义与落点
- 落点：芙洛理 **复盘** 真实界面（概念 7 素履 V1 的同一场景），不另造新界面。
- 数据映射：5 根水平弦 = 5 条真实复习通道。
  - **专注**（暖琥珀 #d8a657）：弦的起伏高度 = 当日专注分钟。
  - **考点**：弦上小竖记 = 当日收集考点数。
  - **练考**：弦的轮廓 = 当日正确率。
  - **打卡**：浅琥珀色连续段 = 连续打卡区间。
  - **时政**：弦上竖记 = 当日是否完成时政日练。
- 右上角保持「距国考 105 天」与连续打卡计数，和素履 V1 一致。

## 2. 动效语言（真实操作驱动）
- **悬停** → 轻拨光标处弦：一个受控振动波从接触点向左右传播，并引发邻弦微弱共鸣。
- **拖动** → 扫弦：连续拨动，像手指划过竖琴；波持续被注入，但始终受阻尼约束，不会失控。
- **单击** → 标记今日：强拨、确定式 `+42` 专注生长、连续打卡数 +1、今日节点放大并回弹。
- **滚轮** → 平移 28 天时间窗（可回看前 90 天）。
- 无 idle 空浮动、无随机奖励、无计分；所有运动来自用户真实输入，动能确定衰减至静止。

## 3. 与素履 V1 的关系
- 保留 V1 已验证的审美基因：暗底 #0e0f12、暖琥珀唯一强调色、细线、克制、零辉光。
- 补回用户之前说 V1「少了更突出动效」的缺口：弦的拨动/扫弦/共鸣让时间轴本身成为可演奏的界面。

## 4. 技术实现
- **Canvas2D 单文件原型**，无 WebGL，因此无 shader 编译/黑屏风险，headless 校验最稳。
- **真实动力学**：一维波动方程显式差分，CFL 参数 `C²=0.16 < 0.5`，速度阻尼 0.992，端点固定反射，邻弦耦合 3%。数值稳定、有界、必收敛。
- **数据即图表本体**：每根弦的静止轮廓直接编码数据（约束⑨：图表本体 + 风格层）；拨动波纹是风格层。
- **可靠性**：`window.__probe()` 暴露给 headless；全局 try/catch 包住帧循环，异常计 err。

## 5. 校验结果
- `node --check` 内联脚本：**SYNTAX_OK**。
- puppeteer-core + Chrome ANGLE/SwiftShader（1366×860，2.6s）：
  - 零 console / page error，fallback 未触发。
  - RAF 运行，字符串被画出（lit > 0）。
  - 今日默认专注 99；模拟单击后 → 141（确定式 +42），连续打卡 2 → 3。
- html-review 适用性：该门控是文档排版流水线（依赖 `--fs-body`/`--color-text` 等文档令牌），对交互式 Canvas 原型不适用；已自查结构完整 + 安全：无 `eval` / `innerHTML` 注入 / 外链脚本 / XSS。

## 6. 诚实限制
- headless 只能验证「能渲染、零报错、交互生效」，**无法判断拨弦动效的视觉美感**（波的传播速度、阻尼手感、共鸣强弱）。必须在真实浏览器（Chrome/Edge）里用鼠标悬停/拖动/点击体验。
- 若真实体验觉得「拨弦太轻」或「共鸣太重」或「弦太挤」，可调：弦间距、拨弦力度、阻尼系数、邻弦耦合。
