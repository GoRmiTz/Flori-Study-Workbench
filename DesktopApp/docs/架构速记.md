# 芙洛理 Flori 桌面端 · 架构速记

> 原生 Windows 桌面应用：**D3D11（纸基着色器）+ Direct2D/DirectWrite（矢量 UI）**，非 WebView、零第三方依赖。
> 本文档是「网页 WebApp → 原生桌面」移植工程的总架构说明，供后续模块开发、维护与新人接入参考。
> 配套每日记录见 `开发日志.md`；本文件只讲结构与约定。

## 1. 项目概览

| 项 | 说明 |
|---|---|
| 程序名 | `Flori.exe`（芙洛理 Flori） |
| 平台 | Windows x64（MSVC，/utf-8 /W3 /permissive-） |
| 渲染 | D3D11.1 设备 + DXGI 翻转链 + D2D1 设备上下文 + DirectWrite |
| 语言标准 | C++20 |
| 依赖 | 仅系统库：`d3d11 dxgi d2d1 dwrite d3dcompiler windowscodecs dwmapi shcore user32 ole32 shell32` |
| 构建 | CMake + Ninja（脚本化装配 MSVC，见 `tools/msvcenv.sh`） |
| 落盘 | `<exe>/archive/{checkin,focus,items}.json`（手写极简 JSON，UTF-8） |

### 设计语言（DOSSIER · 档案·图纸）
全站视觉母题来自 WebApp 的 `dossier.css`，在 `ui/Theme.h` 以 `Palette` 结构体 1:1 落地：
- **墨色 ink900/700/500/300/100** —— 文字与细线
- **纸基 paper/paperHi/paperLo/paperDeep** —— 背景分层
- **标记色 seal(朱砂,主)/brass(黄铜,标注)/jade(青,完成)/vermilion(朱,警示)**
- **形制 shape**：`kGridUnit=8` / `kEdge=4` 微圆角 / `kHair=1` 发丝线 / `kTopNav=52` 档案条 / `kMaxWidth=1080` 内容最大宽度
- 主题切换不是硬切，而是两套 `Palette` 逐通道 `MixPalette` 交叉淡入（0.55s，`InOutCubic`）。

## 3. 渲染管线（每帧 `App::Frame`）

同一块后台缓冲上，先 D3D11 画纸基、再 D2D 叠矢量 UI：

```
WM_PAINT/空闲 → Frame()
  1. 时间步长 dt（QPC 高精度计时，卡顿保护 ≤0.1s）
  2. 主题过渡：m_themeTween 进行中则 MixPalette(palFrom,palTo,t)
  3. m_canvas.BeginFrame(pal)        // 调色板必须在 Layout 前挂上（视图取色）
  4. 布局：顶栏 Layout → content = {0, barH, W, H} → m_router.Layout(content, canvas)
       （截图模式可 m_router.Current()->SetScroll(m_shotScroll) 钉死滚动）
  5. 更新：顶栏 Update → m_router.Update(dt, input) → 尘埃/光标
  6. 绘制：
       m_gfx.BeginFrame()            // 绑定 RTV，D3D 独占
       m_paper.Render(gfx, pal, pp)  // 全屏纸基着色器（纸纹/网格/暗角/颗粒/视差）
       m_gfx.BeginD2D()              // 切到 D2D 设备上下文
         m_canvas.BeginFrame(pal)
         m_dust.Paint()
         m_router.Paint(canvas)      // 当前视图（+ 转场期 outgoing 叠加）
         顶栏 Paint（全幅页浮于内容上方，常规页按 barH 位移+透明度）
         光标 Paint
       m_gfx.EndD2D()
       m_gfx.Present(vsync)
  7. m_input.NewFrame()              // 清 pressed/released/clicked/wheel/keyDown
  8. 截图模式：m_time >= m_shotAt → 存 PNG → PostQuitMessage(0)
```

### 坐标约定
- **DIP（逻辑像素）** 是 UI 布局唯一单位；`Graphics::Scale() = dpi/96`。
- 鼠标输入在 `HandleInput` 中除以 `Scale()` 转 DIP；命中测试用 DIP。
- 文字/矢量由 D2D 的 DPI 变换自动缩放，无需手算。

### 纸基着色器 `PaperShader`
- 运行时编译 `assets/shaders/paper.hlsl`；`F5` 热重载（`Reload` 重新编译，非致命）。
- `Params`：time / scroll / vignette / grain / parallax / reveal（加载屏显影用）。
- 经 `FrameCB` 常量缓冲传入分辨率、纸色、网格色、网格单元等。

## 4. 核心抽象

### 4.1 `App`（应用主体）
- 组合：`Window` + `Graphics` + `Canvas` + `PaperShader` + `Router` + `TopBar` + `DraftingCursor` + `DustField`。
- `Run()` 消息循环：`PeekMessageW` 排空后 `Frame()`；窗口关闭或 `WM_QUIT` 退出。
- `Initialize()`：接好窗口回调（`isBlockedPoint`/`onResize`/`onInput`/`onIdlePaint`）→ 建窗口 → 缓存 `g_hwnd`/`g_dpi` → `Graphics::Initialize` → `Resize` → `Canvas::Init` → `PaperShader::Initialize`（失败不致命）→ 调色板 → `BuildViews()`。
- `BuildViews()`：依次 `add(make_unique<XxxView>())`，**顺序即默认首页**（loader 最先→开屏在加载屏）。
- `HandleInput`：WM_MOUSEMOVE/DOWN/UP/LEAVE/WHEEL/KEYDOWN（`F5` 热重载、`F2`/`Ctrl+T` 切主题、`F11` 最大化、`Esc` 回首页）。
- 主题切换 `ToggleTheme()`：翻转 `m_dark`，起 `m_themeTween`，`Frame` 内逐帧 `MixPalette`。

### 4.2 `View`（视图基类）
```cpp
virtual const wchar_t* Id() const = 0;          // 路由 id，如 L"checkin"
virtual const wchar_t* Title() const;            // 顶栏标题
std::function<void(const std::wstring&)> navigate;
void Go(const std::wstring& id);                 // 内部触发路由跳转

virtual void OnEnter();      // 进入：重置滚动+入场计时（默认 Snap(0)）
virtual void OnLeave();      // 离开：收浮层/提交编辑器（默认空）
virtual void Layout(const D2D1_RECT_F& area, Canvas& cv);  // 设内容高
virtual void Update(float dt, const Input& in);
virtual void Paint(Canvas& cv);

virtual bool FullBleed() const;       // 封面/加载屏隐藏档案条
virtual bool OverInteractive() const; // 悬停可交互元素→改光标

float ScrollY() const;  MaxScroll() const;
void SetScroll(float v);              // 截图自检：瞬间定位（public）
```
- 滚动：`Smooth m_scroll{0,0.20}` 平滑；`Paint` 内 `PushClip(m_area)` + `PushTransform(Translation(0,-ScrollY()))` 实现视差滚动。
- 命中测试：文档坐标需 `shifted.mouseY = in.mouseY + ScrollY()`。
- 子类在 `Layout` 末尾调 `SetContentHeight(h)` 限制滚动范围。

### 4.3 `Widget`（控件基类）
- 成员：`bounds`（命中矩形）、`enabled`、`visible`、`onClick`(std::function)、`enterDelay`+`Tween enter`（交错入场）。
- `Update` 处理 `m_hover`(Smooth 0.22) / `m_press`(Smooth 0.34) / 涟漪（`PaintRipples`）；`onClick` 在「释放且 armed 在本控件内」时触发。
- `HitTest(x,y)` 矩形内判定；`Paint` 为纯虚。
- 派生：`Button`（直角硬边+悬停反色，可带 `tag` 编号签 / `primary` 朱砂底）、`ModuleCard`（首页模块入口卡）、`CountdownCard`（大号等宽倒计时）。

### 4.4 `Router`（路由 + 转场）
- `Add(view)` / `GoTo(id, immediate=false)` / `Layout/Update/Paint` 聚合当前视图。
- 转场：`kDuration=0.62s`，转场中点切页并调用 `outgoing->OnLeave()` + `current->OnEnter()`；旧页淡出上移、新页显影落位（场景级 `InOut` 缓动）。
- `immediate=true`（截图模式）：跳过转场直达，调 `current->OnLeave()` 后切换。
- `InputLocked()`：转场前半段（`m_t<0.55`）吞点击，防误触。
- 索引：`unordered_map<wstring,View*> m_index` 供 `GoTo` 查视图；`Current()/CurrentId()` 供顶栏与输入。

### 4.5 `Canvas`（DOSSIER 绘图原语）
视图层只管排版，画法全封装在 `Canvas`：
- 基本形：`FillRect` / `FillRoundRect` / `StrokeRect` / `Line` / `DashedLine` / `FillCircle` / `StrokeCircle`
- **母题**：`DoubleFrame`（双线框）/ `CornerTicks`（四角裁切标记）/ `PerforationH`（骑缝虚线）/ `NumberTag`（编号签）/ `SealStamp`（朱砂印，可旋转）/ `ProgressRing`（进度环）/ `PaperCard`（纸卡底+描边+底部重线）
- 文字：`Text` / `MeasureWidth` / `MeasureHeight`（按 `maxWidth` 算高，长文换行用）/ `CharsReveal`（逐字揭示，大标题入场）
- 变换：`PushClip`/`PopClip` / `PushOpacity`/`PopOpacity` / `PushTransform`/`PopTransform`（相对叠加）
- 资源缓存：画刷 `Brush`、文本格式 `Format`（按 `FontRole`×字号×字重×tabular 缓存）；字体候选在 `Theme.h::font` 中探测。

### 4.6 `Palette` / `Theme`
- `Theme.h`：`Hex(uint32)` / `WithAlpha` / `MixColor`；`LightPalette()`/`DarkPalette()` 全字段定义。
- 字体角色 `FontRole`：Serif（宋体候选）/ Sans（雅黑候选）/ Mono（等宽数字，倒计时专用）。
- `App::MixPalette` 遍历所有墨/纸/标记色逐通道插值，`dark` 标志在 `t>=0.5` 翻转。

## 5. 数据层

### 5.1 内容单一数据源 `Content`（Data.h/.cpp）
- 对应 WebApp `data.js`：改文案不动结构。
- `Content::Get()` 返回 `static const Content&`，在 `Data.cpp` 落地全部静态配置：
  - `milestones` / `modules`（首页六模块入口）/ `checklist`（默认打卡项）/ `disciplines`（执行纪律）/ `coverLines`（封面段落）
  - `roadmap`（专栏·总线路图：principles/fronts/months/decision）
  - `materials`（资料推荐：scheme/main/budget/categories/pitfalls）
- 视图只读 `Content::Get()`，不持有文案。

### 5.2 派生数据结构（Data.h）
- `CheckItem{ slot, title, standard, tag, minutes, done, id, link, folder }`：`Key()` 优先用 `id`（空白回退 `title`）作勾选/匹配键。
- `ChecklistBundle{ daily, sat, sun }`：`DefaultChecklist()` 播种（daily=静态清单，sat/sun 留空）；`ItemsForDate(bundle, date)` 按星期合并当日生效列表（周末并上 sat/sun）。
- `FocusSession{ date, start, end, min, tag }`：专注会话记录。
- `Date{ y,m,d }` + 工具：`DaysFromCivil`（天数序号）、`DateFromCivil`（逆运算，内联）、`Today()`、`FormatDate`、`WeekdayCN`、`DaysUntil`。

### 5.3 本地档案持久化 `CheckinStore`（Store.h/.cpp，单例）
手写极简 JSON，**无第三方库**：
- `LoadDay/SaveDay(dateKey, map<title,bool>)` → `<exe>/archive/checkin.json`（结构 `{ "YYYY-MM-DD": { "标题":0/1 } }`）。
- `LastNDays(n)` → 最近 n 天日期键（索引 0 = n-1 天前）。
- `LoadFocus()/AddFocus()` → `<exe>/archive/focus.json`。
- `LoadItems()/SaveItems(b)/ResetItems()` → `<exe>/archive/items.json`（结构 `{daily:[...],sat:[...],sun:[...]}`）；无文件/空文件回退 `DefaultChecklist()`。
- 解析器：递归下降，支持字符串转义与 `\u`；JSON 节点类型含 `Arr`（`parseArr`）以支持数组。

### 5.4 日期数学
- `DaysFromCivil(y,m,d)`（Howard Hinnant civil_days）↔ `DateFromCivil(z)`（内联逆运算）支撑任意日期换算。
- 星期：`(DaysFromCivil(y,m,d)+4)%7` → 0=周日 … 6=周六（`ItemsForDate` 据此并周末专项）。

## 7. 交互系统

### 7.1 输入链路
`Window` 回调 → `App::HandleInput`（原始消息转 DIP 输入快照 `Input`）→ `Frame` 内 `m_router.Update(dt, input)` → 视图 `Update` → `Widget::Update` 出 hover/press/ripple/click。

### 7.2 覆盖层（Overlay）
- `CheckinView` 内 `AlertOverlay{ mode(0警告/1成功), title, line1, line2, btnOk, btnLog, card }` 与 `TaskCardOverlay{ item, btnLink, btnClose, card }`。
- 共享 `ComputeOverlayRects`（居中纸卡+遮罩）与 `PaintOverlay`（双线框+标题+文案+按钮+涟漪）。
- 激活时 `Update` 阻断底层：清 `Input` 的 clicked/released/pressed/inWindow，仅处理覆盖层按钮。
- 测试钩子（仅截图自检）：`FLORI_TEST_FOCUS_ALERT=1` 强制弹专注警告；`FLORI_TEST_TASK_CARD=1` 强制弹任务卡。

### 7.3 Win32 EDIT 承载中文 IME
- 管理页需要中文输入，原生 D2D 文本不可编辑 → 用 `CreateWindowExW(L"EDIT", ...)` 承载 IME。
- `Hwnd.h` 暴露 `AppHwnd()`/`AppDpi()`（`App::Initialize` 缓存 `g_hwnd`/`g_dpi`）。
- `ManageView` 子类化 `EditProc`（`GWLP_WNDPROC`+`GWLP_USERDATA`）：`VK_RETURN`→Commit、`VK_ESCAPE`→Cancel、`WM_KILLFOCUS`→Commit；按 DPI 缩放定位与字体；`OnLeave()` 提交当前编辑防丢失。

## 8. 构建与自检

### 8.1 装配环境
```bash
cd "R:/WorkBuddy/Study Plan/DesktopApp"
source tools/msvcenv.sh        # 导出 INCLUDE/LIB/PATH + LJ_CMAKE/LJ_NINJA
"$LJ_CMAKE" --build build      # 增量构建（首次需 configure；GLOB 自动纳入新文件）
```
- 裸 `cmake`/`ninja` 不在 PATH，须用脚本导出的 `$LJ_CMAKE`/`$LJ_NINJA`。
- `CMakeLists.txt` 用 `GLOB_RECURSE ... CONFIGURE_DEPENDS` 自动纳入 `src/**`，新增 `*.cpp/*.h` 无需手改 CMake。
- 构建后 `POST_BUILD` 自动复制 `assets/` 到 `build/assets`。

### 8.2 截图自检（`--shot`）
```
Flori.exe --shot <png> [--route <id>] [--at <秒>] [--dark] [--scroll <px>]
```
- `--shot`：存 PNG 路径，进入截图模式（窗口 `SW_SHOWNOACTIVATE`、隐藏光标）。
- `--route`：直达该路由（immediate，跳过加载动画）。
- `--at`：达到该 `m_time` 秒后存盘并 `PostQuitMessage(0)`；退出码 0 = 成功。
- `--dark`：以深色 `DarkPalette` 启动。
- `--scroll`：`Layout` 后钉死滚动位置，长文档（专栏/资料推荐）分段验证。
- 自检块（如 `FLORI_TEST_*`）仅影响自检，生产构建无副作用。

### 8.3 日志
- `flori.log` 落 exe 旁（`LogInit`/`LogLine`）；记录启动、路由切换、主题切换、截图结果、帧数。

## 9. 新增视图步骤（约定）

1. **写视图**：`src/views/XxxView.h/.cpp`，继承 `View`，实现 `Id()`/`OnEnter`/`Layout`/`Update`/`Paint`；需要数据时扩展 `Data.h` 的 `Content` 或结构。
2. **注册**：在 `App::BuildViews` 用 `add(std::make_unique<XxxView>())` 注册（顺序=首页优先级）。
3. **导航入口**：首页 `modules` 或某视图 `Go(L"xxx")` 跳转。
4. **母题复用**：所有卡片/边框/印章走 `Canvas` 的 DOSSIER 原语，不要自绘矩形样式。
5. **动画**：控件级 `Smooth`/`Tween`+`ease::OutCubic`；场景级 `InOutCubic`（转场由 Router 统一处理）。
6. **持久化**：需要跨进程/跨重启保留的数据走 `CheckinStore`（手写 JSON），勿用内存态（除非纯展示）。
7. **自检**：写完立即 `--shot --route xxx`（亮/暗）确认渲染正常、退出码 0，并同步 `开发日志.md`。
