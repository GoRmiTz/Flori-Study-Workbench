## 三、动代码前必须知道的坑（影响一切任务）

> 详见 `协作与交接手册.md`「关键约定与坑」。最常踩的：

1. **ABI 陷阱（最致命）**：`main.cpp` 栈分配 `lj::App app;`，若改了影响 `sizeof(App)` 的头文件（如 `TopBar.h`、`App.h`、任何被 App 持有的成员头），**必须 `touch src/main.cpp` 强制重编**，否则增量构建不重编 main → 启动即段错误（exit 139）。只改 `.cpp` 或「不被 App 直接持有布局」的头（如 `Store.h`/`FocusTracker.h`/`RoomView.h` 这类仅被各自 .cpp include 的）则无此问题。
2. **EDIT/RichEdit 是 GDI 子窗口**：主窗口须 `WS_CLIPCHILDREN`（Present 的 bitblt 裁剪掉子窗口区，永不覆盖 EDIT 像素）；**禁止在呈现循环每帧 `RedrawWindow(EDIT)`**（与 DWM 合成赛跑 → 频闪）。EDIT 仅由系统事件驱动自绘。
3. **swap chain 必须 `DXGI_SWAP_EFFECT_SEQUENTIAL`**（blit 模型）；FLIP 模式不合成 GDI 子窗口 → 输入控件不可见 + 光标消失。
4. **D2D target bitmap 必须带 `D2D1_BITMAP_OPTIONS_CANNOT_DRAW`**（即 `TARGET | CANNOT_DRAW`）；去掉它会让 `CreateBitmapFromDxgiSurface` 报 `E_INVALIDARG` → 启动 "Render device init failed"。**黑屏不能靠去 CANNOT_DRAW 修**。
5. **转场**：只用 `PushTransform` 位移 + 页面始终不透明绘制；**禁整页 `PushLayer` 透明度、禁离屏位图**（`m_bufA/m_bufB`）——前者黑/白/纯色，后者本机帧循环崩溃。启动有 loader→home 自动转场，转场代码崩会表现为「打不开」。
6. **`WM_SETCURSOR`**：用 `IsChild(m_hwnd, hw)` 统一放行所有子窗口（EDIT / RichEdit(RICHEDIT50W) 等），交由其 `DefWindowProc` 决定光标；主窗口仅「纯客户区」`SetCursor(nullptr)` 让自绘光标接管。
7. **网络传输层**：§3 实时 WS **手写 RFC6455 over Winsock + bcrypt**（弃用 WinHTTP WS —— 本环境 `WinHttpWebSocketCompleteUpgrade` 恒定 12152）；REST 用 WinHTTP。系统库白名单见 `CMakeLists.txt`，**禁止引入第三方依赖**。
8. **线程模型**：UI 线程不碰网络 IO；后台线程只写受锁源 + 置 atomic dirty 标记，`Update` 消费快照、`Paint` 只读。
9. **中文输入**：隐藏 EDIT 代理承载，IME 组合串自绘 + `HideCaret` 压原生光标；`EM_SETSEL(len,len)` 置文末防抖动。
10. **自动更新有三道闸，别绕过**（S0-1）：① `ParseUrl` 拒绝明文 http 远程下载（仅回环放行）；② 下载后在内存比对 `/version` 下发的 `sha256` 才落盘；③ 替换前重读磁盘二次校验。**服务端必须回带 sha256**，否则客户端一律拒绝更新——发布新版走 `Server/src/core/release.js`（自动算哈希，无配置时优雅退化为「当前版本即最新」）。
11. **口令哈希是 PBKDF2-HMAC-SHA256**（S0-2）：格式 `pbkdf2$<迭代数>$<盐hex>$<派生hex>`，60 万次迭代 / 16B 随机盐 / 32B 派生（实测 116ms，仅登录路径）。迭代数写在串里，老记录照旧能验。**旧 FNV-1a 16 位哈希登录成功时自动升级**，不要手改 `accounts.json`。比较用定时安全比较，别改成 `==`。
12. **演示口令不写进任何文档/源码**（S0-3）：只在 `Server/src/config.js` 的 `DEMO_PASS`，且支持 `FLORI_DEMO_PASS` 环境变量覆盖。对外分发前务必用环境变量换强口令。

## 四、自检与验收（每个任务做完都要跑）

- **客户端 17 路由无头自检**（全 `exit=0`）：
  ```bash
  source tools/msvcenv.sh && cmake --build build --target Flori
  for r in loader cover home checkin room dash roadmap materials media video \
           profile manage advisor achieve plan friend login; do
    ./build/Flori.exe --shot "build/shots/ci/$r.png" --route $r --at 1.5 || echo "FAIL $r"
  done
  ```
  - 路由名以各 `View::Id()` 为准（`grep "Id() const" src/views/*.h`）。**曾经这里写过 `arch`/`settings` 两个并不存在的路由、且漏了 `cover`/`friend`，照抄必失败**。
  - `--at 1.5` 是必须的：转场 0.62s + 元素入场动画，`--at 0` 截到的是空帧，两个完全不同的页面差异也只有 0.5%，等于没测。
  - `--shot` 后可跟输出路径（不跟则写死 `shot.png`，17 张会互相覆盖）。
  - 弹层/浮层加 `--preview`（强制打开视图预览/编辑浮层）、`--popup`（强制账户弹层）、`--scroll` 翻看。
- **视觉基线比对**（S2-3，防「没崩但布局塌了」）：
  `powershell -ExecutionPolicy Bypass -File tools\shotdiff.ps1 -Mode check`
  - 首次或有意改版后用 `-Mode baseline` 固化。基线**不入库**（各机 DPI/字体渲染不同，跨机必全红），已在 `.gitignore` 忽略。
  - 实测同一路由连截两次差异 0.000%（完全确定性），跨页差异 56%，阈值 0.5% 既不误报也拦得住真回归。
- **服务端冒烟**：`node tools/smoke.js`（51 项全绿）。
- **契约回归**：`ws_contract_test.exe` 对运行中的 Server 跑通 7 下行 + §4/§5 REST（全绿）。
- **一条龙**：`tools\ci.bat`（构建 → Server → smoke → 契约 → 截图自检 + 基线比对，5 步）。无桌面 GUI 会话时第 5 步自动跳过、不计失败。
- **提交信息**：沿用「模块: 短描述」中文风格（如 `RoomView: 白名单弹层增删`），涉及 ABI 头改动在描述里点明 `touch src/main.cpp`。
