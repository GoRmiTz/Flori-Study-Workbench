## 2. 自动更新机制（Updater）

```
启动 App
  └─ ApplyStartupPending()        若 updates/pending.json 存在且非开发路径
        └─ SwapAndRelaunch()      改名旧 exe→.prev，staging→exe，重启新进程，退出旧进程
后台 CheckAsync()                 拉 Server /version，比对 kAppVersion
  ├─ 无新版本 → 记录日志，结束
  └─ 有新版本 → 气泡提示 + 后台 DownloadAsync()
                    └─ 下载到 updates/Flori.next.exe + 写 pending.json
托盘「检查更新」→ CheckNow()（手动再查一次）
托盘「重启并更新」→ ApplyNow()（立即交换并重启）
```

### 关键安全性设计
- **UI 线程不碰网络**：所有 HTTP（/version、下载）均经 `Cloud::RunAsync` 后台线程。
- **只替换不删除**：交换时先把运行中 exe 改名为 `.prev`（Windows 允许重命名在跑的 exe，只是不能删），再把 staging 移入正式名；任一环节失败即回滚。
- **重启应用而非运行中替换**：交换在当前进程内完成，随后 `ShellExecuteW` 启动新 exe 并 `ExitProcess(0)`，避免运行中改写自身导致崩溃。
- **开发/截图路径保护**：`IsDevPath()` 命中 `DesktopApp\build`、`DesktopApp\out`、`.git` 时**不**自动替换、不下载应用，避免误伤本地构建与 `--shot` 自检。
- **防死循环**：启动交换失败时删除 `pending.json`，继续正常启动，不反复尝试。

### 版本与下载地址
- 本地版本常量：`Updater.h` 的 `kAppVersion`（当前 `"1.0.0"`），发版时与 `Server /version` 对齐修改。
- 下载地址由 `/version` 下发：`downloadUrl` 可为**同服路径**（如 `/releases/Flori-1.0.1.exe`，走 `Cloud::EndpointCfg`）或**完整 https URL**（Updater 解析 host/port/path）。
- 当前 `downloadUrl` 留空，表示暂未发布；填入真实地址即生效。

## 3. 安装器

- **InnoSetup**（`studyplan.iss`）：安装到 `Program Files\芙洛理 Flori`，管理员权限，现代向导，桌面快捷方式任务，支持中/英。产物 `out/installer/Flori-Setup-<版本>.exe`。
- **NSIS**（`studyplan.nsi`）：等价实现，给无 InnoSetup 的环境兜底；MUI2、写注册表卸载项、生成 `uninstall.exe`。
- 两者均只分发 `build/Flori.exe`（Release 构建），用户数据首次运行生成于 `%LOCALAPPDATA%\Flori`，不随包装、不随卸载强删（注释内提供清理开关）。

## 4. Microsoft Store 打包脚手架

- `Store/appxmanifest.xml`：标准 MSIX 清单模板，引用 `assets/` 图标与闪屏，声明 `runFullTrust`（Win32 桌面桥）+ `internetClient`。占位符 `{Publisher}/{PublisherDisplay}/{IdentityName}/{Version}` 待合作伙伴中心填写。
- `Store/README.md`：三种打包方式（VS 打包项目 / makeappx / msix CLI）、资源清单、与自动更新的关系、上线前收尾清单。

## 5. 验证

- 14 路由 `--shot` 自检全部 `exit=0`（自动更新路径在截图模式下被 `IsDevPath()` + `!m_shotMode` 双重跳过，不影响自检）。
- `Server/node tools/smoke.js` 端到端冒烟应仍全绿（`/version` 为新增无鉴权端点，不影响既有路由）。
- 真机验收（需在已安装/分发环境，非 `build` 目录）：启动 → 托盘出现「检查更新」「重启并更新」→ 修改 `Server /version` 的 `version` 高于 `kAppVersion` 并填 `downloadUrl` → 重启客户端应收到气泡提示并后台下载 → 点「重启并更新」应静默替换并重启到新版本。
