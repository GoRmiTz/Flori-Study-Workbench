## 实现要点

1. **数据**：26 个考点，分 7 章（言语/判断/数量/资料/申论/常识/专业·数媒），含分值权重、初始掌握度、关联边（章内强、跨章弱）。
2. **布局**：LCG 固定种子 → 章节环形中心 + 黄金角螺旋撒点 → 140 次力导向（斥力 K_REP=1400 / 边弹簧 K_SPR=0.03 L0=58 / 章节引力 K_GRAV=0.012）收敛为 home 坐标。
3. **物理**：每帧弹簧回 home（K_HOME=0.06, DAMP=0.84）；掌握事件给邻居一次性受控冲量（2.4×strength，方向指向被掌握节点），自然沉降收敛。
4. **编码**：节点半径=分值；填充色=墨青明暗（DIM[47,90,87]→BRIGHT[110,224,196] 按 dm 插值）；边宽=0.6+strength×1.8；背景深炭 + 径向减法渐晕。
5. **交互**：mousemove 悬停高亮+面板；左键掌握 / 右键取消；拖节点（弹性回位）/ 拖空白平移 / 滚轮缩放（围绕光标，钳 [0.45,3.2]）；自动演示循环高亮。
6. **KPI**：总数 / 已掌握 / 掌握率% / 平均掌握度% / 薄弱数，实时随掌握更新。
