# 芙洛理 Flori 小白上手指南（服务端 + 客户端连接）

> 看得懂说明：这一套软件分**两个部分**——
> - **客户端（Flori.exe）**：你天天打开用的那个 App，相当于"笔记本"。
> - **服务端（Server）**：一个后台程序，相当于"云端仓库 + 自习室大厅"。
>
> **不连服务端也能用**（客户端所有功能本机照常跑）；连上服务端后，多了一层：
> 数据自动备份到"仓库"、多台电脑能同步、还能进"自习室"看别人在不在、看公共专栏、传资源。
>
> 本指南只讲**怎么把它跑起来、怎么连上**，用大白话 + 复制粘贴的命令。

---

## 第 0 步：你要先准备什么（清单）

| 需要的东西 | 说明 | 怎么确认已具备 |
|---|---|---|
| ① 项目文件夹 | 就是 `<仓库根>` 这一整套 | 你能看到 `DesktopApp\` 和 `Server\` 两个文件夹就行 |
| ② 客户端程序 Flori.exe | 已经帮你编译好了，**不用自己编译** | 在 `DesktopApp\build\Flori.exe` |
| ③ Node.js（服务端需要） | 服务端是用 Node 写的，电脑上得装它 | 见下方"怎么装 Node" |
| ④ 一个命令行窗口 | 用来启动服务端（不是双击，是敲命令） | Windows 按 `Win` 键，输入 `cmd` 回车，能打开黑窗口即可 |

### 怎么装 Node.js（如果还没装）
1. 先确认有没有：打开命令行（`Win` 键 → 输 `cmd` → 回车），输入：
   ```
   node -v
   ```
   - 如果显示类似 `v20.12.2` 这种版本号 → **已经有了，跳过安装**。
   - 如果显示"不是内部或外部命令" → 需要安装。
2. 安装：浏览器打开 `https://nodejs.org`，点那个绿色 **LTS** 大按钮下载，双击一路"下一步"装完。
3. 装完**重新打开**一个命令行窗口，再输入 `node -v` 确认能看到版本号。

> 注意：服务端是"零依赖"的，装完 Node 直接能用，**不需要**在 Server 目录里跑 `npm install`。

---

## 第 1 步（最省事）：服务端和客户端在**同一台电脑**上

这是给小白的最推荐方案，几乎不用改任何设置。

### 1-A. 启动服务端

> **懒人法（推荐）**：直接**双击** `Server\启动服务端.bat`，它会自动帮你 `cd` 到正确目录并检查 Node.js，然后启动服务端。看到"服务端已启动"就成功，**窗口别关**。跳到下面第 4 步看成功提示即可，不用敲命令。

1. 打开命令行（`Win` 键 → 输 `cmd` → 回车）。
2. 进入服务端目录（**整段复制粘贴**，路径按你实际位置来）：
   ```
   cd "<仓库根>/Server"
   ```
3. 启动：
   ```
   node server.js
   ```
4. 看到下面这样的字，就成功了（窗口**不要关**，关了服务端就停了）：
   ```
   芙洛理 Flori 服务端已启动  http://0.0.0.0:8787
     数据目录 : ...\Server\data
     已注册   : X 个账户（含演示账户 demo）
     WebSocket: 同端口同源，先发 auth 帧
   ```

### 1-B. 打开客户端（自动连上，不用手动登录）
1. 打开文件夹 `DesktopApp\build\`，**双击 `Flori.exe`**，App 就打开了。
2. 因为是同一台电脑，客户端默认就会去连 `127.0.0.1:8787`，**不用做任何配置**。
3. **现在不用手动登录了**：App 一打开会自动以演示账户 `demo` 进系统，并在后台**自动连上服务端**（已经打好了"自动连云端"补丁）。你只需要等个 2~3 秒让它在后台完成握手。
   - 想确认：打开后是直接进主界面的（不是登录框），就说明本地已自动登入；连上云端后专栏/自习室会亮起"实时"。
   - 用自己的账户也行：在账户胶囊点"退出"→ 登录框输入你的账户；第一次手动登录后令牌会记住，以后也是双击自动连。
4. 连接成功后，客户端会在后台自动把数据同步到服务端。

---

## 第 2 步：怎么确认"连上了"

登录后，到这几个地方看一眼，出现"实时 / 云端"字样就说明连上了：

- **自习室（RoomView）**：成员卡片显示 **"实时"**，能看到在线成员。
- **专栏（RoadmapView）**：页面底部出现 **"公共专栏（实时）"** 一栏。
- **资源库（MediaView）**：页面底部出现 **"云端资源库"** 一栏。

如果显示的是 **"离线"**，说明服务端没连上，看下面"常见问题"。

---

## 第 3 步：关掉 / 重启

- **正常关机顺序**：先关客户端（直接关窗口），再回到服务端那个黑窗口按 `Ctrl + C` 停掉服务端。
- **下次再用**：重复"第 1 步"重新 `node server.js` 启动即可。
- **断网也不怕**：服务端没开时，客户端照常使用，所有数据存在你本机；等服务端重新开起来，客户端会自动重连并补同步。

## 进阶：客户端在**另一台电脑**上（局域网）

只有当你想"服务端跑在 A 电脑、客户端跑在 B 电脑"时才需要这一步。同机使用请忽略。

1. **在 A 电脑（跑服务端那台）查 IP**：命令行输入 `ipconfig`，找"IPv4 地址"，类似 `192.168.1.100`。
2. **在 B 电脑（跑客户端那台）建配置文件**：
   路径：`DesktopApp\build\accounts\cloud-config.json`（没有就新建一个文本文件，改成这个名）。
   内容（把 host 改成 A 电脑的 IP）：
   ```json
   {
     "host": "192.168.1.100",
     "port": 8787,
     "secure": false,
     "enabled": true
   }
   ```
3. **A 电脑放行防火墙**（管理员 PowerShell）：
   ```powershell
   New-NetFirewallRule -DisplayName "芙洛理服务端" -Direction Inbound -Port 8787 -Protocol TCP -Action Allow
   ```
4. 在 B 电脑打开 `Flori.exe`，它会自动连到 A 电脑的服务端。

## 常见问题（对着查）

**Q：客户端一直显示"离线"？**
- 服务端那个黑窗口关了没？关了就重新 `node server.js`。
- 同机的话，确认服务端在跑，再重启一下客户端。
- 跨机的话，检查 `cloud-config.json` 里的 `host` 是不是对的、`enabled` 是不是 `true`、防火墙放行了没。

**Q：提示"Node 不是内部或外部命令"？**
- Node.js 没装或没装好。回到"第 0 步"重装，装完**重开命令行窗口**。

**Q：登录了但数据没出现？**
- 同步是后台慢慢跑的，登录后等 2~3 秒再看。
- 想看同步日志：客户端会写 `DesktopApp\build\flori.log`。

**Q：我不想用服务端，能不能纯单机？**
- 能。直接双击 `Flori.exe` 用就行，所有功能本机都能跑，只是没有云端备份/多端同步/自习室社交。

**Q：演示账户是干嘛的？**
- 是一个预置好的测试账户（用户名 `demo`），自带上传资源等权限，方便你立刻体验全部功能。平时用自己的账户也行。
- **口令不写在文档里**（免得仓库一公开就跟着泄露）。要查就打开 `Server\src\config.js` 看 `DEMO_PASS` 那一行；想换成自己的，启动服务端前先设环境变量 `FLORI_DEMO_PASS`。

---

## 一句话总结
> 装好 Node → 双击 `启动服务端.bat`（窗口别关）→ 双击 `Flori.exe` → 等 2~3 秒（演示账户自动连云端）→ 看到"实时"就成功了。不用再手动登录。

> **小提示**：如果你双击 `Flori.exe` 时服务端还没开（或当时没连上），专栏会显示"离线"。只要服务端在跑，关掉客户端重新双击一次就会自动连上。
