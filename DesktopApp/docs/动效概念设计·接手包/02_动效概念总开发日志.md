- 全新隐喻（不重复砚心）：知识点=脉络节点，悬停/点击令"脉气"沿脉络传播点亮关联。
- 动效语言：
  - 悬停节点 → 脉冲沿二次贝塞尔脉络传播，相邻节点按 BFS 深度衰减点亮（最大深度 2，确定可控，不失控）；
  - 点击 → 通/取消该脉络（弹簧深化 + 朱砂环），顶部"已通脉络 N / 总"轻量进度（仅信息、无计分）；

- 技术：Canvas2D 主舞台 + 受控 WebGL 墨晕背景（shader 编译/链接校验 + try/catch，失败即隐藏、CSS 纸纹兜底，杜绝黑屏）；自动演示常开（可关）以保证受限预览里也有动效。
- 文件：`docs/墨脉·动效概念原型.html`、`docs/墨脉·动效概念介绍.md`。

## 概念 1 修复 · 显示 bug（2026-08-16）
- 现象：整图只显示在左上角、太密集、显示不全。
- 根因：① `resize()` 在脚本底部同步调用，`getBoundingClientRect()` 在 flex/绝对定位布局未 flush 时拿到 canvas 默认 300×150，节点据此全挤在 (150,75) 附近且后续无 resize 事件回不来；② 放射布局半径偏小（0.30/0.14×min）+ 无自动适配，整图未缩放居中。
- 修复：① 启动改到 `requestAnimationFrame`+`load` 之后，`resize` 加尺寸兜底（w/h<2 时回退 window 尺寸−顶栏）；② 新增 `fitView()` 自动把整图缩放居中铺满视口（zoom 钳 [0.5,1.6]）；③ 拉大布局半径（0.38/0.16×min）与字间距；④ 拖拽/滚轮置 `userMoved`，已交互则不强制重适配；⑤ 脉冲粒子 11→7 降噪。
- 校验：JS 语法通过；fitView 数值正确（zoom 有界、居中映射无 NaN）。仍须浏览器目视确认观感。

- **母题/交互**：暗房显影盘；核心循环=**扫显影/点阅卷/标掌握**，固定俯视 2D 取景（**绝非轨道旋转/缩放/飞入聚焦**，落实㉞）；悬停读标题、Esc 关闭。
- **技术/红线**：单文件 HTML，Canvas2D 主舞台(透明自洽)+WebGL2 受控背景(淡墨晕纸纹，失败即 display:none + CSS 纸纹兜底，绝不黑屏)；暖白纸 `#F6F2E9`、墨线主导(小菱形节点+细线关联)、零辉光、无彩圆(㉘㉝)，唯一彩色青绿 `#268678` 仅薄弱描边/显影笔晕/按钮。60 节点(七科确定性簇)+~120 关联细线，`mulberry32(20260822)` 确定性。
- **校验（双模式 DOM 桩无头探针）**：`node --check` SYNTAX_OK；WebGL 可用 与 WebGL=null 两模式均 **16/16 PASS**——init 不抛/ready、onScreen>0、nan=false、lightBg=true、develop.devCount+、card.open、markKnown(known+1&cov+&today+1&cardClosed)、markWeak(pending+1)、esc.close、跑帧后仍 nan=false&devCount>0、colorfulCircles=0(运行时按实际填充色校验仅墨灰/青绿通过)。**关键：WebGL 全缺时主舞台仍完整渲染全部节点，黑屏死因结构性消除**。修复 bug：初始未调 `resize()`(W/H=0)、`requestAnimationFrame` 未守卫、补彩色圆运行时检测。
- **诚实限制**：headless 证逻辑不崩/在屏/无NaN/亮底/无彩圆/显影-阅卷-计数数值对；**显影笔观感、墨色浓淡层次、知识拓扑疏密、阅卷卡排版、亮纸配色协调度须真机确认**。
