# 弦 · 时序 · 开发日志

> 概念 8：复盘界面里的一组时间之弦。动效为主、非游戏、真实操作驱动、确定可控、落真实界面、非大众化、零辉光。

## 概念 8 v1（2026-08-16）
- **方向确认**：用户从候选中选定「弦·拨动时序」，取代概念 7 素履（已冻结于 V1）。
- **隐喻**：复盘界面中 5 根水平弦 = 专注 / 考点 / 练考 / 打卡 / 时政；每根弦的静止轮廓即该通道数据曲线，拨动产生受控振动波。
- **真实操作映射**：
  - 悬停 → 轻拨光标处弦；
  - 拖动 → 扫弦（连续轻拨）；
  - 单击 → 标记今日，确定式 +42 专注、连续打卡 +1；
  - 滚轮 → 平移 28 天时间窗。
- **动力学**：一维波动方程显式差分，`C²=0.16`、`DAMP=0.992`、端点固定反射、邻弦耦合 `3%`。有界、稳定、必收敛。
- **技术栈**：Canvas2D 单文件原型（无 WebGL，零黑屏风险）。
- **文件**：`docs/弦/弦·动效概念原型.html`（14.6KB）、`docs/弦/弦·动效概念介绍.md`、本日志。
- **校验**：
  - `node --check` 内联脚本 → SYNTAX_OK。
  - puppeteer-core + Chrome ANGLE/SwiftShader 1366×860，2.6s：零错误、RAF 运行、弦被画出、单击标记今日 99→141（+42）、连续打卡 2→3。
- **红线**：仅新增/修改 `docs/弦/` 与主索引；未碰看板娘层 / App.cpp / TopBar.cpp / Store.*；未 `git add -A`。
- **待评审**：用户真机目视确认拨弦/扫弦/共鸣手感，以及 5 通道是否可读。

方法论（沿用 `creative-motion-design`）：
- 先确认母题再动手（避免在错母题上打补丁）。
- 图表本体 + 风格层分离：弦的静止轮廓 = 数据（本体）；拨动波纹 = 动效（风格层）。
- 形态优先于特效：先让 5 通道曲线清晰可读，再叠拨弦。
- 禁用软圆辉光作主特效：用波动/共鸣/琴弦位移表达「光感」，而非径向渐变光球。
