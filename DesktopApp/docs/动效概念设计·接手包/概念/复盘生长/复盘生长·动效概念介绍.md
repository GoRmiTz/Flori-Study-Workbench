# 复盘 · 生长 — 动效概念介绍

## 一句话意义

把「你每天到底学了什么、学得怎么样」这件**实用且高频**的事，变成一棵**看得见的生长树**：年轮随真实复习数据一圈圈长大，薄弱科目自己发光预警，漂浮光点是你亲手收集的考点。它首先是**复盘工具**，其次才是艺术动效。

---

## 为什么做这个概念（问题导向）

1. **意义优先**：用户明确否决 织（"不懂设计意义是什么"）。复盘生长不再依赖抽象隐喻，而是直接落在 芙洛理 已有的真实功能上：
   - F-D1 FocusTracker：每日专注时长
   - F-D5 拖拽收集考点 → `knowledge.json`
   - 练考模块：模考/时政日练正确率
   - F-D7 本地复盘 + 每日 21:00 nudge
   - 先公后研总计划：距国考/省考/事业单位/考研转轨的天数
2. **实用价值第一**：
   - 一眼看到自己连续打卡几天、今天专注多久、收集多少考点、正确率如何。
   - 薄弱科目自动以冷光裂痕形式浮现，不用翻表格。
   - 与考试倒计时对齐，避免"埋头学却忘了还剩多久"。
3. **动效建立在真实操作上**：悬停看某天、点击"标记今日已复盘"、每日 nudge 唤起。没有问答/计分/输赢，不是小游戏。

## 动效语言（艺术层，由实用层驱动）

| 视觉元素 | 它代表什么（意义） | 动效怎么动（真实输入驱动） |
|---|---|---|
| **同心生长年轮** | 最近 28 天，每一天的投入强度 | 每圈亮度/饱满度 = 当天 `dayFill`；最外圈（今天）按角度 0→360° 生长绘制 |
| **冷光蓝圈** | 模考正确率 < 58% 的薄弱日 | 持续确定频率冷光脉动，仅警示、不吓人 |
| **中心核心** | 连续打卡天数 | 随 streak 微微脉动放大 |
| **漂浮光点** | 拖拽收集的考点（F-D5） | 按类别（考公/考研/事业）着色，沿轨道确定速度漂浮 |
| **悬停高亮** | 查看某一天的具体数据 | 该圈整体亮起 + 沿环行进光峰，右侧面板同步切换 |
| **点击「标记已复盘」** | 完成今日复盘动作 | 今日圈重新生长一遍 + streak +1 + 按钮状态变化 |

- **确定可控**：所有脉动、漂浮、生长速度都是常量，不引入随机游走或失控粒子。
- **非游戏**：没有计分、没有胜负、没有抽卡/奖励机制。
- **落真实界面**：右侧即 复盘 面板 mock，后续可直接替换为真实 ReviewEngine 数据。

---

## 与真实 芙洛理 数据的对接

概念原型使用**确定性演示数据**，落地时只需要把下表替换成 ReviewEngine 的真实输出：

| 字段 | 来源 | 在原型中对应 |
|---|---|---|
| `dayFill` | 综合专注时长 + 收集考点数 | 年轮饱满度 |
| `dayAcc` | 练考/模考正确率 | 薄弱日判定（<58% 变冷光） |
| `dayPts` | F-D5 拖拽收集考点 | 当天收集点数（右侧面板） |
| `dayFocus` | F-D1 FocusTracker | 当天专注分钟（右侧面板） |
| `streak` | F-D7 连续打卡 | 中心核心脉动强度 |
| `weakSubjects` | 练考按科目统计 | 右侧面板薄弱科目列表 |
| `距国考/省考/事业单位/考研` | 先公后研总计划 | 面板倒计时 |

## 技术栈

- 单文件 HTML + WebGL1（零依赖、零贴图）。
- 复用 织 v1.1.3 已验证可渲染的脚手架：WebGL context、bloom FBO 可分离高斯、全局 error 兜底、load+rAF resize、DPR≤2。
- 几何：实心环带（`TRIANGLES`）做年轮、`POINTS` 做漂浮考点。
- 着色器：年轮片元用 `band = 1 - |edge-0.5|*2` 做柔和边缘；薄弱日混入冷色 + 正弦脉动；mote 片元做软核+光环。
