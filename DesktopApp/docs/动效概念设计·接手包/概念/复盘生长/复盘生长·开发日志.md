## 概念 5 · v1（2026-08-16）

### 背景
用户否掉概念 4「织」："不懂这个概念的设计意义是什么"，明确要求下一个概念必须**先有意义、有实用价值，再做艺术动效设计**。根因诊断：织锦隐喻是「知识=布」的抽象修辞，没有解释清楚它解决了 芙洛理 里什么具体问题、用户为什么要看。

### 创意怎么来的（Ideation）
不再从抽象隐喻出发，而是直接看 芙洛理 已有的真实数据能力：
- F-D1 FocusTracker → 专注时长
- F-D5 拖拽收集考点 → knowledge.json
- 练考模块 → 模考/时政日练正确率
- F-D7 本地复盘 + 每日 21:00 nudge
- 先公后研总计划 → 考试倒计时

这些能力都围绕**「复盘」**：你今天学了多久？哪些考点收集了？哪科薄弱？距离考试还剩多少天？这是用户每天都需要、且数据真实存在的高频场景。于是概念定为：**复盘 · 生长** —— 把真实复习数据变成一棵可见的生长树。

### 怎么实现的（Implementation）
- **栈**：单文件 HTML + WebGL1，零依赖、零贴图。
- **数据模型**：28 天演示数据（`dayFill` 投入强度 / `dayAcc` 正确率 / `dayPts` 收集考点 / `dayFocus` 专注分钟 / `weakSubjects` 薄弱科目）。落地时由 ReviewEngine 真实喂入。
- **几何**：
  - 生长年轮：28 个同心实心环带（`TRIANGLES`，每环 SEG=120），由内向外交叠 —— 内圈是 28 天前，外圈是今天。
  - 漂浮考点：52 颗 `POINTS`，按考公朱/考研碧/事业金三色，沿轨道确定速度漂浮。
  - 中心核心：一颗 `POINTS` 光点，代表连续打卡 streak，rad=0。
- **着色器**：
  - 年轮片元：`band = 1 - |edge-0.5|*2` 做柔和环带边缘；`aWeak` 混入冷色并叠加确定频率脉动。
  - 今日圈（最外圈）按 `uGrow` 做角度裁剪，实现 0→360° 生长绘制。
  - Mote 片元：软核 + 细光环。
- **后处理**：复用 织 v1.1.3 已验证的 FBO bloom（9-tap 可分离高斯）+ vignette，失败自动降级直渲。
- **交互（真实操作驱动）**：
  - 悬停某圈 → 该圈高亮 + 沿环行进光峰 + 右侧面板显示当天数据。
  - 点击「标记今日已复盘 ✓」→ 今日圈 fill 提升、重新生长一遍、streak +1、薄弱标记清除。
- **可靠性**：load+rAF 后 resize；DPR≤2；全局 `error`/`unhandledrejection` 兜底；FBO 校验失败降级；`frame()` 包 `try/catch`。
- **mock 真实界面**：顶栏（芙洛理 · 复盘 · 生长）、右侧复盘面板（连续打卡/今日专注/收集考点/模考正确率/距国考/薄弱科目/标记按钮）、底部提示 HUD、左侧图例。

### 实用价值（此概念的核心）
1. 一眼看到坚持曲线：连续打卡、每日投入。
2. 薄弱科目自动预警：正确率低的日期/科目以冷光裂痕浮现，不用翻表格。
3. 与考试倒计时对齐：面板直接显示距国考 105 天等。
4. 数据全部来自真实功能，没有虚构的游戏机制。

### 落地/校验
- JS 内联脚本提取后 `node --check` → **SYNTAX_OK**。
- headless 验证：puppeteer-core + Chrome SwiftShader，1280×860 跑 2.2s，fallback=none、canvas 尺寸正确、面板数据渲染正常、零 console/page 错误；截图证实圆形年轮、冷光薄弱区、漂浮光点、中心核心全部可见。
- 静态核查：所有 `bindBuffer` 均传 `.b`（吸取 织 的 wrapper-object 教训）；`uAspect` 保证不同视口下年轮为圆形；无 `eval/innerHTML/document.write/new Function`。
- 诚实限制：headless 无法验证真实鼠标悬停/点击手感；需在 Chrome/Edge 真机确认悬停看当天、点击标记已复盘、生长动画节奏。

## 概念 5 · v1.1（2026-08-16）

### 改动
- 修复 headless SwiftShader 下偶发的「启动期 getContext 返回 null」问题，同时提升真实多显卡/延迟 GPU 初始化机器的健壮性。
- 将同步 `const gl = canvas.getContext(...)` 改为 `acquireGL()` + `main(gl)` + `run()` 重试循环：
  - 首帧尝试拿 WebGL context；
  - 失败则通过 `requestAnimationFrame` 最多重试 150 帧（约 2.5s），再真正降级到 fallback；
  - 重试成功后再进入 buffer/shader/FBO 初始化与 `boot()`。
- 这样避免了因 GPU 进程尚未就绪而在真实用户机器上误报「不支持 WebGL」。

### 校验（v1.1）
- JS `node --check` → **SYNTAX_OK**。
- puppeteer-core + Chrome ANGLE/SwiftShader，1366×860，等待 3.5s：
  - fallback 隐藏（`display:none`）、零 console/page 错误；
  - 截图确认：28 圈同心年轮、冷光薄弱区、漂浮光点、中心核心、两侧 UI 面板全部正常渲染；
  - 年轮为圆形（uAspect 校正生效）。
