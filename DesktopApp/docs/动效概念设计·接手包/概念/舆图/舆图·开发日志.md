# 概念 28 · 舆图·知识疆域 — 开发日志

## 缘起（2026-08-22）
用户在前一档（概念 27 抽笺·知识笺匣）交付后说"另开"，要求再开一档**全新、不重复**的概念原型。本轮在概念 27 已落实铁律㉟（拒绝花瓶·必须有买点）的基础上，继续强化"买点 + 信息可视化"双主轴，并刻意避开㉞禁用的「轨道观察结构」范式与织缕（织线）/ 抽笺（抽卡）的交互。

## 母题决策
- 选**古舆图 / 疆域图**：知识空间 = 按公考七科分域的地图；未勘=淡墨留白、勘明=等高线墨纹。
- 区别于已归档/在档：浮岛、下潜、平衡、桁架、织机、签筒、轨道结构——本概念是**俯视地图 + 点击勘察回忆测验**，范式不重复。

## 买点设计（先于视觉，回应㉟）
1. 顶部 KPI：疆域覆盖率 % + 七科进度条（信息可视化，用户头号优先级）。
2. 每次勘察 = 一次回忆测验（点留白区→出考点题→标掌握/待巩固）。
3. 待巩固进池、今日勘察计数，自适应重排接口预留。
4. 软件落点：区域=QuizParser 题库分域簇；掌握→ReviewEngine；覆盖率→dashboard。
5. 进度可视化（成就感非计分，落实㉜）。

## 技术实现
- 单文件 HTML；主舞台 Canvas2D（透明自洽）+ WebGL2 受控背景（淡墨晕舆纸，编译/链接失败即 `display:none` + CSS 纸纹兜底，绝不黑屏）。
- 56 区域（7×8），`mulberry32` 确定性生成题面。
- 状态机：map ↔ survey；markKnown（覆盖率+1、涟漪蔓延相邻）/ markWeak（进待巩固池）/ Esc 关闭。
- 暴露 `window.__api` 供无头探针。

## 校验
- `node --check`：SYNTAX_OK。
- 双模式 DOM 桩无头探针（WebGL 可用 / **WebGL=null**）均 **15/15 PASS**：
  - init 不抛 / ready、onScreen=56>0、nan=false、lightBg=true、colorfulCircles=0；
  - surveyRegion(0) 打开面板；markKnown→known=1&today=1；markWeak(1)→pending=1&today=2；Esc 关闭；
  - 点击路径：onDown 未勘区(2) 打开 survey、再点「已掌握」按钮→known=2；跑 5 帧后仍 nan=false&onScreen>0。
- **关键**：WebGL 完全缺失时主舞台仍完整渲染 56 区，黑屏死因结构性消除。

## 诚实限制
headless 仅证逻辑不崩/在屏/无NaN/亮底/无彩圆/数值对；等高线墨纹疏密、亮纸配色协调、勘测面板排版、涟漪手感、七科进度条观感须真机确认。
