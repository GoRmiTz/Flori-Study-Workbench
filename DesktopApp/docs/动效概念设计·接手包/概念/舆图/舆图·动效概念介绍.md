# 概念 28 · 舆图·知识疆域 — 动效概念介绍

> 接手包：`DesktopApp/docs/动效概念设计·接手包/`
> 原型：`概念/舆图/舆图·动效概念原型.html`（Chrome / Edge 打开本地文件即玩）
> 设计红线：㉘ 线条主导无彩圆 · ㉝ 亮色背景 · ㉞ 禁重复「轨道观察结构」范式 · ㉟ 拒绝花瓶·必须有买点/价值闭环

---

## 一、买点 / 价值闭环（先于视觉）

这是本概念与过往"花瓶"最根本的区别——先讲它**怎么落进真实软件、凭什么是买点**，再讲视觉。

1. **信息可视化优先（用户头号优先级）**：顶部 KPI 直接给出**疆域覆盖率 %** 与**七科进度条**（政治 / 常识 / 申论 / 言语 / 数量 / 判断 / 资料）。用户一眼看清"我已掌握多少、哪科还是空白"，这是实用价值，不是装饰。
2. **每次交互 = 一次回忆测验（学习价值闭环）**：点一个留白区域 → 弹出该考点的**勘测题** → 用户标「已掌握 ✔」/「待巩固 ↺」。交互本身就是在做 spaced-repetition 式的主动回忆，不是被动观赏。
3. **自适应复习**：标「待巩固」的区域进入待巩固池、今日勘察数 +1，后续可加权重排（原型已留 `pending` 计数与重排接口），形成复习闭环。
4. **软件落点（落在哪、接什么）**：
   - **内容源**：区域 = 练考模块 `QuizParser` 产出的题库，按科目分域聚簇；勘测题直接复用题目 `.md` 的题干。
   - **掌握度 → 复盘**：「已掌握」写入 **ReviewEngine** 复盘；「待巩固」进**错题集**。
   - **覆盖率 → dashboard**：顶部覆盖率与各科进度条可上收到首页 / 复盘页，作为学习仪表盘组件。
5. **进度可视化（成就感，非计分）**：已勘区域长出等高线墨纹、涟漪向相邻区蔓延，整张疆域逐渐"被点亮"——是"我的知识地图在长出来"的满足感，不是排行榜式廉价游戏感（落实㉜）。

---

## 二、母题与交互范式

- **母题**：古舆图 / 疆域图。知识空间是一张按**公考七科分域**的地图；未勘区域是淡墨留白 + 斜纹，勘明区域长出等高线墨纹 + 标签。
- **核心循环 = 勘察 / 标记 / 蔓延**，固定俯视地图取景：
  - **勘察**：点未勘区 → 打开勘察面板（考点名 + 勘测题 + 两枚按钮）。
  - **标记**：「已掌握」→ 区域转为墨纹已勘、覆盖率 +1、向相邻区发出青绿涟漪；「待巩固」→ 保持留白、进待巩固池。
  - **蔓延**：掌握一个区，相邻区的"已勘连接数"实时更新（悬停面板可读），形成知识网络的可见生长。
- **范式对照（落实㉞ 不重复）**：
  | 旧范式 | 本概念 |
  |---|---|
  | 轨道旋转 + 缩放 + 飞入聚焦（识墟/识渊/识悬/识构） | 固定俯视地图，点击勘察，**绝不轨道环视** |
  | 拖两节点织线（织缕） | 点击区域做回忆测验 |
  | 随机抽笺（抽笺） | 自主选未勘区勘察，地图覆盖率可视化 |
- **舒适交互（㉛）**：无长距跳转；悬停即读详情、点击即开面板、Esc 即关，反馈都在原地。

## 三、视觉与红线落实

- **亮色背景（㉝）**：暖白纸底 `#F6F2E9`（CSS 兜底渐变 + WebGL2 受控背景叠加淡墨晕舆纸纹理）。
- **线条主导 · 无彩圆（㉘）**：已勘区用**细等高线墨纹 + 墨色标签**，未勘区用**淡斜纹留白**；唯一彩色是青绿 `#268678` 仅作**描边 / 涟漪 / 按钮**（非填充圆）。零辉光、零 bloom。
- **受控 WebGL（绝不黑屏）**：GLSL 淡墨晕舆纸为受控背景层，编译/链接失败即 `display:none`、CSS 纸纹兜底，绝不黑屏。
- **数据着色豁免（克制）**：科目不以彩虹区分，而以**七列网格位置 + 进度条**区分，避免撞色（落实"告别方块堆叠 / 配色克制"）。

---

## 四、技术结构

- 单文件 HTML；主舞台纯 Canvas2D（透明底、自洽、不依赖 WebGL）；WebGL2 仅作背景。
- 56 区域（7 科 × 8 题），`mulberry32` 确定性 RNG 生成题面，headless 可复现。
- 暴露 `window.__api`（onDown/onMove/onUp/onWheel/onKey/surveyRegion/markKnown/markWeak/regionScreen/getProbe/setSize）供无头探针驱动。

---

## 五、诚实限制

headless 证了：init 不抛 / 56 区在屏 / 无 NaN / 亮底 / 无彩圆 / 抽-标-计数值对 / WebGL=null 仍完整渲染。但**等高线墨纹疏密、亮纸配色协调、勘测面板排版、涟漪手感、七科进度条观感**须用户在真实浏览器（Chrome / Edge 开本地文件）确认。
