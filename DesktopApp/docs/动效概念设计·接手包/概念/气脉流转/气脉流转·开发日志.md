# 气脉 · 流转 — 开发日志（概念 11）

## v1（2026-08-16）
### 背景与立项
用户认可概念 10「考点星图」为**新基线**（"创意出发点不错，创意和视觉都可以"），并要求"继续下一个概念"。
概念 11 沿用新基线配方（非时序 / 单主色墨青 + 明度层次 / 细线·连续面 / 信息可读 KPI+悬停探针 / 真实操作驱动 / 零辉光 / 确定可控 / 非游戏），但换一个**不同的非时序母题**——连续标量场，与概念 10 的"点拓扑"形成"点-面"互补，避免同一母题连否。

### 数据模型
- 学科 SUBJ = [行测, 申论, 常识, 时政, 专业课] × 维度 DIM = [理解, 记忆, 运用, 熟练] → 20 个采样点。
- 每点持有 `val`（当前掌握度）、`target`（目标，弹簧收敛）、固定网格位置 `(sx,sy)`。
- 初始 `val` 由确定性 hash 生成（0.18..0.80），保证有若干薄弱点（<0.4）供演示与校验。

### 场函数（连续面）
`fieldAt(nx,ny) = Σ val_i·g_i / Σ g_i`，其中 `g_i = exp(-d²/(2σ²))`，σ=0.165。
→ 平滑 0..1 的连续标量场，无方块、无网格硬边。

### 渲染
- 离屏小画布 224×140，逐像素算 `f`：
  - 基色 = `hsl(190°, 36%, 8% + f·54%)`（单主色墨青，明度编码强弱）；
  - 四条等值线带：|f−0.25|<0.02 / 0.45 / 0.65 / 0.85 → 提亮细线（细线美学，非辉光）。
- 主画布 `drawImage` 上采样（imageSmoothing）→ 平滑连续面；叠加细轴网 + 学科/维度标注 + 采样点（大小/亮度=掌握度，薄弱点红叉）+ 悬停探针环。

### 交互（真实操作驱动 · 确定可控 · 非游戏）
- 悬停 → 探针十字环 + 面板（强度% + 所属学科·维度），受控非自跑。
- 点击/拖动 → `boostAt(nx,ny)`：找最近采样点（场空间半径 0.14 内）设 `target=1`；每帧临界阻尼弹簧 `val += (target−val)·0.14` 收敛。
- 滚轮 → 缩放视场 Z（钳 [0.65, 2.6]），仅影响显示映射，不影响场值。
- 自动演示：开局 1.6s 自动抬升最弱项一次（展示"场随输入变化"），缓动虚线探针环巡游；用户交互即停。

### 校验
- `node --check` 抽取内联 JS → **SYNTAX_OK**。
- puppeteer + Chrome/ANGLE/SwiftShader 无头探针：
  - **ERRORS []**（零报错）；STATE {samples:20, dirty:false, Z:1}；
  - 探针 (640,400) → {value:0.542, subj:"常识", dim:"记忆"}（场映射正确）；
  - 注入最弱项后：**薄弱点 5→4**、**总体掌握 53.6%→57.5%**、峰值 68.8%→81.9%、高强区占比 18.9%→33.7%——交互与 KPI 全部按设计生效、弹簧收敛。
