# 识墟 · 创新点 · 聚焦飞入（Focus Fly-in）

> 本文记录「识墟·知识浮城」中**被用户明确认可**的一个差异化功能：**聚焦飞入**——点击任一考点，视角平滑地「飞」到它所属的浮岛并绕该岛旋转，而非瞬移、也非回到世界原点。
> 标记为可复用的**创新点**，后续概念（含识悬）直接沿用此交互骨架。

---

## 1. 为什么它是创新点（与以往的区别）

以往概念（洋流 / 鳞甲 / 凝核 / 深潜 / 浮城）的主交互都是「在固定世界原点周围观察 / 穿行」。视角中心永远是世界原点 `(0,0,0)`，**无法把注意力停在某个具体知识体上**。

聚焦飞入打破了这一点：

- 用户**主动指定一个目标点**（点击节点 → 取其所属浮岛中心），视角中心从世界原点**迁移到该点**；
- 迁移是**确定性的缓动**（lerp，非瞬移、非匀速、非失控），符合「真实操作驱动、确定可控、无长跳」；
- 之后拖拽旋转，**是绕这个被聚焦的点转**，而不是绕世界原点——等于把「观察坐标系」的锚点交给了用户。

一句话：**视角锚点可被子操作转移 + 确定性飞入**，是「以用户意图为中心」而非「以场景原点为中心」。

---

## 2. 实现原理（三段式）

### 2.1 相机模型：把「注视点」与「眼睛」解耦

识墟的相机不是「位置 + 朝向」二段式，而是**目标点 `target` + 球面朝向（yaw/pitch）+ 距离 `camDist`** 三段式：

```js
const cam = { yaw, pitch, camDist, target:[0,0,0],
              tYaw, tPitch, tDist, tTarget:[0,0,0] };   // t* = 目标值（缓动终点）
```

眼睛位置由 `target - 前向*camDist` 推出（`camBasis()`），所以 **`target` 就是轨道旋转的中心 / 注视点**。

### 2.2 点击：把目标点设为浮岛中心，并拉近

核心就在 `click` 处理器（识墟原型 135–143 行）：

```js
cv.addEventListener("click",(e)=>{
  // …拾取命中节点 hit…
  if(hit>=0){
    lockId=hit;
    highlight=ancestorsOf(hit); highlight.add(hit); explored.add(hit);
    const isl=SCENE.islands[SCENE.nodes[hit].isl];
    cam.tTarget=[isl.cx, isl.cy, isl.cz];                 // ① 轨道中心 → 该浮岛中心
    cam.tDist=Math.max(14, Math.min(72, cam.camDist*0.62)); // ② 拉近（确定性缩放）
  } else { lockId=-1; highlight.clear(); }
});
```

两行即完成「聚焦」：① 让未来的旋转中心落到浮岛中心；② 把距离乘 0.62 拉近，让该岛占屏更大。

### 2.3 帧循环：缓动迁移（确定可控，无长跳）

`frame()` 每帧把当前值向目标值缓动（识墟原型 167–172 行）：

```js
cam.yaw   += (cam.tYaw   - cam.yaw)   * 0.12;
cam.pitch += (cam.tPitch - cam.pitch) * 0.12;
cam.camDist += (cam.tDist - cam.camDist) * 0.12;
cam.target[0] += (cam.tTarget[0] - cam.target[0]) * 0.10;  // ③ 注视点平滑飞入
cam.target[1] += (cam.tTarget[1] - cam.target[1]) * 0.10;
cam.target[2] += (cam.tTarget[2] - cam.target[2]) * 0.10;
```

- 系数 0.10~0.12 是**指数缓动**，越接近目标越慢，没有「啪一下跳到」的突兀感——直接贯彻铁律㉛「交互舒服、步距连续无长跳」；
- 因为只改 `target` 不改 `yaw/pitch` 当前值，飞入过程中用户**仍可继续拖拽**，旋转中心会顺滑地跟着新锚点走，不会打架。

### 2.4 复位：Esc 回到世界原点

```js
addEventListener("keydown",(e)=>{ if(e.key==="Escape"){
  lockId=-1; highlight.clear();
  cam.tTarget=[0,0,0]; cam.tYaw=0.6; cam.tPitch=-0.22; cam.tDist=34;  // 缓动回默认锚点
}});
```

## 3. 复用契约（给后续概念）

任何需要「在 3D 场景里关注某具体对象」的概念，直接套用此骨架：

1. 相机用 **`target`(注视点) + yaw/pitch + dist** 三段式，眼睛 = `target - 前向*dist`；
2. 点击对象 → 设 `tTarget = 该对象锚点`、`tDist = 拉近系数`；
3. 帧循环用 **0.10~0.12 指数缓动**迁移 `target` 与各角/距；
4. 复位键把 `tTarget` 与视角参数缓动回默认；
5. 全程不瞬移、不匀速、不失控——确定性可控。

> 识悬·知识悬衡已复用此契约：点击挂牌 → `tTarget` 设为该臂的悬挂轴点并拉近，实现「聚焦到某一学科臂」。

---

## 4. 校验与已知限制

- 无头纯 Canvas2D 桩验证：点击命中 → `lockId` 写入、`cam.tTarget` 改变、后续帧 `cam.target` 向新锚点收敛、`nan=true`、Esc 后回默认——全 PASS。
- 诚实限制：缓动手感（0.10 是否够顺、拉近 0.62 是否合适）须真机确认；本创新点是**交互骨架**而非视觉风格，可套用于任意 3D 母题。
