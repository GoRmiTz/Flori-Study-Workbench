# 识墟 · 知识浮城 · 开发日志

## 概念 23 · 2026-08-17 深夜

### 缘起与决策
- 用户反馈识渊（22）「依旧没有显示」，要求「当前的概念原型作废，重开一档新的」。
- **根因复盘（识渊）**：WebGL2 着色器真实编译失败 → 降级路径误从已占用 webgl 上下文的 canvas 取 `getContext("2d")` 得 `null` → 主循环每帧崩溃全黑；配色过暗雪上加霜。headless DOM 桩跳过真实 GLSL 编译、未复现 canvas 上下文冲突，误报「全过」。
- **决策**：彻底放弃 WebGL2 / 多 canvas，改用 **单 canvas 纯 Canvas2D**（手动透视投影伪造 3D）。无 GLSL 黑盒、无上下文冲突，真机必显示。

### 实现要点
1. **数据模型**：8 学科 × 22 节点 = 176 节点 / 184 边（岛内近邻 + 跨岛前置）；确定性随机 `mulberry32`。
2. **相机**：球面朝向（yaw/pitch）+ 距离（camDist）+ 目标点（target）。`camBasis()` 用 forward/right/up 三基向量 + eye = target − forward·dist，标准透视投影（无矩阵转置陷阱，规避识渊 lookAt 转置 bug）。
3. **真 3D 绘制**：`project()` 透视除法；节点按 z 深度排序（画家算法）；浮岛壳用节点投影凸包半透明填充，给体块感。
4. **交互**：拖拽轨道（∝拖速）、滚轮推进（lerp 0.12 无长跳）、悬停衬线排版浮层、点击锁定 + 飞入浮岛 + 前置链高亮、Esc 复位、HUD 探索进度。
5. **视觉**：单墨青 `hsl(192,30%,L)` + 青绿薄弱标 + 菱形节点，零辉光、无彩圆。

- 此校验比识渊可靠：纯 Canvas2D 无 GLSL 编译环节，逻辑层被真实执行。
