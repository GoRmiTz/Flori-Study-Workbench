## 1. 方向选定

先澄清「重复」的真正含义：概念 18–25 母题各异（浮岛/下潜/平衡/桁架…），但**交互范式全是「拖拽轨道旋转+滚轮缩放+飞入聚焦」观察式**，本质雷同。据此新增 **铁律㉞（禁止重复轨道观察范式）**，并定向修正铁律㉚（去掉强制 360° 轨道环视，改为「固定取景 3D 体 + 用户施操作 + 2D 浮层」）。

在四候选（墨显/织缕/抽茧/折叠）中，用户选 **织缕·经纬**。母题=织机，交互=织/摇机/温习，**固定取景、绝不轨道旋转、绝不飞入聚焦**——从根上脱离老范式。

## 2. 实现要点

- 单文件 HTML，纯 Canvas2D + 暖白纸底（CSS `#F6F2E9`），**无 WebGL**（彻底排除识渊式黑屏）。
- 经线 7 列（学科），每列 6–10 个织点；初始按「相邻学科最近 v 配对」生成 ~86 条依赖纬线。
- 织点：小菱形，墨色浓度=掌握度、薄弱=淡墨+青绿描边、大小=分值。
- 纬线：二次采样折线；过/下交错（奇偶）模拟织物质感；松紧=关联强度（弱→下垂+青绿）。
- 交互：onDown 命中织点→dragFrom；onMove 拖动→ provisional 虚线提示；onUp 若拖到异科节点→落织（去重），否则单击→温习养墨。滚轮→张力有界；Esc→复位。
- 沉降涟漪：织/温习触发 `rippleT` 阻尼衰减，确定性、非 idle。
- 顶部 KPI（学科/经纬/薄弱/均掌/张力）+ 悬停 2D 浮层精确读数。

## 3. 修复的真实 bug（headless 探针抓出）

1. **初始纬线 0 条**：`WARPS.forEach(wp=>{wp.knots=KNOTS.filter(k=>k.warp===wp.i);})` 漏赋 `wp.i` → 过滤全空 → 初始依赖无法生成。改 `WARPS.forEach((wp,i)=>{wp.i=i;...})`。
2. **织不生效 / `moved` 永不成立**：`onMove` 误写成 `dist(p,downPos)`（把两个对象当参数传给接收 4 个数值的 `dist`），算出 NaN，`NaN>4` 恒假，`moved` 永远 false，织分支走不到。改 `dist(p.x,p.y,downPos.x,downPos.y)`。
3. `getProbe` 里冗余的 `pressureT()` 清理为直接用 `tensionT`。
