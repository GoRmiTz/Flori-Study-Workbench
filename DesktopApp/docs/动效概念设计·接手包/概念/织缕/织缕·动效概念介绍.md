# 织缕·经纬 — 知识织机（概念 26）

> 母题=**织机 / 经纬**；交互范式=**织 / 摇机 / 温习**（彻底告别「轨道旋转+缩放+飞入聚焦」观察式范式）。
> 配套原型：`织缕·动效概念原型.html`（浏览器直接打开即玩）。

## 一、隐喻与落点

把知识体系想象成一台**织机**：

- **经线（竖）** = 学科。7 条经线并排，分别是政治理论 / 申论写作 / 言语理解 / 判断推理 / 数量关系 / 资料分析 / 数媒专业。
- **纬线（横）** = 跨科依赖 / 关联。一条纬线把两个不同学科的知识点织在一起，表示「学 A 离不开 B」。
- **织点** = 单个知识点，落在某条经线上，按难度/顺序上下排布。

**实用价值（区别于概念 4「织」）**：概念 4 的「织锦」只是装饰性隐喻，没有清晰信息编码，已被否。本概念把「织」做成**可操作的信息结构**——经线=学科轴、纬线=依赖关系、墨色=掌握度、松紧=关联强度，且**用户能亲手织出新关联、摇机调张力、温习养墨**，每一处动效都在让「学科间如何咬合」这一信息更直观可读。

## 二、信息编码（直观可读 · 铁律⑤）

| 视觉变量 | 编码含义 |
| --- | --- |
| 经线列位置 | 学科（7 列，列底标注学科名） |
| 织点纵向位置 | 该学科内的难度/顺序梯度 |
| 织点大小 | 分值权重（大=重点） |
| 织点墨色浓度 | 掌握度（浓墨深=掌握，淡墨=薄弱） |
| 织点青绿描边 | 薄弱点（掌握度<50%，一眼可辨） |
| 纬线墨深/粗细 | 关联强度（强=墨深粗、绷直） |
| 纬线下垂幅度 | 关联弱（松→垂，紧→直） |
| 顶部 KPI | 学科数 / 经纬数 / 薄弱数 / 均掌 / 张力 |

## 三、动效语言（真实操作驱动 · 确定可控 · 非游戏）

1. **织（核心交互）**：拖拽一个织点到另一个**不同学科**的织点 → 拉出一条新纬线，确定性落织（已存在的关联自动去重）。这是「用户真实操作生成结构」的动效，而非观察预设结构。
2. **摇机**：滚轮上下 → 调整织机全局张力。张力小→纬线松弛下垂；张力大→整幅绷直、节点轻微收拢。有界、确定、不失控。
3. **温习**：单击一个织点 → 「养墨」：掌握度上升、墨色加深、与之相连的纬线同步收紧。安静的确定性反馈，无计分/输赢（铁律㉜ 禁廉价小游戏感）。
4. **悬停探针**：悬停织点/纬线 → 2D 浮层读精确值（学科、掌握度%、建议学时 / 连接两端、关联强度%）。
5. **沉降涟漪**：每次织/温习，织物做一次阻尼收敛的轻微涟漪（确定性、非 idle 乱浮），呼应「织完一针、布面轻颤」的手感。
6. **Esc 复位**：清空选中/悬停、张力回到默认 50%。

## 四、红线落实

- **亮色背景（㉝）**：暖白纸底 `#F6F2E9` + 墨色线条主导（「墨落于纸」）；掌握度用墨色浓度表达，薄弱点用青绿描边，零辉光。
- **换交互范式（㉞）**：固定取景，**无轨道旋转、无缩放飞入、无 360° 环视**；用户不旋转结构，而是对它「织/摇/养」。这是对铁律㉚ 的定向修正。
- **线条主导、无彩圆（㉘）**：节点全为小菱形（非实心彩圆）；纬线为细墨线，弱关联才染青绿。
- **信息可视化优先（⑤）**：坐标轴（学科列）、数值（KPI + 悬停精确值）、可读几何（经纬网）先于风格层。
- **确定可控（⑥）**：所有动力学阻尼收敛；无失控混沌、无 idle 空浮。
- **非大众化（①）**：织机母题 + 织造动效，避开了 SaaS 蓝白卡片套路，也避开了「点-线-环-星」母题锁定（㉙）。
