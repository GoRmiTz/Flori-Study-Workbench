### 实现要点
- **数据模型**：8 学科 × 3 阶层（基础/进阶/高阶，沿 Y 纵深为全球 3 个地层）× 每层 6/8/10 考点 = **192 节点**；每点 `{掌握度, 难度, 前置[]}`；依赖线 = 层内聚类近邻 + 跨层前置，共 **489 边**；线粗 = 关联强度。确定性 seed。
- **相机**：第一人称下潜，`cam.y` 朝 `targetY` 做 lerp（0.12）缓动 → **无长跳**；拖拽 dx→yaw / dy→pitch，∝ 真实拖速 + 惯性快收敛（铁律㉗）。
- **双渲染后端**：
  - WebGL2 真 3D——地层（边缘暗化薄盘 + 网格着色器）、节点（实例化八面体 + Lambert + 明度编码掌握度 + 青绿薄弱标）、依赖细线（线宽 = 强度）、深度缓冲体积感、零辉光；上传前 `mat4Transpose` 转列主序。
  - Canvas2D 保底——手动透视投影 + 画家算法（远→近）渲染同一 scene，WebGL2 不可用时自动降级。
- **交互/2D**：悬停邻近节点 → 2D 浮层读数；点击锁定 → 持久标记 + 前置链高亮（青绿，BFS 沿 pre 边回溯）；Esc 解除；HUD（当前层 / 掌握总览 / 下潜进度条）；层标题衬线排版。

### 校验（无头双路径，DOM 桩真跑交互）
- **WebGL 路径**：init OK → 真实下潜 + 转向 + 滚轮缩放 + 悬停拾取 + 点击锁定(lock=10) + Esc 解除 → `nan=0`、zoom=1.08 有界、has3D=true、colorfulFilledCircles=false、192 节点 / 489 边 → **ALL PASS**。
- **无 GL 降级**：backend=2d 同样全过，不黑屏。
- 校验中修复 **4 个真实 bug**：
  1. `const octV=..., octN=mkBuf(octN,...)` —— `octN` 与上方法线数组重名导致重复声明（语法错）。改为 `octVB/octNB/octEB`。
  2. `mat4LookAt` 写成转置矩阵（平移项错放末行、轴向量转置）→ 所有节点被投到屏外。重写为正确行主序视图矩阵。
  3. WebGL `uniformMatrix4fv` 未把行主序 VP 转置为列主序；地层着色器未用 VP 变换。补 `mat4Transpose` 并给 strata/line/node 三程序统一传转置矩阵。
  4. `pick()` 与 `click` 里的 `if(p.z>0.98) continue` 过激，把「在屏但较远」的节点误杀，导致无法选中。删除该深度阈值（投影对相机背后点已用 `w<=0` 返回 null 过滤）。
