# 识渊 · 知识深潜 — 市场分析

> 本文件是「概念 21 之后」下一个全新概念的**方向论证与任务书**，与同目录《艺术美学》《任务清单》配套。所有结论服务于一个目标：做出一个**既跳出旧母题、又在真机上交互舒服、且信息可视化优先**的动效概念原型。

## 1. 产品与用户语境
- **产品**：芙洛理桌面客户端，定位考公/考研学习伴侣。核心模块含知识地图、复盘、练考、选岗地图等，需要一个"看得见掌握度"的视觉中枢。
- **用户**：数媒 2026 届（湖南），"先公后研"路线。对视觉创新要求极高，已连续否决多版概念，明确反感"AI 套路 / 换皮 / 彩圆俗套 / 辉光"。
- **审美基线（已沉淀）**：信息可视化优先、实用优先；非大众化；克制零辉光；真实操作驱动、确定可控；落在真实界面；单主色 + 明度层次；细线 / 小几何节点；形态自然边界。

## 2. 痛点与机会
- **主流学习软件的知识呈现**：扁平列表、进度条、2D 思维导图。信息密度低，无"纵深 / 结构"直觉，缺乏空间记忆锚点。
- **用户已否的方向**：纯艺术无信息（弦）、稀疏标量场 + 硬方框（气脉）、方块堆叠 + 时序（层积）、彩圆俗套（共学舱）、点-线-环-星单体（星图/轨道/脉络/学仪/星砂）、抽测计分小游戏感（活字印知）。
- **差异化空白**：市面几乎无"真 3D 知识纵深可视化"。把"基础 → 进阶 → 高阶"的掌握度做成**可连续下潜的 3D 地层**，既有空间直觉又有信息密度，是清晰空白点。

## 3. 为何是"连续下潜"而非"旋转单体"
- 前作识卷用横向长卷，用户反馈：**"段与段距离太长、交互不舒服"** —— 离散大跳距是舒适杀手。
- **连续下潜 = 滚动即平滑纵深位移**，天然连续、无长跳；拖拽只做局部转向，符合"确定可控 ∝ 真实拖速、快收敛"铁律（㉗）。
- 直接破除"屏幕中央放个 3D 物体转一转"的母题锁定（铁律㉙）—— 识渊是**在体积里穿行**，不是转一个对象。

## 4. 可行性
- **原型阶段**：Canvas2D 手动透视投影造 3D（保底不黑屏）；可选 WebGL2 增强地层体积感（着色器编译失败 / 不支持则降级，不崩）。
- **单文件 HTML** 可交付、可无头校验；客户端落地再由 C++/D3D11 实现，方向先验证。
- **性能**：分层薄板 + 有限节点 + 画家算法远→近 + DPR 限制，可控。

## 5. 风险与对策
| 风险 | 对策 |
|---|---|
| 可读性（最高优先级） | 每层配可读标签 + 邻近 2D 浮层读数；纵深只作直觉，不替代数据 |
| 3D 眩晕 | 下潜缓动、转向有界、无强制自动旋转 |
| 性能 | 节点 / 线数量上限 + DPR 限制 + 视锥裁剪 |
| 黑屏 | 无 WebGL 强依赖，Canvas2D 保底；GLSL 双路径校验 |

## 6. 结论
方向可行、差异化强、贴合"信息可视化优先 + 真 3D + 舒适交互 + 允许游戏化探索"的最新诉求，作为概念 21 之后新基线候选。下一步：依《任务清单》逐步造原型，方向经用户确认后再动工。
