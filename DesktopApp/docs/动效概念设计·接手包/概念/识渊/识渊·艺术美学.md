# 识渊 · 知识深潜 — 艺术美学

> 与《市场分析》《任务清单》配套。本文件锁定"识渊"的**美学语言与红线禁区**，确保做出来的东西一眼就"非大众化、克制、有信息"。

## 1. 母题
**连续 3D 分层纵深的"知识地层"**：你在竖直纵深里下潜，每一层（stratum）是一个知识阶（基础 / 进阶 / 高阶），层内与跨层以细连线编织成依赖脉络。不是"一个被旋转的对象"，而是"在一体积里穿行"。

## 2. 形式语言（严守红线）
- **拒绝**：点-线-环-星单体、彩圆俗套、辉光 / bloom、方块堆叠、时序母题、稀疏标量场 + 硬方框。
- **采用**：薄层（stratum sheets，半透明细网格面）+ 细节点（菱形 / 方点，小几何节点）+ 细连线（依赖脉络，线粗 = 关联强度）。
- **高密度离散**：每层布多个细节点 + 连线，形成致密拓扑网，而非空旷场（修正气脉"密度太低"死因）。

## 3. 色彩
- 单主色**墨青**（hsl≈192，低饱和）为基；**明度编码掌握度**（暗 = 未掌握、亮 = 已掌握）。
- **青绿**（accent）仅用于薄弱点 / 激活 / 锁定，克制不泛滥。
- 地层可沿纵深做极微冷暖梯度区分领域，但整体仍单色系、**零辉光**。

## 4. 动效与交互语言
- **连续下潜**：scroll → 纵深位移，平滑缓动（ease），步距连续无长跳（**修正识卷缺点**）。
- **局部转向**：拖拽做轨道转向，∝ 真实拖速、快收敛、有界（铁律㉗）。
- **邻近浮现**：节点进入视野才浮现 2D 浮层读数（掌握度 / 难度 / 前置链 / 薄弱），非 idle 空浮。
- **锁定**：点击节点 → 持久标记 + 展开其前置链高亮，Esc 解除。
- **缩放**：滚轮有界。

## 5. 2D + 3D 融合（集大成）
- **3D**：负责"纵深 / 结构 / 依赖"的空间直觉。
- **2D**：HUD（当前层 / 掌握总览 / 纵深进度）+ 悬停浮层 + 锁定详情，负责精确读数。
- **排版**：层标题用克制衬线，信息层级清晰（延续识卷排版优点）。

## 6. 形态边界
自然——地层填满视锥下方纵深，随下潜淡入淡出，非硬方框截断。

## 7. 参考禁区（明确不做什么）
概念 9 方块堆叠 / 时序、概念 11 稀疏场 + 硬框、活字抽测小游戏感、概念 10–17 点线环星单体、彩圆俗套。

## 8. 本次加码（用户要求"做足 3D、可游戏化"）
- 在 **3D 体积感、地层光照、节点交互**上投入更多资源，原型篇幅较前作更长更精。
- 允许**游戏化探索**（下潜 / 转向 / 锁定 / 追踪前置链），但**不做抽测计分、输赢**那类廉价小游戏感。
- 若用 WebGL2：地层做体积 / 边缘暗化（非亮化），守住零辉光。
