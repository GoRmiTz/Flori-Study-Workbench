- [ ] 1. **方向锁定**：识渊 · 知识深潜，母题 = 连续 3D 分层纵深；本三份文档（市场分析 / 艺术美学 / 任务清单）即任务书。
- [ ] 2. **数据模型**：8 学科 × 3 阶（基础 / 进阶 / 高阶）× 每层若干考点；每点 `{ 掌握度, 难度, 前置[] }`；生成比前作更丰富的样例数据（做足、不简陋）。
- [ ] 3. **3D 场景搭建**：分层薄板沿 Y 纵深排布；节点按（层, 角度）定位；依赖细线连接（同层 + 跨层前置），线粗 = 关联强度。
- [ ] 4. **相机与导航**：连续下潜（scroll → 纵深平滑位移，缓动无长跳）；拖拽轨道转向（∝ 真实拖速、快收敛、有界）；滚轮缩放有界。
- [ ] 5. **交互**：悬停邻近节点 → 2D 浮层读数；点击锁定 → 持久标记 + 前置链高亮；Esc 解除；可选游戏化探索（追踪前置链路径）。
- [ ] 6. **视觉**：单墨青 + 明度编码 + 青绿薄弱标；零辉光；地层自然填充纵深；可选 WebGL2 增强体积感（降级不崩）。
- [ ] 7. **2D 层**：HUD（当前层 / 掌握总览 / 纵深进度）+ 排版（层标题衬线，延续识卷优点）。
- [ ] 8. **性能与健壮**：节点 / 线数量上限、画家算法远→近、DPR 限制；无 WebGL 强依赖保底、无 headless 崩溃、安全无 eval / innerHTML 注入。
- [ ] 9. **校验**：node DOM 桩跑交互（下潜 / 转向 / 悬停 / 锁定 / 缩放）→ `nan=0`、有界、无彩圆、真 3D；若用 GLSL 则双路径（含 nogl 降级）。
- [ ] 10. **交付与归档**：原型 `.html`（做足做精，篇幅较前作更长）；补 `介绍.md` + `开发日志.md`；更新 `AGENTS.md` 全景表与 `02_总开发日志`；请真机确认观感（headless 只证不崩 / 不 NaN / 方向对，观感由真机定）。
