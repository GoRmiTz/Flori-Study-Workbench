# 识渊 · 知识深潜 — 动效概念介绍

> 概念 22。对应《市场分析》《艺术美学》《任务清单》三份规划文档，按「先规划、后造原型」的节奏产出。

## 1. 一句话定调
你不是旋转一个 3D 物体，而是**在一团 3D 知识地层里连续下潜**——滚动即平滑纵深位移，拖拽只在局部转向；悬停读考点，点击锁定并高亮它的前置依赖链。这是「在体积里穿行」，彻底跳出「中心放个东西转一转」的母题锁定。

## 2. 隐喻与落点
- **隐喻**：知识是一座向下延伸的「地层」。越往下越难（基础 → 进阶 → 高阶），每一层是一张知识阶，层内与跨层以细连线编织成依赖脉络。
- **落点**：芙洛理客户端的「知识地图 / 复盘 / 练考」中枢。比扁平列表、思维导图多了一层「纵深 + 结构」的直觉，又保留 2D 面板负责精确读数。

## 3. 信息编码（靠形态与明暗，不靠颜色）
- **单主色墨青**（hsl≈192，低饱和）为基；**明度编码掌握度**（暗=未掌握、亮=已掌握）。
- **青绿**（accent）仅用于薄弱点 / 锁定 / 激活，克制不泛滥。
- 地层沿纵深做极微冷暖梯度区分领域，但整体单色系、**零辉光**。
- 节点=小八面体（小几何节点，非彩圆，铁律㉘）；依赖线细，线粗=关联强度；地层为半透明带网格的薄盘，随下潜淡入淡出。

## 4. 交互语言（集大成：3D + 2D + 排版 + 动效）
- **连续下潜**（主交互）：滚轮 = 纵深平滑位移，lerp 缓动（0.12），**步距连续无长跳**（修正识卷「段距太长」缺点，落实铁律㉛）。
- **局部转向**：拖拽做轨道转向，∝ 真实拖速、惯性快收敛、有界（铁律㉗）。
- **悬停邻近节点**：浮现 2D 浮层读数（掌握度 / 难度 / 薄弱 / 点击提示），非 idle 空浮。
- **点击锁定**：持久标记 + 展开其前置链高亮（青绿），Esc 解除。
- **缩放**：Shift+滚轮 或 +/− 键，有界 [0.6, 2.4]。
- **游戏化探索**（铁律㉜，无计分）：在 3D 结构里「走通知识脉络」——下潜探明各层、追踪某考点的前置依赖链；没有抽测、输赢、排行榜等廉价小游戏感。

## 5. 2D + 3D 融合
- **3D** 负责「纵深 / 结构 / 依赖」的空间直觉；WebGL2 提供真体积感（深度缓冲、Lambert 光照、地层边缘暗化）。
- **2D** 负责精确读数：HUD（当前层 / 掌握总览 / 下潜进度条）+ 悬停浮层 + 锁定详情；层标题用克制衬线延续识卷排版优点。
- **保底**：WebGL2 不可用或着色器编译失败 → 自动降级 Canvas2D（手动透视投影 + 画家算法），**绝不黑屏**。

## 6. 与过往概念的区别（为何算创新）
| 维度 | 旧（10–21） | 识渊（22） |
| --- | --- | --- |
| 主交互 | 旋转一个 2D/3D 物体 | **连续下潜穿行体积** |
| 语法 | 点-线-环-星 / 流带 / 鳞片 / 长卷 | **分层地层 + 细连线 + 八面体节点** |
| 纵深 | 平面或单层 | **真 3D 分层纵深，可连续穿行** |

## 7. 诚实限制
headless 校验只能证明「能渲染、零报错、交互数值对、不黑屏」；**GLSL 是否真机编译通过、地层体积感、下潜手感、节点密度、单墨青配色、3D 浮层观感**必须由你在真实浏览器（Chrome/Edge 直接开本地文件最稳）确认。
