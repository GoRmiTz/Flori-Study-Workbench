# 概念 29 · 墨显·知识显影 · 开发日志

> 日期：2026-08-22
> 作者：动效概念设计接手（GPT 协作）

## 缘起
用户在前档（28 舆图·知识疆域）后说"再开"，要求再开一档**全新不重复**概念。在㉟（拒绝花瓶·买点）与"信息可视化优先 + 真实操作持续驱动 + 确定可控"硬律下，选早先披露的候选之一 **墨显·显影**：母题=暗房显影盘，光标如显影笔扫过才显出知识——既不是轨道结构，也不同于织缕/抽笺/舆图的交互。

## 设计决策
- **买点先于视觉**：介绍文档第一章即写"买点/价值闭环"，每条交互都落进 ReviewEngine/错题集/dashboard，杜绝花瓶。
- **交互范式 = 扫显影 / 点阅卷 / 标掌握**：固定 2D 俯视，无轨道旋转/缩放/飞入聚焦（㉞）。
- **真实操作驱动 + 确定可控**：`reveal` 用确定性 lerp 跟随光标（移近→升、移远→缓隐），无 idle 浮动、不失控（命中用户"真实操作驱动确定可控"铁律）。
- **信息可视化**：显影后拓扑直接可读（大小=重要性、墨浓=掌握、细线=关联）。

## 实现要点（单文件 HTML）
- 主舞台 Canvas2D（透明、自洽），手工 2D 坐标；WebGL2 背景仅受控（淡墨晕纸纹），守卫+失败即隐藏，CSS 纸纹兜底。
- 60 节点（七科确定性簇）+ ~120 关联细线，`mulberry32` 确定性。
- 阅卷卡用 HTML overlay（文字清晰），按钮标已会/待巩固直接改 Set + today 计数。
- KPI 顶栏实时刷新（已显影/覆盖率/待巩固/今日）。
- 暴露 `window.__api`（onMove/onClick/onKey/pump/openNodeById/markKnown/markWeak/getProbe）供无头探针。

## 修复的 bug
1. **初始 `resize()` 未调用** → `W/H=0`、全屏 0 尺寸。修正：循环启动前显式 `resize()`。
2. **`requestAnimationFrame` 在 headless 桩里未守卫** → 桩内未定义会抛。修正：守卫 `typeof requestAnimationFrame==='function'`。
3. 彩色圆检测：drawNode 把每个节点的实际填充色压入 `lastNodeFills`，探针 `classifyFill` 校验仅墨灰/青绿通过，彩色=0（真实运行时校验，非装饰）。

## 校验
- `node --check` → SYNTAX_OK。
- **双模式 DOM 桩无头探针**（`_probe.js`，WebGL 可用 / **WebGL=null**）：均 **16/16 PASS**——init 不抛/ready、onScreen>0、nan=false、lightBg=true、develop.devCount+、card.open、markKnown(known+1/cov+/today+1/cardClosed)、markWeak(pending+1)、esc.close、跑帧后仍 nan=false&devCount>0、colorfulCircles=0。
- **关键**：WebGL 完全缺失（null）时主舞台仍完整渲染全部节点、零 NaN、亮底、无彩圆 → 黑屏死因结构性消除。

## 诚实限制
headless 证逻辑不崩/在屏/无NaN/亮底/无彩圆/显影-阅卷-计数数值对；**显影笔观感、墨色浓淡层次、知识拓扑疏密、阅卷卡排版、亮纸配色协调度须真机确认**。
