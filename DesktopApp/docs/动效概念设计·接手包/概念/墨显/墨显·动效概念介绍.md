# 概念 29 · 墨显·知识显影

> 动效概念设计 · 接手包 · 概念 29
> 母题：暗房显影盘（光标如显影笔，扫过处知识自淡墨显出）
> 状态：🟡 待真机评审

---

## 一、买点 / 价值闭环（先于视觉，回应铁律㉟）

之前的概念被批"像无用的花瓶"——好看但说不清**怎么落进真实软件、凭什么是买点**。本概念把"买点"写在第一章，且每一处交互都直接产出学习价值：

1. **钩子 = 显影的动态仪式感**：所有知识本为淡墨潜藏，你移动光标如"显影笔"扫过，知识才自淡墨显成浓墨。这是**真实操作持续驱动**的确定性显影（你移才显、移走缓隐），不是预设循环动画，也不是 idle 乱飞——正好命中你"真实操作驱动 / 确定可控"的硬律。
2. **学习价值 = 主动浏览回忆**：显影的过程就是一次**主动扫描/回忆复习**——知识拓扑（节点 + 细线关联）随光标实时"长"出来，你边看边在脑中复述。
3. **直接产出 = 阅卷打标**：点已显节点 → 弹出该考点（标题 + 精讲 + 主动回忆提问）→ 标「已会 ✔ / 待巩固 ↺」。
4. **软件落点（写实，非展示）**：
   - 节点数据 = **F-D 练考模块 `QuizParser` 产出的题目 `.md`** 分域簇（公考七科，确定性布局）；
   - 标「已会」→ 写入 **ReviewEngine 复盘**；标「待巩固」→ 进**错题集**；
   - 顶部 KPI「已显影 N/共 M、覆盖率 %、待巩固、今日」→ 接 **dashboard 进度可视化**（成就感非计分，落实㉜）。
5. **信息可视化优先**（你头号优先级）：显影后的**知识拓扑直接可读**——节点大小=重要性、墨色浓度=掌握度（掌握=浓墨、薄弱=淡灰+青绿描边）、细线=关联；扫过即见"哪片密、哪片空"，不像装饰花瓶。

**一句话买点**：把"随机抽卡复习"换成"亲手把整张知识地图显影出来"——既是浏览回忆的复习钩子，又是覆盖率可视化的进度成就，且每次操作都落进复盘/错题集。

---

## 二、母题与交互范式（刻意不重复 + 落实㉞）

- **母题 = 暗房显影盘**：知识是一张潜藏的墨稿，显影笔（光标）所及才显形。区别于浮岛(识墟)/下潜(识渊)/平衡(识悬)/桁架(识构)/织机(织缕)/签筒(抽笺)/舆图(舆图)——**没有任何"观察一座 3D 结构"的影子**。
- **核心循环 = 扫显影 / 点阅卷 / 标掌握**：
  - **扫**：光标扫过 → 半径内节点 `reveal` 升向 1（确定性 lerp），关联细线随之显出；移开后缓隐回淡墨潜藏（不丢已显记忆，reveal 已>0.55 的节点保持显形）。
  - **点**：点已显节点 → 阅卷卡（考点名 + 精讲 + 主动回忆提问）。
  - **标**：已会 / 待巩固 → 落库 + 计数。
- **范式自检（㉞ 禁轨道观察）**：固定俯视 2D 取景，**无拖拽轨道旋转、无滚轮缩放、无飞入聚焦**；交互是"光标扫显影 + 点击阅卷"，属于"对平面施加真实操作"，非"环视结构"。

---

## 三、视觉与红线（落实㉛㉜㉝㉞ + ㉘线条主导）

- **亮色背景**：暖白纸 `#F6F2E9`（CSS 径向纸纹兜底），非暗底。
- **墨线主导 / 无彩圆**：节点为**小菱形**（墨色浓度=掌握度、薄弱=淡灰填充+青绿描边），关联为**细线**（线粗=重要性×显影度）；唯一彩色 = 青绿 `#268678`，仅用于薄弱描边 / 显影笔淡晕 / 按钮。无填充彩圆、无辉光、无 bloom（㉘）。
- **零失控**：显影是确定性 lerp（跟随光标，不自己乱跑），无 idle 浮动。
- **WebGL2 仅作受控背景**：淡墨晕纸纹（失败即 `display:none`，CSS 纸纹兜底），**结构上不可能黑屏**。

---

## 四、数据规模

- 60 个知识节点（公考七科，每科约 8–9 个确定性考点），~120 条关联细线（科内成环 + 跨科近邻）；`mulberry32(20260822)` 确定性，每次打开布局一致、可复现。

---

## 五、诚实限制

headless 校验只证了"不崩 / 在屏 / 无 NaN / 亮底 / 无彩圆 / 显影→阅卷→计数数值对"。**显影笔的观感、墨色浓淡层次、知识拓扑疏密、阅卷卡排版、亮纸配色协调度**这类观感，须你在真实浏览器（Chrome/Edge 开本地文件）确认。
