# 识潮 · 知识洋流 · 动效概念介绍（概念 18）

> 母题锁定破局之作。承接用户「方向被固定住了、全是老元素」的论断——概念 10/12/13/14/16/17 虽母题各异，却共用「点-线-环-星」2D 语法。本概念依据新立铁律 **㉙ 突破母题锁定 + ㉚ 强制 3D 交互探索**，改用**真三维流带 + 二维浮层**的全新空间语法，且与所有已通过方向形态显著不同。

## 一、隐喻与落点
把「知识体系」隐喻为一团在三维空间里持续流动的**洋流**：每条流带 = 一个学科的知识流，整团洋流在你面前缓缓涌动、彼此缠绕。

- **真实落点**：芙洛理的「练考 / 知识库 / 自习室」等板块都可用「学科洋流」总览——一眼看出哪条学科流的掌握度饱满（流带明亮厚实）、哪条薄弱（流带黯淡、露出小菱形薄弱点）。
- **界面**：mock 真实 chrome（顶栏 brand + 概念 tab + 头像），让落点一目了然（铁律⑦）。

## 二、信息编码（信息可视化优先 · 铁律⑤）
- **学科** → 每条流带一个**类比色族**（墨青→青→蓝→紫，单主色系内的克制色相，非彩虹撞色；铁律⑫ + 数据着色豁免⑰）。
- **掌握度** → 流带整体**明度/不透明度**（掌握越高越明亮厚实，越低越黯淡；零辉光，铁律④）。
- **考点密度** → 流带本身由 150 个采样点构成，整团 32 条流带致密填充球形体积（高密度离散，破气脉「稀疏大而空」死因；铁律⑮）。
- **薄弱点** → 掌握度 <50 的采样点，在**悬停 / 锁定**该流带时显形为**小菱形**（单一强调色，非彩圆；铁律㉘）。
- **顶栏 KPI**：考点总数 / 学科 / 平均掌握 / 薄弱段 / 洋流数，全局读数一眼可得。

## 三、动效语言（真实操作驱动 · 确定可控 · 非游戏 · 铁律⑥㉚）
- **真三维轨道旋转**：四元数 trackball 实现 360° 拖拽旋转，**「拖哪跟哪」**（屏幕空间轴预乘，转到任意角度都不反转；铁律㉗ 同款稳健方案）。
- **惯性**：松手后惯性角速度来自真实拖速、封顶、快速收敛（∝拖速，非固定角速度暴冲）。
- **缩放**：滚轮在 [0.6, 2.4] 有界缩放。
- **流动光包**：每条流带上有沿曲线行进的亮段，速度=该学科活跃度——这是**数据驱动的真实动力学**，不是 idle 空浮；确定可控、不失控乱跑。
- **二维浮层协同**：悬停某流带 → 右侧面板读出该学科掌握度 / 薄弱点 / 考点流段数 + 掌握度分布小柱图；点击 → 锁定该洋流持续高亮。3D 负责空间直觉，2D 负责精确读数（铁律㉚）。

## 四、红线落实自检
- ✅ 创新第一、非大众化（彻底跳出点-线-环-星；真 3D 流场）。
- ✅ 信息可视化优先（学科/掌握度/薄弱点/密度全部可读）。
- ✅ 现代、克制、零辉光（类比色族、无加性光球）。
- ✅ 真实操作驱动、确定可控、非游戏。
- ✅ 落真实界面（mock chrome）。
- ✅ 高密度离散、自然球形边界（无硬长方形截断，铁律⑯）。
- ✅ 突破母题锁定（㉙）+ 强制 3D 交互（㉚）。

## 五、诚实限制
headless 仅能验证「能渲染 / 零报错 / 交互数值对」（已用 DOM 桩跑通 init + 真实拖拽 + 滚轮 + 惯性多帧，断言 nan=0、zoom 有界、has3D=true、无彩圆）。**动态观感（流带美感、旋转手感、配色协调度）须用户在真实浏览器（Chrome/Edge 直接开本地文件）确认**。
