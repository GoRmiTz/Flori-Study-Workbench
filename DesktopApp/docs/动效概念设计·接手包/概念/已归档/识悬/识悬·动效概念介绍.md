# 识悬 · 知识悬衡 · 动效概念介绍

> 概念 24（2026-08-17 深夜）。承接用户两条指令：① 把识墟「聚焦飞入」写成创新点（已完成，见 `识墟·创新点·聚焦飞入.md`）；② 开一个**与以往「在 3D 空间里穿行/旋转」范式彻底不同**的全新概念。

## 1. 母题：动态平衡雕塑（而非「观察一个 3D 结构」）

以往概念（洋流 / 鳞甲 / 凝核 / 深潜 / 浮城）的主交互都是「在固定原点周围观察 / 穿行一个 3D 物体或空间」。识悬换了一个**根本不同的物理隐喻**：

- 一座 **3D 悬垂平衡装置**（Calder 动态雕塑式）：顶部一根悬丝垂下中央枢纽，4 条主臂从枢纽放射，每条臂两端各挂一块学科牌（共 8 牌）。
- 每块牌有一个**权重** = 重要性 ×（1 − 掌握度）×（1 − 0.8 × 学时分配）。掌握越低、分配越少 → 越重 → 悬得越低；臂倾角由两端**权重差**驱动。
- 整个装置有**确定性微摆**（有界正弦，非 idle 乱飞），各处角度用弹簧缓动趋近平衡。

这不再是「你绕着看」，而是「**一个会随你的操作而重新平衡的系统**」。

## 2. 核心交互：拖拽挂牌 = 重新分配学时（真实操作驱动）

- **拖拽一块学科牌上下** → 改变它的「学时分配」：上拖 = 加学时 = 变轻；下拖 = 减学时 = 变重。
- 系统**确定性重平衡**：该臂倾角随两端新权重差弹簧缓动，其他臂若牵连也一并调整。你看得到「我把时间加给薄弱学科 → 它升起、整体趋向平衡」。
- 这是铁律㉜ 允许的「游戏化探索」但**非廉价小游戏**：没有计分/输赢，乐趣来自「亲手把知识天平调平」的 tactile 反馈。

## 3. 2D + 3D 融合与信息可视化

- **3D 主舞台**：透视投影的悬衡装置，线条主导（悬丝/臂/垂丝），挂牌为小圆角矩形（墨青单色、明度=掌握度、薄弱牌青绿描边），零辉光、无彩圆。
- **2D 浮层（悬停）**：衬线排版读出学科 / 掌握度 / 学时分配 / 稳固或薄弱 / 权重。
- **2D HUD（顶部）**：标题 + 「失衡度」（各臂倾角绝对值之和，直观显示整体是否平衡）+ 已调节学科数；锁定时显示聚焦学科与权重。
- 顶栏 mock 真实界面 chrome（知识库/练考/复盘/识悬），落点一目了然。

## 4. 复用创新点：聚焦飞入

点击任一学科牌 → 相机轨道中心 `cam.tTarget` 平滑迁移到该牌并拉近（lerp 0.10，无长跳），之后拖拽即绕该牌旋转——直接复用 `识墟·创新点·聚焦飞入.md` 的契约。Esc 复位。

## 5. 技术底座（根除黑屏）

- **单 canvas 纯 Canvas2D**：手动透视投影伪造 3D + 深度排序 + 轨道相机。无 WebGL / 无多 canvas，彻底规避识渊(22)「WebGL2 降级取 2d 得 null 崩溃全黑」的覆辙。
- 确定性随机 `mulberry32`，可复现。

## 6. 红线落实

突破母题锁定(㉙) · 真三维轨道交互 + 二维浮层(㉚) · 交互舒服无长跳(㉛，lerp 缓动) · 游戏化探索禁廉价小游戏感(㉜) · 信息可视化优先 · 线条主导+小几何节点 · 单墨青克制零辉光 · 无彩圆。

## 7. 诚实限制

headless 证逻辑不崩 / 8 牌全在屏 / 拖拽改分配生效 / 点击聚焦命中 / Esc 复位 / 无 NaN；**装置疏密、微摆幅度、拖拽手感、配色协调、衬线排版观感须用户在真实浏览器确认**。
