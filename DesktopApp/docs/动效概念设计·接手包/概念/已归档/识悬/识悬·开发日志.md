### 实现要点
1. **数据模型**：8 学科，每学科 {mastery, importance, alloc(学时分配 0..1)}；权重 `w = imp·(1−mastery)·(1−0.8·alloc)`。
2. **运动学（每帧 updateKin）**：4 主臂从枢纽 O 放射，臂倾角由两端权重差弹簧缓动 `tilt += (tTilt−tilt)*0.08`，`tTilt=clamp(0.55·(wL−wR), ±0.5)`；挂牌从臂端下垂 `DROP`，叠加确定性微摆（有界正弦 `0.16·sin + 0.05·sin`，非 idle 乱飞）。
3. **相机**：复用识墟三段式（`target`+yaw/pitch+dist），透视投影 `project()`；聚焦飞入复用创新点（点击牌→`tTarget=牌位置`且 `tDist*0.6`，lerp 0.10 无长跳）。
4. **交互**：`pointerdown` 拾牌→`pointermove` 上拖改 `alloc`（−dy·0.0035，上拖=加时=变轻）→ 系统重平衡；悬停衬线浮层；点击聚焦该臂；Esc 复位 alloc 与相机。HUD 显示「失衡度」=Σ|tilt| + 已调节数。
5. **视觉**：线条主导（悬丝/臂/垂丝）+ 圆角矩形小牌（墨青单色、明度=掌握度、薄弱青绿描边），零辉光、无彩圆；牌上衬线首字。
