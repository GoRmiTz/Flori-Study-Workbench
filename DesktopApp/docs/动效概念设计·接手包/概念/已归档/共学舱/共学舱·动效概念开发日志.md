# 概念 15 · 共学舱（CoAtrium）· 动效概念开发日志

## 概念 15 · 共学舱 v1.0（2026-08-16 深夜，全新概念原型 · 非学科板块）
- **缘起（用户明确要求）**：用户"今天看到轨道是最好的概念设计"，要求①写思考过程补全开发日志、②修轨道拖拽跳跃、③**不要总盯着学科板块**，去查软件文档里自习室/专栏/知识库等板块的创新点并做概念设计。
- **查文档找创新点**：读 `P2-1桌面自习室需求验证方案.md`、`功能缺口与优化清单.md`、`架构速记.md`。确认：自习室（RoomView）是**在场可视化最弱**的板块，真实信号有 presence 在场 / 专注状态(专注中·休息·离开) / 专注时长 / 共享音乐 / 聊天，且已知缺口（中文输入、BGM 后端未接）。这些全是**事件驱动**数据，最适合"氛围+信息可读"动效。专栏偏内容流、知识库与考点重叠 → **优先做自习室**。
- **选定母题 · 共学舱**：自习室 = 圆形共学中庭，中心舱核(共享氛围) + 在场同学稳定席位围坐。非星图/星砂/晶簇/轨道，是**围坐式在场图谱**，强调"有人陪你学"的临场感。
- **信息编码（信息可视化优先）**：光圈大小=今日专注分钟、色相=学科(三通道着色豁免)、明度/稳定度=状态(专注稳定亮/休息呼吸/离开虚化)、中心舱核=在场人数+总专注；顶部 KPI + 悬停精确面板。
- **动效（真实操作驱动/确定可控/非游戏/零辉光）**：实时在场事件驱动(进房弹簧绽放/离房淡出/状态脉冲)、聊天涟漪(确定性阻尼)、舱核呼吸(亮度调制非辉光)、悬停高亮+面板、单击聚焦共学(连线舱核+压暗其余)、状态筛选 chips、静置自动演示(交互即停)。Canvas2D + 亮色纸感(无WebGL黑屏)。
- **实现要点**：席位角度用**均匀分位 + 极小抖动**(`i*2π/N + (rnd-0.5)*0.12`)，保证稳定不跳位且**永不错位重叠**（首版曾误用黄金角+大抖动，minGap 仅 0.036rad≈2°，席位严重重叠；修正后 minGap 0.389rad、最小弧长 93px > 最大直径 58px）。入场用 scale 弹簧(0→1 收敛)。确定性 mulberry32 种子。
- **校验**：`node --check` SYNTAX_OK；席位角度确定性稳定、不重叠(93>58)；状态编码合法；安全无 eval/`innerHTML` 注入。
- **红线**：仅新增 `概念/共学舱/` 三件套（`共学舱·动效概念原型.html`+`介绍.md`+`开发日志.md`）；未碰看板娘层/App.cpp/TopBar.cpp/Store.*；未 `git add -A`。
- **诚实限制**：headless 证零报错/无NaN/席位不重叠/状态编码合法，**判不了审美**——待用户真机确认：圆形中庭观感、光圈=专注的可读性、聊天涟漪/呼吸/共学连线是否好看且不过度、与轨道(概念14)的节奏差异是否舒服。
- **待评审**：方向是否认可？认可则小幅打磨（席位疏密、呼吸幅度、涟漪速度、配色冷暖、是否加"邀请好友虚位"）。若否，按铁律优先回退概念10/12/14 基线而非在错母题打补丁。

## 概念 15 · 共学舱 CoAtrium（❌ 用户否决 · 已归档）
- 日期：2026-08-17 凌晨
- **用户否决原因（原话）**：「普通的圆形并不好看，特别是彩色填充的圆形，五颜六色的非常的丑……现在的做的这个概念设计相当不好看，没有线条的参与，只有光溜溜的彩圆，很俗套不好看。放弃这个概念设计。」
- **根因**：母题天然是"人=圆"，实现成一大堆**彩色实心圆 + 舱核大圆 + 光圈**，且**几乎无线条**（只有细连线但被大圆盖过），正好是用户最反感的"光溜溜的彩圆"俗套形态。
- **处置**：按用户要求**放弃、不在其基础上修改**，归档至 `概念/已归档/共学舱/`。此方向定为**负面对照教材**写入 AGENTS.md §2.1/§2.3。
- **沉淀为铁律**：后续一切概念设计**严禁彩色填充大圆/彩圆堆砌**；构图必须以**线条/细结构**为主，节点用**小几何标记（菱形/方/短刻）**而非实心圆；配色克制（单主色或至多一个强调色），拒绝五颜六色。此条写入 `用户审美偏好与动效铁律.md`（新增铁律㉘）。
