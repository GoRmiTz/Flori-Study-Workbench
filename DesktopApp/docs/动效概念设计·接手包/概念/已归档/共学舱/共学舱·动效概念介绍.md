# 概念 15 · 共学舱（CoAtrium）· 动效概念介绍

> 模块落点：**芙洛理 · 自习室（RoomView 实时在场）** —— 这是用户明确点名、且动效创新空间最大的非学科板块。

## 缘起
用户要求"不用总盯着学科板块做概念设计，去软件文档里找自习室/专栏/知识库等板块的创新点"。
查 `P2-1桌面自习室需求验证方案.md` 与 `功能缺口与优化清单.md` 后确认：自习室是当前**在场可视化最弱、且已知有中文输入 / BGM 后端缺口**的板块，其真实数据信号（presence 在场、专注状态、专注时长、共享音乐、聊天）全是**事件驱动**的，天然适合"氛围 + 信息可读"的动效概念。专栏偏内容流、知识库与考点重叠，故优先做**自习室**。

## 母题：圆形共学中庭
把自习室画成一座**圆形共学中庭**——中心是"舱核"（共享氛围 / 当前在场人数），在场同学各自占一个**稳定席位**围坐一圈。不是星图拓扑网、不是星砂点云、不是晶簇晶体、也不是轨道壳层，而是**围坐式在场图谱**：强调"有人陪你一起学"的临场感。

## 信息编码（信息可视化优先 · 图表本体先于动效）
- **光圈大小 = 今日专注分钟**（几何大小区分维度，不靠撞色）；
- **色相 = 学科**（复用概念 12 三通道数据着色豁免，和谐色相族）；
- **明度 / 稳定度 = 当前状态**：专注中（稳定亮）· 休息（缓慢呼吸）· 离开（虚化淡）；
- **中心舱核**：在场人数 + 今日总专注；
- 顶部 **KPI**（在场 / 平均今日专注 / 今日总专注 / 自习室占比）+ 悬停精确面板（昵称 / 学科 / 今日专注 / 状态 / 连续到房 / 在房时长）。

## 动效（真实操作驱动 / 确定可控 / 非游戏 / 零辉光）
- **实时在场事件驱动**：有人进房 → 席位弹簧绽放（scale 0→1 收敛）；离开 → 淡出；状态切换 → 脉冲。
- **聊天涟漪**：模拟聊天消息从发言人席位发出一圈阻尼涟漪（确定性、普通 alpha，非辉光粒子）。
- **共享氛围**：舱核缓慢呼吸（亮度调制，非加性辉光）。
- **悬停** → 高亮席位 + 精确面板；**单击** → 聚焦"共学"（该席位连线至舱核、其余压暗）。
- **状态筛选 chips**：全部 / 专注中 / 休息。
- **静置自动演示**：模拟在场动态（进出 / 状态 / 聊天涟漪），交互即停。
- Canvas2D 主舞台 + 亮色纸感径向渐变（无 WebGL 黑屏风险）；席位角度**确定性均匀分位**，稳定不跳位、永不错位重叠。

## 校验
- `node --check` SYNTAX_OK；席位角度确定性稳定、最小弧长 93px > 最大席位直径 58px（不重叠）；状态编码合法；`window.__probe()` 回传 {peers,on,nan,seatStable,radiusBounded}。
- 安全扫描：无 `eval` / 未信任注入。
