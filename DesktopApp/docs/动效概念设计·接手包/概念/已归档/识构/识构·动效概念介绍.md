# 概念 25 · 识构 · 知识桁架（Knowledge Truss）

> 落点：芙洛理 · 识构页（mock 顶栏 tabs：知识库 / 练考 / 复盘 / 识构 + 头像；顶部 KPI；右侧图例）。
> 母题：**3D 空间桁架 / 网架结构**——知识=一张被撑开的整体骨架，而非散落岛屿或旋转单体。

---

## 一、隐喻与落点

考公 / 考研的知识体系，被画成一座**三维空间桁架（space-frame lattice）**：

- **节点（joint）= 考点**，每个学科成一簇局部晶格，再被跨簇斜撑编织成**一张整体连通的网架**；
- **杆件（member）= 知识点之间的关联 / 依赖**，细线相连，粗细有界；
- 整座桁架在你眼前悬于亮色纸面之上，可 360° 轨道观察、可俯冲聚焦某一点、可被"点亮"加固。

区别于既往：识墟是**散布浮岛**、识渊是**分层下潜**、识悬是**悬垂平衡雕塑**——本概念是**被刚性杆件连成一体的连通结构**，视觉语言是「骨架 / 网格 / 工程图纸」，而非「点团 / 流带 / 悬挂」。

## 二、信息可视化（先于动效 · 铁律⑤）

| 编码维度 | 视觉映射 |
| --- | --- |
| 学科 | 空间簇位置（8 簇沿球面分布）+ 面板文字，**不靠颜色区分**（刻意克制，呼应铁律⑫⑰） |
| 分值权重 | 节点几何大小（2.6 + 分值×0.7 px） |
| **掌握度** | **墨色浓度**（亮纸翻转暗底逻辑：已掌握=浓墨深、薄弱=淡墨；薄弱再描青绿边） |
| 关联 / 依赖 | 细线杆件（簇内实线，跨簇斜撑虚线，线粗有界） |
| 整体状态 | 顶部 KPI：节点总数 / 已掌握 / 掌握率% / 薄弱数 / 杆件数 |

悬停任意节点 → 右侧精确面板（学科 / 分值 / 掌握度% / 关联杆件数 / 状态标签），一眼读出知识薄弱簇。

## 三、动效语言（真实操作驱动 · 确定可控 · 非游戏 · 零辉光）

- **拖拽**：轨道旋转（yaw/pitch 经四元数式分解，拖哪跟哪，无反转），释放后惯性 ∝ 真实拖速、封顶快速收敛（吸取轨道 v1.1 教训，铁律㉗）；
- **滚轮**：围绕视野中心缩放，有界 [0.6, 2.4]；
- **悬停**：高亮该节点 + 其关联杆件（青绿）+ 精确面板；
- **单击节点**：点亮（掌握度 0→1 弹簧收敛，墨色由淡转浓）+ **相机平滑飞入该节点**（复用《识墟·创新点·聚焦飞入》契约，lerp 0.10 无瞬移无长跳）；
- **右键节点**：取消掌握 + 飞入；
- **Esc**：相机复位回整体（飞回原点、拉远）；
- **静置 3s**：缓慢自转自动演示，任一交互即停（演示动效，非 idle 空浮）；
- 顶部 KPI 实时刷新。

## 四、视觉红线落实（亮色背景 · 铁律㉝）

- **亮色暖白纸底**（CSS 纸纹 + WebGL2 受控背景双层兜底），墨线 / 墨色元素主导——「墨落于纸」；
- 配色随之翻转：暗底「明度=掌握度」改为亮纸「墨色浓度=掌握度」，零辉光零 bloom 不变；
- **线条主导、无彩圆**（铁律㉘）：结构是纯细线杆件 + 小几何节点（八面体剪影），绝无光溜溜彩色实心圆；
- 单一墨青 + 青绿薄弱强调，克制和谐。

## 五、技术架构（根除识渊式黑屏 · 铁律㉛与 §7 例外口径）

- **主舞台 = 单 canvas 纯 Canvas2D**：透明底，手动透视投影伪造 3D（根除 WebGL 黑屏风险），绘制桁架细线 + 几何节点；
- **背景 = WebGL2 仅作受控背景层**：fragment shader 渲暖白纸 + 极淡墨晕 + 蓝图细网格（呼应"工程图纸"语境）。**编译 / 链接守卫 + 失败即 `display:none`**，亮纸由 CSS 兜底——即使着色器整段失败也只是少了纹理，**绝不黑屏**；
- 该架构是 AGENTS §4 所允「WebGL 仅作受控背景」的落地，与识渊「WebGL 作主渲染 + canvas2d 降级取空上下文崩溃」有本质区别。
