## 架构决策（关键 · 根除黑屏）
- **主舞台 = 单 canvas 纯 Canvas2D**（透明底，手动透视投影伪造 3D）——承担全部交互与绘制，不依赖 WebGL。
- **背景 = WebGL2 仅作受控背景层**：暖白纸 + 极淡墨晕 + 蓝图细网格 fragment shader；编译/链接守卫 + 失败即 `display:none`，CSS 纸纹兜底。**识渊(22)死因（降级从 webgl canvas 取 2d 得 null 崩溃）在此被结构消除**——主舞台永远自洽，WebGL 仅是装饰层。

## 数据模型
- 8 学科 × 18 节点 = **144 节点**；每簇局部晶格（3×3×3 取 18，确定性 mulberry32 seed 20260818）+ 簇内最近邻连边 + 跨簇斜撑（i→i+1、i→i+3）编成一体网架，**约 300+ 杆件**。
- 编码：节点大小=分值、墨色浓度=掌握度、青绿描边=薄弱；杆件细线（跨簇虚线）。
