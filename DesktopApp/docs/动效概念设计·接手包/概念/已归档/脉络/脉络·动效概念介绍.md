# 脉络 Lineage · 知识库动效概念（概念 16）

> 非学科板块概念设计 · 针对「知识库」模块 · 线条主导、零彩色实心圆

## 这是什么
把知识库画成一张**细线知识网**：每一条保存的笔记/文章/素材是一个**小菱形几何节点**，节点之间用**细线脉络**相连，线的粗细 = 关联强度。整体像一张亲手绘制的知识地图——**全是线，没有一块彩色实心圆**。

## 为什么是这个形态（避坑）
上一版「共学舱」被否，根因是堆了一堆**彩色填充圆**，光溜溜、俗套。本概念严格反向设计：
- **节点 = 菱形几何标记**（旋转方块），描边 + 近单色填充，**不是圆、更不是彩色圆**。
- **构图以线条为骨架**：脉络连线 + 背景细网格，空白处也有线，绝不空。
- **配色克制**：全局单墨青主色 + 至多一个青绿强调色（仅用于核心节点与高亮），**拒绝五颜六色**。
- **数据用明度/线宽/位置编码**，不靠颜色堆砌（域用位置排布区分，不用彩色区分）。

## 信息编码（信息可视化优先）
| 视觉通道 | 含义 |
| --- | --- |
| 节点大小（菱形边长） | 条目重要度 |
| 节点填充明度（灰阶） | 掌握度（浅=生疏，深=熟） |
| 节点描边/内点 | 核心节点用青绿强调 |
| 线粗细 | 关联强度 |
| 节点位置（簇） | 所属知识域（8 域沿大圆排布） |
| 虚线圆环 + 标签 | 知识域边界与名称 |

## 交互（真实操作驱动 / 确定可控 / 非游戏 / 零辉光）
- **拖拽** 平移地图；**滚轮** 缩放（有界 [0.5, 2.6]）。
- **悬停** 节点 → 高亮其全部脉络连线（变青绿）+ 准星环 + 精确面板（域/关联数/掌握度/最近温习）。
- **单击** 节点 → 聚焦该节点的知识子图（其余淡出，连线高亮）；**单击空白**退出聚焦。
- **顶栏筛选**：全部 / 仅核心。
- **入场动画**：脉络以线描方式逐根画出（dash-offset 揭示），节点缩放进场——是"画线"不是"弹圆"。
- 静置时无任何空浮动；平移带阻尼惯性，松手即停（吸取轨道惯性教训，∝拖速、封顶、快收敛）。

## 技术
单文件 HTML + Canvas2D + 暖纸亮色主题（无 WebGL 黑屏风险）。确定性 `mulberry32` 布局，刷新一致。`window.__probe()` 暴露节点数/连线数/NaN/缩放有界/无彩圆标记供回归。
