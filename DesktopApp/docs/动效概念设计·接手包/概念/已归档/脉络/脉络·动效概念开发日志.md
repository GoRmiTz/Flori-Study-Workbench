# 脉络 Lineage · 动效概念开发日志（概念 16）

## 概念 16 · 脉络 Lineage（全新概念原型 · 非学科·知识库 · 待评审）
- 日期：2026-08-17 凌晨
- **缘起**：用户否决「共学舱」（原话：「普通的圆形并不好看，特别是彩色填充的圆形，五颜六色的非常的丑……没有线条的参与，只有光溜溜的彩圆，很俗套不好看。放弃这个概念设计」）。要求开**全新**原型，并明确**不在错误上修改**。

### 选型思考（怎么避开被否的坑）
1. **先排雷**：共学舱之死 = 彩色实心圆 + 无线条。新概念必须满足三条硬约束：**节点非圆（小几何标记）/ 构图以线条为骨架 / 配色克制（单主色+至多一个强调色）**。
2. **不盯学科**：延续用户上轮提醒，选**知识库**模块（非考点/非自习室）。知识库天然是"条目 + 关联"的网络结构，最适合用**线**表达，且不会诱导出圆形。
3. **形态决策**：不用力导向随机点云（易像星砂/星图），而用**2D 平面知识地图**——域沿大圆排布成簇、簇内条目螺旋散布、簇间少量桥。读起来像"亲手画的知识地图"，**线条主导**。
4. **与已认可基线关系**：借鉴概念 10（细线拓扑网 + 单主色 + 明度编码 + 悬停面板）与概念 14（菱形几何节点 + 线条 + 单强调色）的精神，但**换模块、换形态**（平面图 vs 原子轨道），不复制形态。

### 信息编码
- 节点大小=重要度；节点填充明度(灰阶)=掌握度；核心节点=青绿强调(单色)；线粗=关联强度；位置簇=知识域；虚线圆环+标签=域边界。
- **刻意不用彩色区分域**——域靠位置排布区分，配色全程单墨青 + 单一青绿强调，从根本上杜绝"五颜六色"。

### 实现要点（确定性技术）
- Canvas2D + 暖纸亮色径向渐变背景 + **细网格线**（空白处也有线，强化"线条主导"）。
- 确定性 `mulberry32(20260817)` 布局；域中心沿大圆 `d*2π/8` 排布，域内角螺旋 `k*2.39996` + 抖动。
- 节点渲染：**菱形**（旋转方块）`moveTo(0,-r)→(r,0)→(0,r)→(-r,0)`，描边 + 近单色填充 `hsl(168,8%,L%)`（8% 饱和≈灰绿，非彩色）；核心节点内嵌小青绿菱形。
- 连线：`lineWidth=0.5+strength*1.4`，`rgba(38,54,51,a)` 细线；悬停/聚焦变青绿加粗。
- **入场线描**：每根线 `setLineDash([len,len])` + `lineDashOffset=len*(1-te)` 逐根画出（easeIO），是"画线"不是"弹圆"。
- 交互：拖拽平移 + 阻尼惯性(`dragV*0.86`，∝真实拖速、封顶、快收敛，吸取轨道教训)；滚轮缩放有界 `[0.5,2.6]` 围绕光标；悬停命中最近菱形(<13px)；单击节点聚焦子图、空白退出；顶栏 全部/仅核心 筛选。

### 校验
- `node --check` → SYNTAX_OK。
- 独立复刻布局：节点 **79**、连线 **102**、**NaN=0**、节点半径 **4.7~7.7px（小几何标记,非大圆）**、域 8、核心 8。
- 安全/配色扫描：无 `eval`/`new Function`；无高饱和彩色填充；无大半径 `arc` 实心圆 → **确认零彩色填充圆**。
- `__probe` 返回 `colorfulFilledCircles:false`、网格标记 `hasGrid:true`、缩放有界。
