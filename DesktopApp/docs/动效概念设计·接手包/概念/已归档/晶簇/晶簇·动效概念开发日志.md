## 概念 13 · 晶簇 v1.1（2026-08-16 晚，用户实测反馈迭代）
- 用户反馈 3 点：① 软件主色为亮色，需要**亮/暗双主题**；② 拖拽旋转**方向错乱**（有时左拖却右转、上拖却下转）；③ 动效/粒子需**更丰富**。
- **修复② 旋转方向（根因）**：旧版用 yaw/pitch 绕**世界固定轴**旋转，当标本转到背面时，世界轴与视觉朝向相反，导致"有时反向"。改 **四元数 trackball**：拖拽轴 = (dy, dx, 0)，增量四元数前置乘（`q = qMul(dq, q)`），旋转定义在**屏幕空间**，无论标本朝向如何都"拖哪跟哪"，彻底消除偶发反向。加**旋转惯性**（释放后按记录角速度 `spinAng*=0.90` 落座，约 1s 收敛）。
- **新增① 双主题**：JS `THEMES{dark,light}` + 顶栏 `暗/亮` 切换按钮 + `body.light` CSS 覆盖；画布背景/晶面/棱线/面板/图例全随主题。亮底下掌握度编码反转（未掌握=淡、已掌握=深艳），与暗底（暗→亮）对称。
- **丰富③ 粒子与动效**（全部确定可控、零辉光、主题感知）：① 掌握时**晶体火花爆发**（事件驱动，确定性、平涂小菱形、阻尼下落）；② **棱线能量流**（数据沿晶格流动的光点，周期性）；③ **悬停微光**（悬停晶面随机迸小晶花）；④ 旋转惯性落座；⑤ 邻面脉冲保留。无加性辉光、无 idle 空浮。
- 校验：`node --check` SYNTAX_OK；trackball 方向测试 **drag RIGHT→+37.7px(右移) / drag UP→−33.4px(上移)**；2000 次随机拖拽 NaN=0；惯性 61 步收敛；安全扫描无 eval/未信任注入。
- 红线守住：仅改 `概念/晶簇/` 三件套；未碰看板娘层/App.cpp/TopBar.cpp/Store.*；未 `git add -A`。

## 概念 13 · 晶簇 v1.2（2026-08-16 深夜，用户实测反馈迭代）
- 用户反馈 3 点：① 切到亮色后"晶体标志没了、只剩线条"；② 亮色比暗色舒服，去掉暗色只留亮色；③ 加一套新颖卡牌系统，与晶体联动。
- **根因① 晶面隐形**：v1.1 亮色 `fLight(m)=90-60*m`，未掌握晶面（m≈0）算得 90% 亮度≈背景白 → 在亮底上不可见，约 60% 初始未掌握晶面消失，只剩暗色棱线（"线条"）。修复：亮色亮度收进 **42%–78% 可见带**（未掌握淡 78% / 已掌握深艳 42%，均明显深于背景白~88%）。同时把晶面从单钻石重绘为**切割宝石多刻面**（底钻+上左/上右亮面+下暗面+竖接缝），明确读作"晶体标本"。并删除整个 dark 主题与切换按钮，仅留亮色。
- **新增③ 标本图鉴卡牌系统（与晶体双向联动，非游戏/信息优先/零辉光）**：
  - 左栏 `标本图鉴`：368 张标本卡（学科色条+标题+难度+关联数+掌握度条），支持**学科筛选 + 排序（未掌握优先/掌握度/学科）**。
  - **双向联动**：点卡片 → 该晶体用四元数 `qFromTo(u, +Z)` + `slerp` **平滑转正面对你**（~1s 收敛）+ 选中详情卡；悬停卡片 → 晶体高亮环；悬停晶体 → 对应卡片 `.hot` 高亮；点晶体 → 选中并同步滚动卡片 + 弹出右侧详情标本卡（学科/晶系/分值/难度/掌握度/状态/**相邻晶面可点击溯源**）。
  - 晶系风味名（等轴/层状/粒状/针状/棱柱/板状/柱状/菱方）进详情卡，强化"矿物标本"新颖隐喻。
  - 图鉴可收起（`收起/展开`，展开时晶体簇中心右移 130px 避免遮挡）。
- 校验：`node --check` SYNTAX_OK；亮色亮度带 **42–78%**（背景~88% → 可见）；trackball **拖右 +40.7px / 拖上 −36.2px**（方向正确）；`slerp` 转身 **59 步收敛**；2000 次随机拖拽 **NaN=0**；安全扫描无 eval/未信任注入。修了一处 HSL 参数顺序写反（sat,light,hue→hue,sat,light）。

## 概念 13 · 晶簇 v1.3（2026-08-16 深夜，根因修复 + 菱形节点 + UI 重做）
- 用户反馈：① 线端点没有菱形标志、晶体菱形没了；② 标本卡可以但不美观，要用 UI 设计 skill 重做。
- **关键根因（推翻 v1.2 判断）**：v1.1 起 `facets` 初始化 `depth:0`，而 `project()` 只回写 `sx/sy/sz`、**从没回写 `depth`**，导致画晶体半径 `r=(3+score*1.05)*f.depth*...` 恒为 0 → **所有晶体被画成 0 像素、根本没渲染**。"只剩线条"的真因是此 bug，不是亮色主题（v1.2 的亮色修复是误判）。
- 修复：① `project()` 回写 `sc/depth`；新增 `facetR(f)=(5.0+score*1.6)*f.sc*zoom*0.96` 作为晶体半径；② 晶体重绘为**清晰菱形轮廓（等臂）+ 宝石切面**；③ 棱线缩短到菱形边界（不再穿过晶体），并在**每条线两端各绘一个菱形节点标志**（subject 色，`drawDiamond`）。校验：半径 minR 5.22 / maxR 12.15px（可见）、NaN=0、菱形节点 736 个。
- **UI 重做（按 creative-motion-design 红线：克制单主色/零辉光/配色和谐/细线/现代感/信息优先/非SaaS套路）**：重写整套 CSS（仅亮色纸张暖调，accent 青绿 #0f9e86）。卡片加宝石小图标(.gem 旋转方块)、标题行(.chead)、状态药丸(.cstate)、掌握度条改 subject 色渐变；详情标本卡加大圆角/精致网格/渐变顶条/精致按钮/邻接药丸；顶栏品牌前加菱形标记、tab/头像精致化；KPI/图例/提示间距与字距优化；微交互过渡用 cubic-bezier。代码内 `hint` 左移随图鉴 316px。
- 校验：`node --check` SYNTAX_OK；半径可见性测试 minR 5.22>0.5（旧版 0）、NaN=0；安全扫描仅静态学科名/数值构建 innerHTML（无 eval/未信任注入）。
