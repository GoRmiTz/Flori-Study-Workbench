# 概念 13 · 晶簇 CrystalCluster · 动效概念介绍

> 接手包内新概念原型。Metaphor：把考公/考研微观考点画成一块漂浮在暗空中的**矿物晶簇标本**——8 个学科 = 8 个晶系，每颗晶体小面 = 一个题型/微观知识点。

## 1. 为什么是这个母题（对齐基线，规避死因）

继承概念 10/12 已认可基线，规避既有死因：

- **非时序**：空间关系 / 晶体结构，不碰时间轴（弦/层积之鉴）。
- **高密度离散**：8 晶系 × 46 晶面 = **368 颗晶体小面 + 细棱连线**，绝不空（气脉"大而空"之鉴）。
- **自然边界**：全幅深底 + 中央微亮 + 暗角，晶系自由漂浮，**无硬长方形截断**（气脉之鉴）。
- **告别方块堆叠**：全为菱形小面 + 细拓扑棱线（层积之鉴）。
- **配色克制 + 数据着色豁免**：单主色族（墨青系，学科用协调色相）+ 三通道数据着色（概念 12 豁免）。
- **零辉光**：仅平涂 + 细描边 + 普通 alpha 描边环，无加性光球（流光/素履之鉴）。
- **信息可视化优先**：晶面大小=分值、明暗=掌握度、色相=学科、纯度=难度，顶部 KPI + 悬停精确面板（弦之鉴）。

与概念 12「星砂」的区分：星=散点漂浮，晶=**几何晶体小面 + 棱线成簇**，矿物/几何感更强、更"收藏品"，且天然满足高密度 + 自然边界，是新方向而非复制。

## 2. 落点（mock 真实界面）

芙洛理·晶簇页：顶栏 tabs（知识库 / 练考 / 复盘 / **晶簇** + 头像）、顶部 KPI 条、左下操作说明、右下三通道颜色图例。看得见动效加在哪。

## 3. 信息编码（先于动效）

| 视觉变量 | 数据维度 | 说明 |
| --- | --- | --- |
| 晶面大小 | 分值权重 (1–5) | 几何大小区分，不靠撞色 |
| 晶面明暗 | 掌握度 (0–1) | 暗→亮，单色族内明度层次 |
| 色相 | 学科来源 | 8 个协调色相族（数据着色豁免） |
| 纯度(饱和度) | 难度 (0.2–1) | 高难更饱和 |
| 细棱连线 | 知识关联 | 晶系内最近邻 2 条预计算 |
| 顶部 KPI | 总数/已点亮/掌握率/平均掌握/最暗晶系 | 一眼读出薄弱簇 |

## 4. 动效语言（真实操作驱动、确定可控、非游戏、零辉光）

- **悬停**晶面 → 高亮其菱形 + 准星环 + 精确面板（受控，非自跑）。
- **左键点击** → 点亮/取消「掌握」，该晶面由暗转亮（临界阻尼弹簧收敛，不失控）；**同晶系相邻晶面受控脉冲**（衰减光环，阻尼收敛后归位）。
- **右键** → 取消掌握。
- **拖拽** → 旋转整块标本（yaw/pitch，pitch 钳制 ±1.3）；**滚轮** → 围绕中心缩放（zoom 钳 [0.5,2.2]）。
- **自动演示**：静置时缓慢自转 + 周期性点亮脉冲，任一交互即停（演示动效，非 idle 空浮）。

## 5. 视觉红线落实

① 告别方块堆叠——菱形小面+细棱；② 配色克制和谐——墨青主色族+数据色相，无撞色；③ 零辉光——平涂+细描边；④ 高密度离散 368 面；⑤ 自然边界——全幅深底漂浮无矩形框。

## 6. 技术

- 单文件 HTML；**Canvas2D 主舞台 + 暗底径向渐变**（`createRadialGradient`，无 WebGL，杜绝黑屏风险）。
- 3D 晶簇：fibonacci 球分布生成晶系/晶面，旋转矩阵投影 + 正交深度缩放（无透视除零），深度排序远→近绘制。
- 确定性随机（mulberry32，种子固定）保证布局可复现。
- 掌握度弹簧 `mast += (target-mast)*min(1,dt*6)`；脉冲 `pulse *= 0.06^dt` 衰减，均确定收敛、无 NaN。
- 暴露 `window.__probe()` 供无头校验（总数/已点亮/NaN数/边数/zoom有界）。
