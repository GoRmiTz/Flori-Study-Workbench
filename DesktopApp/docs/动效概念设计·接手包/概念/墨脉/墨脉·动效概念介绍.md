# 墨脉 · 知识脉络 —— 动效概念介绍

> 概念原型：`docs/墨脉·动效概念原型.html`（浏览器打开即玩）
> 状态：概念阶段，待评审是否落地实现。

## 一句话
把知识点画成一张**会呼吸的脉络网络**；你的**悬停 / 点击**让"脉气"沿脉络流动、点亮关联——让"知识之间的连接"变得看得见、摸得着。

## 它让什么更直观
- **知识关联可视化**：考公知识点不是孤立词条，而是彼此勾连的脉络（行测资料分析 → 申论写作、判断推理 → 常识法律、时政 → 公基……）。鼠标一悬停，关联脉络立刻"通上气"，比静态列表直观得多。
- **掌握程度有手感**：点击节点"通此脉络"，节点深化 + 朱砂环，一眼看出自己网住了哪片知识；顶部"已通脉络 N / 总"给出轻量进度（仅信息，无计分）。
- **界面在动，但听你指挥**：所有运动都由你的真实操作触发，松手即沉降，绝不自跑。

## 由什么操作驱动（非游戏、无问答/计分）
- **悬停**节点 → 脉冲沿脉络传播、点亮相邻节点（受控、有衰减，不失控）。
- **点击**节点 → 通/取消该脉络（弹簧深化 + 朱砂环）。
- **拖拽**平移、**滚轮**缩放（惯性、阻尼，必落座）。
- **切换 知识库 / 复盘** → 整张脉络编排式重排（放射布局 ↔ 分组列布局，节点各自速度错位抵达）。

## 为何非大众化
- 隐喻取自中医"经络/脉络"与文人"墨"语境，是考公/中文场景独有的视觉语言；不是 SaaS 蓝白卡片，也不是火球流体。
- 动力学是**图上的波传播 + 弹簧**，确定可控；区别于"自由流体乱跑"，也区别于"抽测压印小游戏"。

## 集成落点（若评审通过）
- 界面：芙洛理 **知识库 / 复盘** 视图的"知识脉络"区。
- 技术：用现有 D2D/D3D 渲染层；仅新增 `src/gfx/` 下文件。
- 红线：不碰未提交看板娘层（`src/kanban/*`）、`App.cpp`、`TopBar.cpp`、`Store.*` 等；提交只 `git add` 本次新增文件。
- 诚实限制：headless 无法验证观感，动态需真机/浏览器目视确认。

## 与「砚心」的关系
同源方法论（动效为主 / 真实操作驱动 / 确定可控 / 落真实界面），但**全新隐喻与动力学**——砚心是卡片墨晕入场，墨脉是网络脉冲传播。二者不重复，本概念独立评审。
