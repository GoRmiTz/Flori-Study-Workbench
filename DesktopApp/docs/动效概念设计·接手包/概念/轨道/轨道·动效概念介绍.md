# 概念 14 · 轨道（Orbita）· 动效概念介绍

> 状态：**全新概念原型（待评审）**。软件主色为亮色，故仅亮色主题。当前停在 `docs/` 原型阶段，未集成进客户端。

## 一、隐喻与落点
把考公/考研的知识宇宙画成一颗**原子**：

- **知识核**（中心）= 你的知识核心，是已掌握内容的聚合体。
- **8 个角向扇区** = 8 个学科（政治理论 / 常识判断 / 言语理解 / 数量关系 / 判断推理 / 资料分析 / 申论写作 / 面试实战）。
- **8 层同心壳层** = 难度层级，**由内向外难度递增**，每层带 **L1→L8 刻度标签**（直接可读，符合"信息可视化优先"）。
- **电子点（菱形）** = 微观考点。每个点是一个待攻克的题型/知识点。

"轨道"是一个**全新形态**：既不是考点星图的抽象拓扑网、也不是识海星砂的随机星点云、更不是晶簇的几何晶体——它是**结构化壳层 + 放射扇区**的原子模型，科学、现代、非大众化。

## 二、信息编码（信息可视化优先）
| 维度 | 编码方式 |
| --- | --- |
| 学科 | 色相（8 个和谐色族，非撞色） |
| 掌握度 | 明暗（未掌握浅、已掌握深艳） |
| 分值权重 | 点大小（越大越重要） |
| 难度 | 所在壳层（L1 易 → L8 难，带刻度） |
| 关联 | 同扇区电子轨连线（细线，粗细一致） |

三通道着色（色相=学科 / 纯度=难度 / 明暗=掌握度）沿用概念 12 的**数据着色豁免**，但额外用**壳层结构**承载难度维度，比纯星点更"读得出来"。

## 三、动效语言（真实操作驱动 / 确定可控 / 非游戏 / 零辉光）
- **拖拽旋转**：四元数 trackball（拖哪转哪，绝不再"有时反向"），松手有**旋转惯性**落座（约 1s 收敛）。
- **滚轮缩放**：有界 [0.5, 2.2]，不失控。
- **悬停**：高亮该电子点 + 弹出精确面板（学科 / 壳层难度 / 分值 / 难度系数 / 掌握度 / 关联数）。
- **单击**：点亮/取消掌握 → **电子跃迁火花**爆发（确定性、平涂小菱形、阻尼下落），邻点受控脉冲后归位。
- **能量流**：数据光点沿电子轨连线周期性流动，体现"知识在壳层间传导"。
- **自动演示**：静置 3 秒自动缓慢旋转，交互即停（保证受限预览里也有动效）。
- **学科筛选**：右上角 chips 点击高亮某学科、暗化其余。

全部动效均无加性辉光、无 idle 空浮，守零辉光铁律。

## 五、与已否决方向的区别
- **非「织」（概念 4 否决）**：织锦隐喻被否因"无清晰实用价值"；轨道用壳层刻度直接承载难度数据，信息可读。
- **非「气脉」（概念 11 否决）**：非稀疏插值的大而空连续场、非硬矩形截断；轨道是高密度离散点 + 天然圆形边界。
- **非「层积」（概念 9 否决）**：无方块堆叠、无时间轴。
- **非「弦」（概念 8 否决）**：数据直接可读，非"艺术有趣但读不出"。
- **非「复盘·生长/年轮」（概念 5 否决）**：现代原子美学，非古老有机形态。
