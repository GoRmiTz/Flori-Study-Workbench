# 概念 27 · 抽笺·知识笺匣（动效概念原型）

> 母题 = 笺匣 / 签筒（求签仪式）。核心范式 = **抽 / 阅 / 收** 的仪式流。
> 本概念是**对"花瓶"批评的直接回应**：它不只是一个好看的动态展示，而是一个**自带买点、能落进真实软件、每次交互都产生学习价值**的复习入口。

---

## 〇、买点 / 价值闭环（本概念的核心，先于视觉）

用户批评："欠缺的主要是怎么在软件中利用上……怎么成为买点还是有欠缺，看起来像无用的花瓶。" 并点名「抽卡」项目为正面范式——"用户可以通过卡片获取知识，且富有娱乐性"。

**抽笺的卖点就是"抽卡式复习"：**

1. **娱乐化随机复习（钩子）**：用户点一下笺匣，抽一笺——有"抽"的惊喜感与仪式感，把枯燥的 spaced repetition 包装成"每日抽 N 笺"。这是持续打开的理由。
2. **知识直接到手（价值）**：每笺 = 一个最小可消化的知识单位（考点名 + 一句精讲 + 真题引），不是装饰，是干货。
3. **进度可视化（留存）**：右上「已习 N 笺 · 今日抽 M 笺」+ 右侧「已习笺册」刻度，让积累肉眼可见，给成就感（非计分、非排行榜，不廉价）。
4. **自适应复习闭环（深度）**：标「待巩固」的考点后续会被**加权重抽**，自然形成"薄弱点反复出现→直到掌握"的复习闭环。

**软件落点（怎么被用起来）：**
- 笺面内容**直接来自 F-D 练考模块** `QuizParser` 产出的题目 `.md`（真实题库，非编造展示数据）。
- 标「已会 ✔」→ 写入 **ReviewEngine 复盘**（掌握度 +1）。
- 标「待巩固 ↺」→ 进入**错题集**，后续加权重抽。
- 顶栏 mock 真实 chrome（`知识库 / 练考 / 复盘 / 抽笺` tabs），让"加在哪"一目了然。

→ 它本质上是**练考/复盘功能的娱乐化入口**，用户每次交互 = 复习知识 + 推进进度，不是看个漂亮图形。

## 一、隐喻与落点

| 项 | 内容 |
| --- | --- |
| 母题 | 笺匣 / 签筒（求签）：从一匣知识笺中抽一笺，阅毕归档入册 |
| 交互范式 | **抽取 → 阅读 → 归档** 仪式流（固定取景，**绝不是轨道旋转 / 飞入聚焦**） |
| 视觉语言 | 暖白纸底 + 墨线笺匣 + 墨色笺纸；零辉光、无彩圆、线条主导 |
| 信息编码 | 笺面三段 = 学科标签(青) / 考点名(浓墨) / 精讲+真题引(淡墨)；已会=墨绿印、待巩固=青印 |
| 动效语言 | 抽出时的**墨韵揭示**（自上而下晕开 + 边缘墨点）；归档时的飞入笺册 + 盖章 |

---

## 二、信息可视化与交互

- **顶部 KPI**：已习 N 笺 · 今日抽 M 笺 · 待巩固 K 笺（实时聚合读数）。
- **右侧笺册**：每入册一笺长出一枚刻度（已会=墨绿、待巩固=青），进度可视化。
- **真实操作驱动**：
  - 点笺匣 → 抽一笺（真实点击，确定性动画，非自跑）。
  - 点「已会 / 待巩固」 → 归档并写回数据。
  - `Esc` → 丢弃当前笺，回到匣前（不记进度）。
- **确定可控**：抽出/归档均为 ease 缓动、固定时长（~560ms），无失控、无 idle 空浮。

## 三、红线落实

- ✅ 铁律㉟（拒绝花瓶·买点/价值闭环）——本概念即为此律的落地样本。
- ✅ 铁律㉞（禁止重复"轨道观察结构"交互范式）——固定取景的**施作**流，非环视。
- ✅ 铁律㉝（亮色背景）——暖白纸 `#F6F2E9`。
- ✅ 铁律㉘（禁彩圆俗套·线条主导）——节点/印章均为墨线或菱形刻度，无彩色实心圆。
- ✅ 铁律④（零辉光零 bloom）、铁律⑤（信息可视化优先）、铁律⑥（真实操作驱动·非廉价小游戏）。

## 四、技术架构（绝不黑屏）

- **主舞台**：纯 Canvas2D，透明底，自洽绘制笺匣/笺纸/印章/刻度，**不依赖 WebGL**。
- **受控背景**：WebGL2 fragment shader 画"暖纸 + 极淡墨晕漂移 + 极淡笺纹"，`try/catch` + 编译/链接校验；**任何失败即 `display:none`**，CSS 纸纹兜底 → 即使着色器整段失败也只是少了背景纹理，**绝不黑屏**（根除识渊"降级取 2d 上下文得 null 崩溃"死因）。
- 校验：`node --check` + 双模式 DOM 桩无头探针（WebGL 可用 / WebGL=null 两种均 `onScreen>0、nan=false、lightBg=true、colorfulCircles=0`）。

## 五、诚实限制

headless 只能证"能渲染 / 零报错 / 抽-标-计数 数值对 / 亮底 / 无彩圆"。**以下须用户在真实浏览器（Chrome/Edge 开本地文件）确认**：墨韵揭示的观感、笺纸排版疏密、墨绿/青印章是否够"印"味、亮纸配色协调度、抽/归档手感与时长。
