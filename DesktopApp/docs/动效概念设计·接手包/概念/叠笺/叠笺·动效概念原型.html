叠笺 v3.5 · 多卡包 + 错题栏 · 概念原型
卡包层：左右排布多个卡包（考公 / 考研 / 事业单位），聚焦包背后浮起专属色光晕（终末地/方舟风）、卡包本体为棱角切角框；A/D 或拖动切焦点，单击任意卡包即开该包；顶栏「卡包」随时返回。
层级：单击最前卡深入、单击同级背后卡直接切换、单击上级背后卡回退（不再重复堆叠层级）；背后卡静止、不跟随当前卡滑动；最前卡带四角准星。
错题收集：题卡上按住 2 秒 → 变暗 + 右侧错题栏滑出，错题卡紧密横排只露边边；拖入某栏落下即收藏（涟漪 + 墨点迸发 +「已加入」），面板稍候收起。
题卡面只显示题面描述，不直接显示答案（答案在展开浮层，含扫描线揭幕）。拖拽已禁框选 / 误开新标签页；A/D/空格 切卡，S 展开。

把做错的题拖进来收藏。每个栏最多显示 50 张叠卡，更多只计数不显示（像一摞收集卡）。
