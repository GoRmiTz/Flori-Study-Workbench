# 叠笺 · 动效概念介绍（v3 · 统一堆叠 / 无翻面 / 不穿模）

> 概念原型：`docs/叠笺·动效概念原型.html`（浏览器直接打开，建议 Chrome / Edge；DOM/CSS 实现真实 3D 倾斜与分级特效）
> 本版（v3）是对 v2.2 用户反馈的**根因级重写**，不是补丁。

## 一句话隐喻
一笺之下犹有千笺。知识是树，树的不同深度是一叠实体笺卡，全部**叠在同一副牌堆里**；钻取时父层不消失、只是沉到牌堆更深的后方，像拆开包装、把内卡压在包装之上。末级卡片依**难度稀有度**呈现不同特效——越难，越像抽出一张稀有卡。

## 层级结构（吻合需求）
- **第 1 层**：考公（总合集）
- **第 2 层**：行测 / 申论 / 时政 / 常识 / 随机（随机＝合并其余全部题型）
- **第 3 层**：言语理解 / 判断推理 / 资料分析 / 数量关系 / 随机（随机＝合并当前科目全部题型）
- **第 4 层（底层卡片）**：具体题目卡，可展开、带难度

任意层级均可"深度递出"切换，点右上「返回」收束回上层。

## 为什么到 v3：根因诊断（重要）
v2.2 仍残留两个问题：① 层级卡与身后卡**穿模**；② 卡片翻阅的特效与上级"残影"卡的特效**重复**。
根因不在参数没调好，而在**架构**：

- v2 之后采用"两套独立 3D 系统共存于同一 perspective 空间"：**当前层叠笺（deck）+ 独立的父层残影（ghost）系统**，外加一个 `.flipper` 的 `rotateY` 翻面动画。
- 残影 ghost 与 deck 各自做 3D 变换，二者 z 区间靠数值"拉开"维持不相交——只要任意一边的动效（尤其是难/极卡的 3D 倾斜、父层退后姿态）幅度略大，就会在中间区间相互穿插（穿模）。
- 翻面 `rotateY` 动画 + ghost 自身也带 3D 姿态，于是"卡片在翻"和"父卡在倾"两种动态在同一画面里同时发生，视觉上就是**特效重复**。

**v3 的修法不是再调数值，而是拆掉这套双系统、统一成一副牌堆**：

1. **单一深度栈**：所有卡（当前层的兄弟 + 历史祖先）都是同一个 `Map` 里的 `.card` 对象，每帧朝 `poseForDepth(d)` 弹簧归位，`z = -Z*d`（Z=130，严格单调）。因为深度单调、层间距固定且足够大，**数学上不可能相交**——无论 tilt 多大，背后最近的一张卡也远在 130px 之外。
2. **去掉翻面（flip）**：末级卡不再分正反两面、不再 `rotateY` 翻动。题要直接印在卡面，单击即展开整题浮层。既消除了"翻"这个重复动效，也少了一层 3D 状态。
3. **特效只给最前卡**：`.fx-spot`/`.fx-reflect`/3D 倾斜全部用 `.card.front:hover` 门控，只有**唯一一张最前卡**能点亮；背后卡是安静的静态封面（仅留极淡的常驻流光描边作"卡面语言"），**特效不再重复**。
4. **背后卡只用 `rotateZ`**：祖先/兄弟的"层间错位"仅用平面内旋转（rz = 4°·d），**绝不离开自己的 z 平面**，因此无论怎么摆都不会和邻层穿插。

结论：v3 的稳定性来自结构（单栈 + 单调 z + 平面旋转），而非对一堆 magic number 的调参，所以不会出现"调好一个又穿另一个"的反复。

## 动效语言（全部由真实操作驱动、确定可控、非游戏）
- **悬停**最前卡片 → 轻微 3D 视差倾斜（鼠标跟随，幅度按难度 ≤8°）+ 镜面/追光/流光点亮；背后卡纹丝不动、不发光。
- **钻取（拆包式切换）**：单击层级卡 → 被点的卡片**沉入牌堆后方**（弹簧退深），其下层卡片**浮到最前**叠在它之上——像拆开包装、把内卡压在包装上面。父层以"更靠后的牌"形式继续留在牌堆里（不是另一套残影），点返回或右键即可一层层浮回来。该切换刻意脱离市场主流的平推/发牌式，强调"开包"叙事，且完全走了同一条堆叠通道，无第二套坐标系。
- **滑动 / 拖拽 / 滚轮** → 层内以**深度递出**翻动（后卡从后方浮起、前卡退后），带惯性、必落座；无从左到右的发牌动画（与叠层语言重复，早版已去）。
- **单击末级卡** → 浮层展开完整题目（题干+选项+参考答案）。

## 卡片分级与抽卡式特效
难度：**极 / 难 / 中 / 易**。特效强度随难度递增（视觉稀有度，无随机奖励机制，非游戏），且**全部仅悬停最前卡时显现**：
- **易** → 流光描边（Border Glow，缓慢流动渐变，常驻极淡）
- **中** → 追光灯（Spotlight，鼠标处光斑跟随）+ 流光描边
- **难** → 镜面反光（Reflective，高光随鼠标横扫）+ 3D 倾斜（Profile）+ 追光 + 流光描边
- **极** → 在难基础上再加 **Title Card 光影景深**（悬停抬起+柔光），五效齐发；tilt 系数略降至 8° 以保证安全间距

> 终末地（Endfield）式卡面语言：实体卡在灯下转动的镜面高光、追光、流光描边，被转译为"难度越高、卡面越活"的稀有度视觉。

## 版式
卡片为**横向名片比例**（CW=min(560, w·0.46)、CH=CW·0.60，随视口自适应），正文更小字号（13–14px）以容纳主体内容；标题大、留白足，像一张张考公知识名片。

## 本次打磨（v2.2 → v3）
- **根因改写**：拆掉"deck + ghost 双 3D 系统 + flip"，统一为**单一深度栈**（所有卡共享 `poseForDepth(d)`、单调 z）。
- **消除穿模**：层间距固定 Z=130 且 z 严格单调，背后最近卡远在 130px 外；背后卡只用 `rotateZ`（平面内）绝不离开自身 z 平面 → 结构上不相交。
- **消除特效重复**：翻面动画删除；`.fx-spot/.fx-reflect/3D倾斜` 一律门控到 `.card.front:hover`，只有唯一最前卡亮；背后卡仅保留常驻极淡流光描边。
- **保留并强化"拆包"**：父层退后是牌堆里"更深一层"的同一套弹簧，不是独立残影系统，叙事与稳定性兼得。
- **防失控**：沿用帧率无关弹簧 `1-pow(k,dt)`、启动延迟到 `load`+`rAF` 后测尺寸（避免默认 300×150）；自动演示 ~4.8s/步、被任意操作立即打断。

## 不晃眼睛
配色收敛暖纸+墨灰+朱砂/分级辉光；特效**仅在悬停/交互时显现**，静止时卡片安定为素纸；自动演示放慢且可一键关闭。

## 本次打磨（v3 → v3.1）：拖拽直接操控
用户反馈 v3 的拖拽"脱不动、拖着没感觉"——根因是 v3 的拖拽只改 `scrollPos` 推进层级，**最前卡片本身不跟随手指**，全靠身后卡弹到前面来"假装"切换，缺乏直接操控感与实时反馈。
v3.1 把拖拽改回**直接操控（direct manipulation）**：
- **卡片实时跟随手指**：拖动时最前卡片按 1:1（纵向 0.4 阻尼）跟随指针位移，不再"钉"在原地；松手后弹簧回弹/落座。
- **倾倒 + 让位反馈**：拖动时卡片朝拖动方向轻微 `rotateZ`（系数 0.025°/px），并随位移放大 1.07、淡出，明确表达"被拿起、要让位"；同时下一张自牌堆后方浮现（由 `scrollPos` 连续推进驱动）。
- **阈值切换**：拖过 `~90px` 或快速甩动（速度>14px/帧）即提交翻到下一张；否则回弹，确定可控、不误触。
- **底部圆点 pager**：实时显示当前在同级中的位置（随拖动连续点亮），点圆点可直达，给明确的进度反馈。
- 背后卡仍只用 `rotateZ`（平面旋转）、特效仍仅最前卡——v3 的"不穿模 / 不重复"铁律不变。

## 本次打磨（v3.1 → v3.2）：防误选 + 键盘 + 计数
用户反馈 v3.1 拖拽时**选中的是卡片里的文字**、且拖拽会**误开新标签页**——这是浏览器原生行为：在文字上按下拖动会发起文本选择 / 文本拖拽，松手落在浏览器外即开新标签。另外"只靠拖"切换太费手。
v3.2 的修法（双保险，从根上掐断原生拖拽）：

- **`user-select:none` + `-webkit-user-select:none` + `-webkit-user-drag:none`**：落到 `.stage` 与 `.card` 上，文字永不可被框选；卡片 `draggable=false`。
- **`pointerdown` 调用 `e.preventDefault()`**：从源头阻止浏览器在该手势上发起选择 / 拖放；并设 `touch-action:none` 防触屏手势。
- **三层 `dragstart` 拦截**：`deck` / `stage` / `document` 上的 `dragstart` 一律 `preventDefault()`——彻底杜绝文字 / 图片被拖出浏览器开新标签。
- **键盘导航（主诉求：省手）**：`D` / `空格` = 下一张，`A` = 上一张（均循环），`S` = 展开当前卡，`Esc` / `Enter` = 返回上一层 / 关闭浮层。键盘切换同样走 `scrollPos` 弹簧，平滑落座。
- **抓取态视觉**：拖动中的卡片加 `.grabbing`（光标变 grabbing + 阴影加深），明确"被拿起"。
- **计数器**：底部新增"第 X / N 张"，与圆点 pager 同屏，进度一眼可见。
- 穿模 / 特效重复铁律与 v3 完全一致，未动架构。

## 本次打磨（v3.2 → v3.3）：多卡包 + 错题栏收集
用户认可 v3.2 功能，要求在**同一概念内继续创新**（非新概念）：① 把"考公"降级为一个**卡包**，左右并排放置多个卡包（考公 / 考研 / 事业单位），可选、可返回；② 增加**错题栏拖拽收集**：做错一题后，把题卡拖入右侧错题栏。

### 多卡包（pack selector）
- 顶层进入**卡包视图**：多个卡包在水平方向以"焦点居中、左右收拢并 `rotateY` 内倾"的**旋转木马**排布（考公红 / 考研靛 / 事业单位青）。`A`/`D` 或拖动切换焦点，`单击`/`空格`/`S` 打开进入其层级树。
- 卡包本身是一个 `isPack` 节点，打开后才是行测/申论……（原 4 层结构完整保留）。**根层级点「返回」或顶栏「卡包」→ 回到卡包视图**（修复了此前无法回到考公这一层的问题）。
- `PACKS` 数组驱动；`computeItems` 按 `S.mode` 分支（packs 用 `poseForPack`，deck 用 `poseForDepth`）；`syncUI/syncPager/keydown` 全做了卡包感知。

### 错题栏拖拽收集（long-press → dim → drop）
- 在**题目卡（leaf）**上按下即启动 2 秒长按计时：
  - 2 秒内松开 = 普通单击 → 展开题卡；
  - **按住超过 2 秒未松** → 进入收集态：背景经 `.scrim` 变暗、右侧**错题栏面板**滑入（含 3 个预置栏，并灌入示例错题演示堆叠）；
  - 继续拖拽，经过某错题栏即 `.hot` 高亮；松手落入 → 该栏 +1 张、顶部 mini 卡用**题目难度色**、弹出"已加入「XXX」"toast + 栏位闪光，题卡播 `addedpop` 微亮，**随后回到原页**（卡片弹簧归位）。
- **收藏家感**：每个错题栏最多渲染 **50 张**叠在一起的 mini 卡（错位+微旋转），超出只显示计数"仅显 50"，像一摞收集卡。顶栏「错题栏」按钮可随时浏览。
- 卡包层 / 非 leaf 卡不触发此手势；拖拽防误选/防开新标签的双保险（v3.2）全部保留。

## 本次打磨（v3.3 → v3.4）：单点修复 + 点哪开哪 + 错题栏横排 + 创意光晕
用户实测 v3.3 提出 5 处问题，本版**逐条根因修复**并在交互上自由发挥：

1. **单点失效 / 单点误显拖动**（根因）：v3.3 在 `pointerdown` 立刻 `dragging=true` + 加 `.grabbing`，且**分类（非末级）卡单击没有任何分支处理** → 单点分类卡无事发生、且按下即显示抓取态。
   - 修法：引入"阈值判定"——**移动超过 6px 才升级为拖拽**（此时才加 `.grabbing` 与 `dragObj`），之前只算"按压"；单击分支对**任意卡**生效：leaf→展开、其余→深入。单点不再误显拖动。
2. **拖动很长也不切换**（根因）：切换 commit 依赖一个**从未被赋值的 `S.dragVel`**（恒为 0），且 commit 只在 `moved && !leaf` 分支，逻辑割裂。
   - 修法：删除虚假阈值，拖拽中**实时改 `scrollPos` 预览递出**，松手**吸附到最近一张**（`round(scrollPos)`）——拖多远都能稳切。
3. **卡包层显示"第卡包层"**（根因）：`.depth` 模板是"第 <b>…</b> 层"，v3.3 把 depth 文本写成"卡包"，拼成"第卡包层"。
   - 修法：卡包层**直接隐藏 `.depth` 层数指示**（只留顶部"卡包"面包屑 + 底部"第 X / N 个卡包"计数），不再出现"层"字。
4. **点侧边考研却打开考公**（根因）：`pointerup` 用 `S.frontObj`（永远是居中聚焦包）开包，而非命中包。
   - 修法：卡包层单击改用 **`hitCard(x,y)` 语义命中**——点哪个包开哪个，无需先把焦点挪过去。
5. **错题栏叠卡挡住栏名**（根因）：`.bin-stack` 把 50 张卡**竖向重叠**，向上溢出盖住标题。
   - 修法：改为**从左到右横排**（flex 左→右、轻微扇形错位、横向可滚动），栏名始终在上方、不再被遮挡；最前一张用难度色，仍保留"收藏家"质感。

### 自由发挥的创意增量
- **卡包聚焦光晕（aurora）**：卡包层时，舞台中心叠加一层该包专属色的**柔光晕**（考公朱砂 / 考研靛蓝 / 事业单位青绿），随焦点切换平滑换色——把"选包"做成有氛围的仪式感，而非冷冰冰的轮播。
- **落点涟漪（ripple）**：题卡拖入错题栏松手时，在栏中心绽放一圈**涟漪环** + `flash` 闪光，配合"已加入"toast，收藏动作有明确回馈。
- 以上特效均为**确定可控的非游戏动效**：光晕随焦点切换、涟漪随落点播放，不由随机/计分驱动。

> 铁律不变：统一单栈、单调 z 不穿模、特效仅最前卡不重复、防误选/防开新标签双保险。

## 本次打磨（v3.4 → v3.5）：层级重复 / 背后卡跟随 / 错题栏堆叠 / 光晕可见
用户实测 v3.4 提出 6 处问题，本版**逐条根因修复**，并大胆引入终末地/明日方舟风创意：

1. **错题栏叠卡太松、有角度、出滑轨**（根因）：v3.4 的 `.mini` 用 `flex + 负 margin + rotate` 扇形排布，旋转 + 错位在窄面板里既挡栏名又像滑轨。
   - 修法：`.bin-stack` 改为**相对定位 + 绝对横排**，每张卡 `left = k*11px` **无旋转、紧密横排，仅露一条边边**；面板过宽时横向滚动，栏名永远在上、不被遮挡。
2. **点背后卡出现 `行测/资料分析/行测/资料分析` 重复层级**（根因）：v3.4 对所有单击统一 `drillInto(o.node)` 入栈——点**上级背后卡**会把它再 push 一层，于是历史出现重复层。
   - 修法：给每张卡标注 `kind`（front / sib / anc）+ `sibIndex` / `histIndex`；单击按角色分流——**最前卡深入 / 同级背后卡直接切换 frontTarget / 上级背后卡回退到该层（`goBackTo`）**，绝不重复入栈。
3. **背后卡跟着当前卡轻微移动**（根因）：v3.4 用连续 `S.scrollPos` 算兄弟深度，拖拽时 scrollPos 实时变 → 背后卡跟着递出位移。
   - 修法：兄弟深度改用**吸附后的 `frontTarget`**（而非连续 scrollPos），背后卡在拖拽中**静止**；仅最前卡随手指位移，松手吸附后再整体弹簧归位。
4. **卡片里直接显示答案**（根因）：v3.4 题卡面渲染 `node.brief`（含题面/选项），用户认为像"答案"。
   - 修法：题卡面**只显示描述性 `node.cover`（如"逻辑填空 · 辨析成语与实词"）**，答案与整题只在展开浮层出现（浮层新增**扫描线揭幕**动画）。
5. **落点涟漪看不到**（根因）：v3.4 松手即 `exitBinMode()` 立刻收起面板，涟漪/闪光还没播完就消失了。
   - 修法：落入后**延迟 900ms 再收起面板**，涟漪 + 闪光 + 墨点迸发完整播放；涟漪改用**错题栏专属色**描边、放大到 160px。
6. **卡包聚焦光晕看不到**（根因）：CSS 里**根本没有 `.aurora.on` 规则**，`classList.add('on')` 什么都没改，opacity 恒为 0。
   - 修法：补 `.aurora.on{opacity:1}`，并把径向渐变增强为三档（`cc → 33 → 透明`），光晕清晰可见、随焦点包换色。

### 大胆创意增量（终末地 / 明日方舟 风）
- **卡包棱角切角框 + 专属色辉光**：考公/考研/事业单位卡包改为**八边切角科幻框**（clip-path），并以外发光 `drop-shadow(var(--pack))` 强化包的"阵营色"，选包像在挑一支队伍。
- **最前卡四角准星（HUD 感）**：deck 模式最前卡四角点出**朱砂色 L 型准星**（方舟式瞄准框），明确"当前焦点"。
- **墨点迸发（钻取 / 收藏反馈）**：钻入下一层、打开卡包、拖题入栏松手时，落点迸发 14 颗**同色墨点**四散淡出——用户驱动、确定可控，给"动作"以爽快手感。
- **展开浮层扫描线揭幕**：单击展开整题时，sheet 以 **`clip-path` 自顶向下扫描揭开 + 亮度脉冲**，呼应方舟 UI 的科技揭幕感。

> 铁律不变：统一单栈、单调 z 不穿模、特效仅最前卡不重复、防误选/防开新标签双保险。

## 复盘与经验（v1→v3.5 沉淀）
- **概念定位**：叠笺是"由真实操作驱动的叠层卡片导航 + 多卡包 + 错题收集"的动效语言，落地场景为芙洛理知识库/练考。整体被用户评价"功能整体做得很不错了"，方向成立。
- **最贵的教训（穿模）**：v2.1/v2.2 把"当前层叠笺"和"父层残影"两套 3D 系统塞进同一透视空间，再靠数值拉 z 区间避免相交——不稳定、必穿模。v3 改为**单一深度栈 + 单调 z**，从结构上消除相交，是"根因重写"而非"数值补丁"。
- **特效重复**：翻面动画 + 父层倾身两套动效同屏并发 → 把特效用 `.card.front:hover` 门控到唯一最前卡，背后卡静默。
- **交互三坑**：① 按下即 `dragging` 导致单点误显拖动 → 6px 阈值分离单击/拖拽；② 状态变量 `S.dragVel` 从未赋值却拿来做判定 → 交互失效先查"变量真被赋值了吗"；③ 点侧边考研却开考公 → 点击用 `hitCard(x,y)` 语义命中，不依赖"恒为聚焦对象"。
- **可见性两坑**：效果看不到，常因"事件没真触发"——光晕看不到是 CSS 根本没有 `.aurora.on` 规则（opacity 恒 0）；涟漪看不到是松手立刻收面板。修法都是"让反馈完整播放 + 确认有对应样式"。
- **可复用结论**：任何 3D 只放单一透视栈；特效默认只亮当前焦点；单击/拖拽 6px 分离；点击语义命中；状态变量用到前确认已赋值；每个概念单开子文件夹收纳全部产物（见《动效概念原型·开发日志》"方法论总结"）。
