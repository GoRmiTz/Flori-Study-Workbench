# 概念 17 · 学仪 Astrolabe · 动效概念介绍

> **定位**：今日收尾的全新概念原型。针对「脉络与星图形态重复、不够创新」的反馈，彻底换一种**仪器形态**——知识 = 一台古典刻线仪（浑天仪/星盘意象），全细线、零彩圆。
> **状态**：🟡 待评审（单文件 HTML 原型，浏览器直接打开）

## 一、母题：知识即「刻线仪」
把知识结构画成一台可拨动的古典仪器：
- **8 个同心刻度环** = 8 个学科（径向位置区分，**不用彩色**）
- **环上小菱形刻度点** = 微观考点（几何标记，非实心圆）
- **放射辐条** = 学科分隔刻线
- **游标指针（alidade）** = 当前读取/聚焦的考点，可随悬停/选中拨动
- **中心知识核** = 总览（小菱形 + 细环，非彩圆）

形态上与轨道（原子壳层+彩圆电子）的根本区别：它是**仪器**而非**天体**——满屏细刻线（刻度环、刻度齿、辐条、游标），节点是落在环上的小菱形，配色仅单墨色 + 单一青绿强调，**彻底无彩色填充圆**，直接回应铁律㉘。

## 二、信息编码（信息可视化优先）
| 视觉变量 | 编码含义 | 可读方式 |
|---|---|---|
| 径向位置（环号） | 学科（8 环） | 环缘学科名标注 |
| 环上角位置 | 学科内掌握度排序（梯度可读） | 沿环从低→高铺开 |
| 节点大小 | 重要度（基础/中/高） | 菱形尺寸 |
| 节点明度（灰阶） | 掌握度（暗→亮） | 单色灰阶，无五颜六色 |
| 强调色（青绿） | 悬停/选中/核心 | 仅描边与核心用 |
| 细刻线 | 关联（同环相邻 + 跨环参考） | 线描连接 |

## 三、动效（真实操作驱动 / 确定可控 / 非游戏 / 零辉光）
- **拨动仪器**：在盘面拖拽即转动刻度环；采用**指针角差驱动**（解缠后 `rot += dAng`），天然「指哪转哪」，杜绝轨道早期的方向错乱；释放后**惯性∝真实拖速、快收敛**（吸取轨道教训，轻滑不暴冲）。
- **悬停读数**：指针拨向最近刻度点，弹出精确面板（掌握度/重要度/类型/关联）。
- **点击聚焦**：锁定游标，同环高亮、异环压暗，关联刻线显现。
- **滚轮缩放**：有界 [0.6, 2.4]。
- **静置自动巡扫**：4s 无操作游标缓扫全仪，展示「仪器在运转」。

## 四、技术要点
- Canvas2D + 暖纸背景 + 细网格（全是线），无 WebGL 黑屏风险。
- 确定性 `mulberry32` 布局，可复现。
- 入场即正确渲染，无半径 0 隐形 bug（吸取晶簇教训）。
- `__probe()` 返回 `colorfulFilledCircles:false / hasGrid:true / ringsNoFill:true` 供回归。

## 五、与已通过基线的关系
- 复用：确定性布局、三通道着色豁免（此处收敛为单墨色+灰阶）、信息可视化优先、KPI+悬停面板。
- 区别：形态从「点云/网/簇/壳」换成「**刻线仪器**」，强调线条刻蚀美学与可拨游标交互，属全新尝试。

⚠️ **诚实限制**：headless 仅验证「零报错 / 无 NaN / 节点落环 / 惯性∝拖速 / 无彩圆」。审美（刻线密度、游标手感、灰阶+青绿是否舒服）需你真机确认。
