## 概念 17 · 学仪 v1.0（2026-08-17 凌晨，收尾全新概念 · 待评审）
- **缘起**：用户要「今天最后一个概念」，并明确脉络「类似设计已存在、不够创新」→ 归档不精进，开**真正形态创新**的概念。
- **选型排查（避开重复与已否决）**：星图/星砂=点云、晶簇=几何晶体、轨道=原子壳层、脉络=细线网（与共学舱同被指「线条够但形态偏网」且与星图重复）→ 选**古典刻线仪**全新型态：仪器隐喻（浑天仪/星盘），满屏细刻线 + 可拨游标，节点为落环小菱形。兼具「线条参与」（铁律㉘）与「形态创新」。
- **编码**：8 同心刻度环=学科（径向区分不用彩）；环上角位置=学科内掌握度排序梯度；节点大小=重要度；明度灰阶(14%饱和墨绿)=掌握度；青绿仅强调悬停/选中/核心；细刻线=关联。
- **实现要点**：
  - 旋转用**指针角差驱动**（`atan2` 取角、`dAng` 解缠 `±π`、`rot+=dAng`），天然「指哪转哪」，根治轨道早期固定轴反向问题。
  - 惯性 `angVel=dAng`，释放后 `rot+=angVel; angVel*=0.9` → **∝真实拖速、轻滑不暴冲**（吸取轨道 v1.1 教训）。
  - 节点按 `baseAng+rot` 投影到对应环半径，绘制小菱形（灰阶填充 + 强调描边），核心嵌小青绿菱形；环/辐条/游标全 `stroke` 细线，无填充大圆。
  - 入场即渲染，半径显式 `R0+s*step`，无晶簇式 `depth` 未回写 bug。
- **校验**：`node --check` SYNTAX_OK；节点 93 / 落 8 环 / NaN=0；惯性 **5px→5.0°、60px→60.5°**（∝拖速）；缩放有界 [0.6,2.4]；安全扫描仅静态学科名 `innerHTML`（无 eval/未信任注入）；`__probe` 标记 `colorfulFilledCircles:false / hasGrid:true / ringsNoFill:true`（确认零彩圆）。
- **红线守住**：仅新增 `概念/学仪/` 三件套；未碰客户端；未 `git add -A`。
- **诚实限制**：headless 证零报错/无NaN/节点落环/惯性∝拖速/无彩圆，**判不了审美**——待真机确认刻线密度、游标拨动手感、灰阶+青绿配色是否舒服、是否够「创新」。
