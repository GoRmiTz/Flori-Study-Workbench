# 概念 10 · 考点星图（知识拓扑）· 动效概念介绍

> 针对概念 9「层积」被判定为**负面对照教材**（方块堆叠 + 撞色 + 时序）后的修正方向。
> 用户原话："图形太丑，全部都是方块堆叠，颜色搭配也很烂，这版完全可以作为反面教程了" + "不要盯着时间轴做设计了，往其他方面发展"。
> 本概念据此三条新红线从零重做：**非时序 · 告别方块 · 配色克制**。

---

## 一、母题与落点

- **母题**：把考公 / 考研的考点画成一张**空间关系网**（节点 = 考点，细线 = 关联）。
- **落点**：芙洛理客户端「考点星图」页（mock 了真实 chrome：顶栏 tabs 知识库/练考/复盘/考点星图 + 头像；顶部 KPI 条）。
- **为什么是非时序**：概念 8（弦·时序弦波）、概念 9（层积·时序岩芯）连续两次失败在"时间轴"上，故本次彻底离开时序，转向**空间拓扑**。

## 二、信息可视化优先（图表本体先于风格层）

所有可读性都来自几何编码，不靠动效"藏信息"：

| 维度 | 编码方式 | 一眼可读什么 |
|------|----------|--------------|
| 考点分值权重 | **节点大小**（半径） | 哪些考点分值高、该优先 |
| 掌握度 | **单色系明暗**（暗→亮，墨青 #2f5a57 → #6ee0c4） | 已掌握（亮）/ 薄弱（暗） |
| 考点关联强度 | **连线粗细** | 哪些考点成簇、强相关 |
| 全局进度 | 顶部 **KPI 条** | 总数 / 已掌握 / 掌握率% / 平均掌握度% / 薄弱数 |
| 单点精确值 | 悬停**精确面板** | 名称 / 章节 / 分值 / 掌握度% / 关联数 / 状态 |

一眼能读出"哪些章节是亮的（已掌握）、哪几簇还是暗的（薄弱）"——这是概念 8 弦、概念 9 层积都没做到的"直观读信息"。

## 三、动效语言（真实操作驱动 · 确定可控 · 非游戏 · 零辉光）

- **悬停节点** → 高亮其关联边（其余边淡出）、弹出精确面板。受控、不自跑。
- **左键点击"掌握"** → 该节点由暗转亮，**相邻节点被受控弹簧轻微吸引后归位**（邻居脉冲，阻尼收敛，绝不失控乱飞）。这是"你的真实操作持续驱动"的核心动效。
- **右键"取消掌握"** → 退回初始掌握度。
- **拖拽节点** → 弹性跟随、松手回位（弹簧回 home）；**拖空白** → 平移；**滚轮** → 围绕光标缩放（有界 [0.45, 3.2]）。
- **自动演示常开**（循环高亮 + 提示面板，移动鼠标即停），保证受限预览 iframe 里也有动效可看。
- 无 idle 空浮、无加性辉光、无问答计分。

## 四、视觉红线落实（直接回应概念 9 的否决）

1. **告别方块堆叠**：全篇细线 + 圆点拓扑网，零柱状/色块/方块。
2. **配色克制和谐**：仅一个主色（墨青）靠**明度层次**表达掌握度；文字用灰度；维度靠**大小/明度/位置**区分，**无多硬色块撞色**。
3. **零辉光**：仅细描边与受控脉冲环，无加性光球、无 bloom。
4. **深炭底 + 微渐晕**（减法暗角，非加性发光）。

## 五、技术实现

- Canvas2D 主舞台（headless 验证友好、零 overdraw 风险）。
- **确定性力导向布局**：固定 LCG 种子 → 章节环形中心 + 黄金角螺旋撒点 → 140 次迭代（斥力 + 边弹簧 + 章节引力）收敛为 `home` 位置，仅算一次，不实时混沌。
- 实时物理：每帧对 `home` 做弹簧 + 阻尼（K_HOME=0.06, DAMP=0.84），掌握事件给邻居一次性受控冲量后自然沉降。
- DPR 适配、窗口 resize 重适配、相机 fit 居中。
- 安全：提示面板用 `textContent` 构建，无 `innerHTML` 注入 / `eval`。

## 六、诚实限制

headless 只能验证"能渲染 / 零报错 / 交互生效"，**无法判定审美**。方块堆叠与撞色已从设计层面规避，但请你在真实浏览器确认：星图是否"美观、配色舒服、信息一眼可读"。
