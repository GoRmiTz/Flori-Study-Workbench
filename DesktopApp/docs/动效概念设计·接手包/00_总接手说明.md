## 0. 这是什么

一组**动效概念原型**（单文件 HTML，浏览器直接打开即玩），目标是在「动效为主、非游戏、由真实操作驱动、确定可控、落真实界面、非大众化」约束下，持续从零创新，直到某个方向被评审认可、可落地进芙洛理桌面端（`DesktopApp/` C++ 客户端）。

- 这些**都还是 `docs/` 原型阶段**，未合并进 `App.cpp` / 任何视图 / 看板娘层。
- 系列从概念 0（砚心）到概念 12（识海·星砂），外加 3 个早期失败案例（墨生 / 墨流体 / 活字印知）。部分概念被废弃、部分被用户认可为「通过方向」。

## 3. 跨概念设计红线（速记，全本见 `01_`）

1. **创新第一、非大众化**：拒 SaaS 蓝白渐变+圆角卡片那套。
2. **有意义 + 实用价值优先**：不能为动效而动效。
3. **现代感、艺术现代化**：弃用古老有机形态（年轮/树/生长）。
4. **克制、零辉光、零 bloom**（最常被否根因）：用色深/笔触/描边，不用加性光球。
5. **【最高优先级】信息可视化优先、实用性优先**：数据要直观可读，拒绝「好看但读不出数据」。
6. **真实操作驱动、确定可控、非游戏**：拒问答/计分/抽测/输赢；动力学须阻尼收敛。
7. **落真实界面**：看得见加在哪（mock 真实 chrome / tabs）。
8. **告别方块堆叠**：用细线/点阵/连续面/拓扑网。
9. **配色克制和谐**：单主色+灰度层次，维度靠明度/大小/位置区分，不靠撞色。
10. **放弃时间轴 / 时序母题**：弦、层积连续失败在时序。
11. **信息载体须高密度离散**：拒稀疏采样插值出「大而空」的场（气脉死因）。
12. **形态边界须自然**：拒硬长方形截断（气脉死因）。
13. **数据着色豁免**：仅当颜色**系统性编码数据维度**时允许多色相（概念 10/12 三通道即此），仍守零辉光。

**两条最该记住的「血泪」约束**
- **约束⑭（通过配方即新基线）**：概念 10「考点星图」获认可，配方作为后续新基线——非时序 + 单主色（墨青）+ 明度层次编码掌握度 + 细线拓扑网（线粗=关联强度）+ 力导向确定性布局 + 顶部 KPI + 悬停精确面板 + 真实操作驱动。概念 8/9/11 正式摒弃，仅 9 留作「负面对照教材」。
- **约束㉖（最重要）**：**已认可版本勿在其上堆新风格层；连续否定某方向时，优先回退到上一认可版，而非继续打补丁。** 概念 12 的 v3→v5 连续三版加层即反面教材。

## 4. 单个原型怎么运行与校验

- **运行**：浏览器直接打开 `概念/<名称>/*.html`（Chrome/Edge 打开本地文件最稳，无需服务器 / 构建 / npm）。
- **语法校验**：抽取内联 `<script>` 跑 `node --check`；或零依赖 CDP（Node22 内置 WebSocket 连系统 Chrome）无头探针，断言零报错 + 交互数值对（如点亮 +1、收卡计数 +1）。
- **诚实限制**：headless 只能证「能渲染 / 零报错 / 交互数值对」，**判不了审美**——任何视觉 / 手感改动必须由用户在真实浏览器确认。

## 5. 接手建议 · 下一步能做什么

- **继续打磨某「通过方向」**：在已认可框架内做小幅审美迭代（如概念 10/12 的卡片排版、弹簧手感、翻面速度、图谱排布），**不要换母题、不要加新风格层**。概念 12 当前定格 v2，详见其专属接手包。
- **开新概念**：先回到概念 10/12 共识基线，先与用户对齐母题再动手（约束⑨：同母题连否 2 次就换）。优先非时序、高密度离散、自然边界、信息可视化优先。
- **落地评估**：若某方向被用户最终认可，下一步是「仅新增 `src/gfx/` 集成」阶段（见各概念开发日志「待评审」段），仍须守客户端红线（见下）。

## 6. 操作红线（动手前必看）

- 仅改 `docs/` 原型与文档；**绝不碰** 看板娘层 / `App.cpp` / `TopBar.cpp` / `Store.*` 等客户端代码。
- 提交只 `git add` 本次新增 / 修改文件，**勿 `git add -A`**（曾因误 add 删光 `src/`，见通用铁律）。
- 每次迭代**先记开发日志再改代码**，并**滚动总结用户反馈**防创意偏离（用户明确要求的协作习惯）。

- **Q：为什么有些概念只有 html、没有介绍/日志？** A：早期概念（砚心/墨脉/活字印知）文件在 `docs/` 顶层，且未配齐三件套；后续概念（叠笺起）统一收进子文件夹并带 介绍+原型+开发日志 三件套。
- **Q：概念 12 卡片那堆「塔罗封面/抽卡光晕/四层变换」漂亮设计呢？** A：都做过、都被否了、已回退 v2。以 v2 为唯一基线，详见 `概念/识海星砂/` + 其专属接手包。
- **Q：三通道颜色（色相=学科/纯度=难度/明暗=掌握度）还在吗？** A：在，是概念 12 通过关键加分项，保留（约束⑬ 数据着色豁免）。
- **Q：为什么概念 3/4/6 文件夹不见了？** A：被用户废弃删除，方向已否决，无需接手。
- **Q：更全的项目交接（构建/服务端/架构）在哪？** A：`DesktopApp/docs/协作与交接手册.md`（本项目总入口），本包只覆盖「动效概念设计」子集。
