## 0. 一句话了解这个项目

**芙洛理 Flori** 是一个**原生 Windows 桌面应用**（Win32 + D3D11/D2D/DirectWrite 自绘 UI，**零第三方依赖**），给考公/考研同学做「打卡 + 专注 + 复盘」的本地优先工具；可选的**自有 Node 服务端**（`Server/`，零框架）提供云端备份、多端同步、实时自习室、公共专栏。

- 不连服务端也能用（纯本地）；连上后多一层云端 + 社交。
- 判断「现在能做什么」**以代码 + 本文档 + `客户端现状对齐.md` 为准**，旧 PM 文档（`芙洛理·产品管理建议…`、`芙洛理·高优先级任务分派清单.md`）仅作创意/方向参考，其描述的「WebApp 形态」已是历史。

## 2. 开发环境（工具链版本）

| 需要 | 版本/说明 | 备注 |
| --- | --- | --- |
| Windows 10/11 | x64 | 仅 Windows（桌面端） |
| **Visual Studio Build Tools** | 含 **C++ 桌面开发** 工作负载（VC.Tools.x86.x64） | `vswhere` 自动定位；2022 版验证可用 |

| **Ninja** | 随 VS 附带 | 构建生成器 |
| **MSVC** | C++20（`/std:c++20`）、`/utf-8` | `CMakeLists.txt` 已设 |
| **Node.js** | ≥ 18（服务端） | `node -v` 确认；服务端零依赖，**不用 `npm install`** |
| **Git** | 任意新版 | 版本控制 |
| Python | 仅构建脚本偶尔用到 | 非必须 |

> 不需要任何第三方 C++ 库 / npm 包。系统库白名单见 `CMakeLists.txt`（`d3d11/dxgi/d2d1/dwrite/d3dcompiler/windowscodecs/dwmapi/shcore/user32/ole32/shell32/winhttp/ws2_32/bcrypt + 媒体 mfplat/xaudio2 + imm32 + psapi`）。

## 3. 构建客户端（从源码编译 Flori.exe）

### 方式 A · Git Bash（推荐，脚本化）
```bash
cd "R:/WorkBuddy/Study Plan/DesktopApp"
source tools/msvcenv.sh          # 装配 MSVC 环境（等价于 vcvars64.bat）
cmake --build build --target Flori # 增量构建，产物 build/Flori.exe
```
首次构建若 `build/` 不存在，先生成：
```bash
source tools/msvcenv.sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=RelWithDebInfo
cmake --build build --target Flori
```

### 方式 B · 双击 `build.bat`（cmd）
自动定位 VS / CMake / Ninja 并构建，产物 `build/Flori.exe`。可选参数传配置：`build.bat RelWithDebInfo`。

### 契约回归测试（可选，验证 §3/§4/§5 协议）
```bash
# 先起 Server（见第 4 节），再跑：
source tools/msvcenv.sh
cmake --build build --target ws_contract_test
./build/ws_contract_test.exe     # 连运行中的 Server，7 下行 + §4/§5 REST，全绿通过
```

### ⚠️ ABI 陷阱（必读，否则启动段错误 139）
`main.cpp` 里 `lj::App app;` 是**栈分配**，其大小取决于所有被它持有的成员头。若你改了影响 `sizeof(App)` 的头（典型：`TopBar.h`、`App.h`、任何 App 直接持有的视图/成员头），**必须**强制重编 main：
```bash
touch src/main.cpp && cmake --build build --target Flori
```
只改 `.cpp`、或改「不被 App 直接持有布局」的头（如 `Store.h`/`FocusTracker.h`/`RoomView.h`，它们仅被各自 `.cpp` include）则**没有**此问题。详见 `任务清单.md` 第三节。

### 起客户端
- **同机最省事**：直接双击 `DesktopApp\build\Flori.exe`。演示账户 `demo` 会自动连本机 `127.0.0.1:8787`（自动连云端补丁），等 2~3 秒握手。
- **跨机（局域网）**：在客户端机器建 `DesktopApp\build\accounts\cloud-config.json`：
  ```json
  { "host": "192.168.1.100", "port": 8787, "secure": false, "enabled": true }
  ```
  并在服务端机器放行防火墙 `New-NetFirewallRule -DisplayName "芙洛理服务端" -Direction Inbound -Port 8787 -Protocol TCP -Action Allow`。
- **纯单机**：直接双击 `Flori.exe`，所有功能本机可用，只是没有云端/社交。

> 详细使用/排查见 `小白上手指南.md` 与 `本地网络联通与云端存储使用说明.md`。

## 5. 项目结构与架构速记

```
DesktopApp/                        原生 Windows 客户端（C++20 / D3D11+D2D，零依赖）
  src/core/    App（主循环/路由/帧循环）、Window（Win32 窗口）、FocusTracker（前台检测）、
               TrayIcon（托盘）、Hwnd（句柄/IME 辅助）、Screenshot（自检截图）
  src/gfx/     Graphics（D3D11 交换链 + D2D target）、PaperShader（纸纹）
  src/ui/      Canvas（自绘图元）、Router（视图切换）、Widget/FieldText（IME 助手）、
               Glyphs（矢量图标）、FloatingPlayer（全局浮空播放器）、ImageViewer、Layout/Motion/Theme/Input
  src/net/     Http（WinHTTP REST）、Realtime（手写 RFC6455 over Winsock + bcrypt）
  src/app/     AccountStore（本地账户+会话缓存）、Cloud（云端对接）、Data/Store（本地持久化）、
               PlanTemplate（方案模板）、Updater（自动更新）、Json（极简手写解析）
  src/audio/   MusicPlayer（MF 解码 + XAudio2）
  src/views/   17 个视图：Loader/Cover/Home/Dash/Checkin/Room/Roadmap/Materials/Media/
               Video/Profile/Plan/Advisor/Achieve/Friend/Login/Manage/Stub
  tools/       msvcenv.sh（MSVC 环境）、ws_contract_test.cpp（契约测试）、ci.bat（CI）、
               studyplan.iss / studyplan.nsi（安装器）、

Server/                           自有 Node 服务端（零框架，仅系统模块 + 必要 ws 实现）
  server.js                      入口，0.0.0.0:8787，REST + 同源 WebSocket
  src/routes/    auth / sync / columns / media / friends
  src/core/      users / sync / columns / friends / auth
  src/realtime/  ws.js（RFC6455 升级/帧解码/心跳）、gateway.js（事件网关）
  src/util/      fsjson / http
  tools/smoke.js                服务端冒烟自检（51 项）
```

**关键架构事实**
- **本地优先云同步**：UI 线程不碰网络 IO；后台线程写受锁源 + 置 atomic dirty 标记，`Update` 消费快照、`Paint` 只读。
- **渲染约束**：swap chain 必须 `SEQUENTIAL`（blit）；D2D target 必须 `TARGET | CANNOT_DRAW`；转场只用位移 + 不透明绘制（禁 PushLayer/离屏位图）；EDIT/RichEdit 是 GDI 子窗口，主窗口须 `WS_CLIPCHILDREN` 且禁每帧 RedrawWindow。
- **网络**：REST=WinHTTP（Bearer 鉴权，同端口同源）；WS=`Realtime` 手写 RFC6455 over Winsock（弃用 WinHTTP WS）。服务端帧/掩码语义严格符合 RFC6455。
- **账户隔离**：数据按 `accounts/<name>/*.json` 落盘；演示账户用户名 `demo`，**口令不写进任何文档**——见 `Server/src/config.js` 的 `DEMO_PASS`，或用环境变量 `FLORI_DEMO_PASS` 覆盖后再对外分发（S0-3）。
- **本地口令哈希**：`accounts.json` 的 `passHash` 为 `pbkdf2$<迭代数>$<盐>$<派生>`（CNG PBKDF2-HMAC-SHA256，60 万次）。历史 16 位 FNV 记录登录成功时自动升级，无需手工迁移。

## 6. 关键约定与坑（速查）

完整版见 `任务清单.md` 第三节。最常踩的：
1. **ABI 陷阱**：改 App 布局头 → `touch src/main.cpp` 再构建，否则启动段错误 139。
2. **EDIT 合成**：主窗口 `WS_CLIPCHILDREN`；禁每帧 `RedrawWindow(EDIT)`（频闪）。
3. **swap chain**：必须 `SEQUENTIAL`；D2D target 必须 `CANNOT_DRAW`（去它会启动失败）。
4. **转场**：只位移 + 不透明；禁整页 PushLayer / 离屏位图（黑屏/崩溃）。
5. **WM_SETCURSOR**：`IsChild` 统一放行子窗口（含 RichEdit）。
6. **零第三方依赖**：系统库白名单见 `CMakeLists.txt`；引入 npm 包/C++ 库需评审。
7. **中文 IME**：隐藏 EDIT 代理；`HideCaret` 压原生光标 + `EM_SETSEL(len,len)` 防抖。
8. **提交风格**：「模块: 短描述」中文（如 `RoomView: 白名单弹层增删`）；ABI 头改动在描述点明 `touch src/main.cpp`。

## 7. 自检清单（每次提交前跑）

```bash
# 客户端：构建 + 17 路由无头自检（全 exit=0）
source tools/msvcenv.sh && cmake --build build --target Flori
for r in loader home room plan advisor roadmap materials media video profile achieve dash manage login checkin arch settings; do
  ./build/Flori.exe --shot --route $r --at 0 || echo "FAIL $r"
done
# 弹层类加 --preview / --popup；长列表加 --scroll

# 服务端：冒烟（51 项全绿）
```
