# 层积 · 岩芯时序（概念 9）

> 复盘界面里的时间岩芯剖面。数据**显性可读**——坐标轴、数值刻度、悬停精确值、拖动框选实时聚合——动效退为受控增强。

## 1. 设计回应（为什么是它）
- 直接修复概念 8「弦」被否的根因：**「艺术有趣但无法直观获得信息、实用性低」**。本概念把**信息可读性**放在第一位。
- 三重可读保障：① 带刻度 Y 轴 + 数值标签的几何柱；② 悬停弹出当天精确数值；③ **拖动框选任意区间 → 顶部 KPI 实时聚合**（均值专注 / 总考点 / 平均正确率 / 最长连续）。

## 2. 落点与数据映射
- 落点：芙洛理 **复盘** 真实界面（tabs + 顶栏 + 距国考倒计时）。
- 每天 = 一段竖直「岩芯柱」，由可读几何编码：
  - **专注**（琥珀柱，高度 ∝ 专注分钟，含岩芯层理横纹）= 主读信息；
  - **正确率**（柱右细青灰柱，高度 ∝ 正确率；**薄弱日标红**）= 次读；
  - **考点**（柱左小点簇，点数 = 收集考点数）；
  - **连续打卡**（基线朱砂连线，连接相邻打卡日）。

## 3. 动效语言（真实操作驱动、克制、零辉光、确定可控）
- **悬停** → 当天岩芯高亮 + 侧栏精确数值（专注/考点/正确率/连续/时政）。
- **拖动框选** → 选中区间高亮 + 顶部 KPI 切到该区间实时聚合读数（核心「直接获取信息」交互）。
- **单击** → 标记今日，确定式 +42 生长（弹簧缓动 + 节点脉冲）。
- **滚轮** → 平移 28 天时间窗（可回看前 90 天）。
- **Esc** → 清除选区。
- 无 idle 空浮、无随机奖励、非游戏；所有运动来自真实输入。

## 4. 技术实现
- **Canvas2D 单文件原型**：信息密集（坐标轴/文字/精确值/聚合）场景下 Canvas2D 比 WebGL 更清晰可靠，且无 shader 黑屏风险、无加性辉光（契合零辉光铁律；GPU shader toolkit 的「避免 overdraw/辉光」原则亦支持此选择）。
- **确定性演示数据**（LCG），与概念 7/8 同源，距国考 105 天、默认显示今日。
- 窗口 `_agg(a,b)` 暴露区间聚合，供 headless 直接验证信息计算正确性。

## 5. 校验结果
- `node --check` 内联脚本：**SYNTAX_OK**。
- puppeteer-core + Chrome ANGLE/SwiftShader 1366×860：
  - 零 console / page error；RAF 运行；岩芯柱被画出（lit > 0）。
  - 区间聚合验证：全 90 天 → 均值专注 162 / 总考点 313 / 最长连续 17；末 10 天 → 均值专注 175 / 均值正确率 36。
  - 标记今日：211 → 252.68（确定式 +42，弹簧收敛）。
- html-review（交互式 Canvas 子集）：结构完整 + 安全——无 `eval` / `innerHTML` 注入 / 外链脚本 / XSS。文档排版令牌（--fs-body 等）对交互原型 N/A。

## 6. 诚实限制
- headless 只能验证「能渲染、零报错、信息计算正确、交互生效」，**无法判断观感**（柱体比例、配色协调、框选手感）。须在真实浏览器（Chrome/Edge）体验。
- 若真机觉得柱太密/配色刺眼/想换隐喻（如真正的地质岩芯切片而非柱状），可继续打磨。
