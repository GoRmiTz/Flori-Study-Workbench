## 概念 1 · 墨脉 MoMai —— 知识脉络脉冲（本次）
- 日期：2026-08-16
- 全新隐喻（不重复砚心）：知识点=脉络节点，悬停/点击令"脉气"沿脉络传播点亮关联。
- 动效语言：
  - 悬停节点 → 脉冲沿二次贝塞尔脉络传播，相邻节点按 BFS 深度衰减点亮（最大深度 2，确定可控，不失控）；
  - 点击 → 通/取消该脉络（弹簧深化 + 朱砂环），顶部"已通脉络 N / 总"轻量进度（仅信息、无计分）；
  - 拖拽平移 / 滚轮缩放（惯性阻尼，必落座）；
  - 切换 知识库↔复盘 → 整图编排式重排（放射布局 ↔ 分组列布局，节点各自速度错位抵达）。
- 技术：Canvas2D 主舞台 + 受控 WebGL 墨晕背景（shader 编译/链接校验 + try/catch，失败即隐藏、CSS 纸纹兜底，杜绝黑屏）；自动演示常开（可关）以保证受限预览里也有动效。
- 文件：`docs/墨脉·动效概念原型.html`、`docs/墨脉·动效概念介绍.md`。
- 校验：node 内嵌 JS 语法通过；静态核查 sendPulse/updatePulses/bez/veinCtrl/drawGL/initGL 齐全；zoom 恒∈[0.5,2.2] 无除零，pulses 有深度上限无 NaN/失控。
- 诚实限制：headless 无法验证观感，需用户在浏览器目视确认（Chrome/Edge 直接打开本地文件最稳）。

## 概念 1 修复 · 显示 bug（2026-08-16）
- 现象：整图只显示在左上角、太密集、显示不全。
- 根因：① `resize()` 在脚本底部同步调用，`getBoundingClientRect()` 在 flex/绝对定位布局未 flush 时拿到 canvas 默认 300×150，节点据此全挤在 (150,75) 附近且后续无 resize 事件回不来；② 放射布局半径偏小（0.30/0.14×min）+ 无自动适配，整图未缩放居中。
- 修复：① 启动改到 `requestAnimationFrame`+`load` 之后，`resize` 加尺寸兜底（w/h<2 时回退 window 尺寸−顶栏）；② 新增 `fitView()` 自动把整图缩放居中铺满视口（zoom 钳 [0.5,1.6]）；③ 拉大布局半径（0.38/0.16×min）与字间距；④ 拖拽/滚轮置 `userMoved`，已交互则不强制重适配；⑤ 脉冲粒子 11→7 降噪。
- 校验：JS 语法通过；fitView 数值正确（zoom 有界、居中映射无 NaN）。仍须浏览器目视确认观感。
