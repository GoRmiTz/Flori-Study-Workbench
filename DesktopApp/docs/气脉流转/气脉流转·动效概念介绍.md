# 气脉 · 流转 — 专注能量场（概念 11）

> 非时序 · 单主色墨青 · 连续标量场 + 等值线 · 信息可视化优先 · 真实操作驱动 · 零辉光 · 确定可控 · 非游戏

## 1. 母题与立意
把"专注投入 / 能力强度"画成一张**二维连续标量场**，而不是一根时间轴、也不是一堆方块柱。

- 横轴 = **学科**（行测 / 申论 / 常识 / 时政 / 专业课）
- 纵轴 = **维度**（理解 / 记忆 / 运用 / 熟练）
- 平面上 20 个采样点 = (学科 × 维度)；每个点的**掌握度 0..1** 通过高斯 IDW 插值成一张平滑的"能量场"。

场强高 = 该处能力强；场强低洼 = 薄弱。整张图就像一张"能力地形图"，一眼看见强弱分布——**这正是信息可视化的直接可读**，且彻底告别时间轴与方块堆叠。

## 2. 信息编码（图表本体先于动效）
| 视觉通道 | 表达的数据 | 说明 |
|---|---|---|
| **明度（单色墨青，暗→亮）** | 场强 / 掌握度 | 维度靠明度层次区分，不靠撞色 |
| **等值线（细线，4 条）** | 25% / 45% / 65% / 85% 强度带 | 勾出强弱等高带，一眼读"哪里强哪里洼" |
| **采样点小圆点（大小/亮度）** | 该 (学科·维度) 掌握度 | 不画方块，只画细点 |
| **红叉标记** | 薄弱点（掌握度 < 40%） | 直接点名"哪里弱" |
| **顶部 KPI 条** | 峰值 / 均值 / 高强区占比 / 薄弱点数 / 总体掌握率 | 全局一眼可读 |
| **悬停探针** | 任意点强度% + 所属学科·维度 | 直接获取信息，不靠猜 |

## 3. 真实操作驱动（确定可控 · 非游戏）
- **悬停** 任意处 → 探针十字环 + 读数面板（受控，不自动乱跑）。
- **点击 / 拖动** 在某 (学科·维度) 上 → "注入专注"：该采样点掌握度 `target=1`，场强局部抬升；临界阻尼弹簧收敛（不失控、不空浮）。拖过多个点 = 连续复习多个点。
- **滚轮** 缩放视场（围绕中心，有界钳制）。
- **自动演示**：开局 1.6s 自动抬升最弱项一次（展示"场随输入变化"），一枚缓动虚线探针环轻轻巡游；用户一交互即停。

## 4. 视觉红线（直接回应前几版的失败）
- **告别方块堆叠** → 连续面 + 细等值线，全图无一根柱、一块色块。
- **配色克制和谐** → 仅一个主色（墨青 190°），靠明度层次与位置表达维度，零撞色。
- **零辉光** → 仅平涂明度面（上采样平滑是抗锯齿，非加性发光）+ 细描边；无光球、无 bloom。
- **深炭底 + 细轴网**（减法层次，非加性渐晕）。

## 5. 与概念 10「考点星图」的关系
概念 10 是**点**（拓扑网：节点=考点，细线=关联）；概念 11 是**面**（连续场：学科×维度的能力地形）。两者共用你认可的新基线配方（非时序 / 单主色 / 细线 / 信息可读 / 真实操作驱动 / 零辉光），但母题不同——形成"点-面"互补，避免同一母题连否。
