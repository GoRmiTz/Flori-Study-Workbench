# 客户端现状对齐（Reality vs 旧文档）

> 起草：2026-08-10 ｜ 用途：让新接手者 5 分钟分清「代码现实」与「旧 PM 文档」
> 适用范围：本仓库 `DesktopApp/`（原生桌面端）。`WebApp/`、`Server/` 另见各自文档。

---

## 0. 一句话结论（最重要）

**芙洛理客户端已经 pivot 为「原生 Windows 桌面端 + 自有 Node 服务端」形态，不再是基于浏览器的 WebApp。**
旧 PM 文档（2026-08-02 / 08-03 描述的 `WebApp v1.9.12` + `localStorage`）描述的是**早期形态**，仅作历史参考，**不能用来判断当前代码能做什么**。

判断功能是否落地，**以代码 + 本目录下 `架构速记.md` / `开发日志.md` / `云端对接设计·客户端§3-§5.md` 为准**。

## 1. 形态对照表（旧文档 → 现实）

| 维度 | 旧 PM 文档描述 | 代码现实（2026-08-10） |
| --- | --- | --- |
| 运行形态 | WebApp（浏览器 / WebView） | 原生 Win32 窗口 + D3D11/D2D/DirectWrite 自绘 UI |
| 第三方依赖 | 框架（React/Vue/Electron 等） | **零第三方依赖**（系统库白名单：d3d11/dxgi/d2d1/dwrite/d3dcompiler/windowscodecs/dwmapi/shcore/user32/ole32/shell32/winhttp/ws2_32/bcrypt + 媒体 mfplat/xaudio2） |
| 数据存储 | `localStorage` | 本地文件系统（`accounts/<name>/*.json`）+ 服务端云端（`Server/` 自有 Node 服务，REST 8787 + 同源 WebSocket） |
| 同步模型 | 浏览器端缓存 | **本地优先云同步**：UI 线程不碰网络 IO；后台线程写受锁源 + 置原子 dirty 标记，消费快照渲染 |
| 跨端 | 移动端为主 | 桌面为主（Windows-only），移动端为待验证方向（见 P2） |
| 实时能力 | WebSocket（服务端） | 客户端 `src/net/Realtime.cpp` 手写 RFC6455 over Winsock + CNG，连自有 Server |

## 2. 真实架构（当前）

```
DesktopApp/               原生 Windows 客户端（C++20 / D3D11+D2D，零依赖）
  src/core/               App（主循环 / 路由切换 / 帧循环）
  src/gfx/                Graphics（D3D11 交换链 + D2D target）、PaperShader（纸纹着色器）
  src/ui/                 Canvas（自绘图元）、Router（视图切换）、Widget/FieldText、
                          Glyphs（矢量图标）、FloatingPlayer（全局浮空播放器）、ImageViewer
  src/net/                Http（WinHTTP）、Realtime（WS）
  src/app/                AccountStore（本地账户 + 会话缓存）、Cloud（云端对接）、Data/Store
  src/audio/              MusicPlayer（MF 解码 + XAudio2）
  src/views/              DashView / RoadmapView（云端专栏）/ RoomView（实时自习室）/
                          MediaView / VideoView / ProfileView / ManageView / FriendView /
                          LoginView / LoaderView / CoverView / CheckinView / StubView
  tools/                  msvcenv.sh（MSVC 环境）、ws_contract_test.cpp（契约测试）、ci.bat（CI）

Server/                  自有 Node 服务端（零框架，仅系统模块 + 必要的 ws 实现）
  server.js              入口，0.0.0.0:8787，REST + 同源 WebSocket
  src/routes/            columns / media / auth
  src/core/              users / sync
  tools/smoke.js         服务端冒烟自检（51 项）
```

**关键事实**
- 转场已回退为「纯位移 + 页面始终不透明绘制」（稳定，无黑屏 / 不崩）。
- 登录页 `LoginView` 已在路由注册：退出登录 / 未登录点顶栏胶囊均进入登录页。
- 会话靠 `session.json` 缓存：首次需登录，之后启动自动重登（不需要重复输入密码）。
- 浮空播放器常驻：切到任意页面音乐不中断；暂停键为矢量图标（非表情蓝方块）。

## 3. 旧文档里「有」但当前「不在客户端」的东西（避免误判）

- 旧文档的 `localStorage` 数据模型 → 实际是本地文件 + 服务端，不存在 `localStorage`。
- 旧文档的「WebView / 跨端热更新」→ 实际无 WebView，无热更新，纯原生编译。
- 旧文档把「公共专栏 / 实时自习室」当网页功能 → 实际是原生客户端通过 `Cloud`/`Realtime` 连自有 Server 实现。
