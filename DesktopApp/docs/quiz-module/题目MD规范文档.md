# 题目 MD 规范文档（练考模块 · 软件↔AI 契约）

> 本文档是「时政练考 / 模考」模块的地基契约：**AI 按此格式产出 `.md`，软件按此格式解析渲染**。
> 任一方偏离都会让题目无法识别，因此这是实现前必须先冻结的规范。
> 设计目标：① 人能直接读写（纯 Markdown）；② 软件能用极简状态机零歧义解析；③ 选项位置固定（A–E），便于右侧答题卡对齐。

---

## 1. 文件结构

- 扩展名：`.md`
- 编码：UTF-8（无 BOM）
- 命名建议：`<日期或卷名>.md`，如 `2026-08-15.md`、`2026国考行测模考卷一.md`
- 存放位置：**指定文件夹**（默认 `accounts/<账户>/quiz/<类别>/`，如 `quiz/时政/`、`quiz/模考/`；位置可在设置中修改）

---

## 2. 文档骨架（两段）

```
---            ← 第 1 段：YAML 元数据（考试/卷信息）
title: ...
date: ...
category: ...
mode: ...
duration: ...
source: ...
model: ...
---            ← 结束元数据

# 卷标题        ← 第 2 段：正文（标题 + 若干题目）

> 卷首说明（可选，Markdown 引用块）

## Q1
**题干**：……
选项 / 题型 / 答案 / 解析 / 知识点 / 难度

## Q2
……
```

---

## 3. 第 1 段：YAML 元数据（Frontmatter）

位于文件头，由两个 `---` 包裹。字段全部**可选但有推荐值**：

| 字段 | 含义 | 取值 / 示例 | 必填 |
|---|---|---|---|
| `title` | 卷标题 | `2026-08-15 时政每日一练` | 推荐 |
| `date` | 日期 | `2026-08-15` | 推荐 |
| `category` | 类别 | `时政` / `模考` / `常识` / `行测` | 推荐 |
| `mode` | 模式 | `quiz`（日练，不限时）/ `exam`（模考，限时） | 推荐 |
| `duration` | 模考总时长（分钟） | `120`；`0` 或省略=不限时 | 仅 exam |
| `source` | 来源 | `AI生成` / `人工` / `导入` | 可选 |
| `model` | 生成所用模型 | `deepseek-v4-flash` | 可选 |

解析规则：取第一个 `---` 与第二个 `---` 之间的文本，按 `key: value` 逐行读取；忽略未知字段。

---

## 4. 第 2 段：题目块（核心）

每道题以 `## Q<序号>` 标题开始（序号从 1 递增，决定题目排序）。题块持续到下一个 `## Q` 或文件结束。

### 4.1 题干（stem）
- 优先使用显式行：`**题干**：……` 或 `题干：……`
- 也兼容把标题后同一行的剩余文本作为题干（如 `## Q1 2026年中央一号文件聚焦的主题是？`）
- 解析时：先取 `题干` 行，若无则取 `## Qn` 标题后的文本。

### 4.2 选项（options）★位置固定
每行一个选项，格式：
```
- A. 选项文本
- B. 选项文本
```
**解析正则**：`^\s*-\s*([A-E])[.)、]\s*(.+)$`
- 字母 `A–E` 即选项位置，按出现顺序收集；**软件严格按字母渲染答题卡 A/B/C/D**，AI 必须保证 A–E 连续无跳号。
- 支持 2–5 个选项（判断/单选常为 4 个，多选可 4–5 个）。

### 4.3 题型（type）
行含 `题型` 关键字，取值 `单选` / `多选` / `判断`（默认 `单选`）：
- `单选`：答案为单个字母。
- `多选`：答案为多个字母（如 `ABD`）。
- `判断`：选项固定为 `A. 正确` / `B. 错误`（AI 可显式写出，也可只写答案 `正确/错误` 由软件映射到 A/B）。

### 4.4 答案（answer）★关键字段
行含 `答案` / `正确选项` / `正确答案`，后接字母：
- 单选：`答案：A`
- 多选：`答案：ABD`（字母连写或空格分隔均可，解析时去重排序）
- 判断：`答案：正确` / `答案：A`

### 4.5 解析（explain）
行含 `解析` / `详解` / `解答`，后接文本；**可跨多行**，直到遇到下一个字段行（`题型`/`答案`/`知识点`/`难度`/`## Q`）或文件结束。也兼容 `> 解析内容` 引用块写法。

### 4.6 知识点（point）· 难度（difficulty）· 可选
- `知识点：中央一号文件` —— 用于复盘薄弱点聚合。
- `难度：1` —— 整数 1–3（1 易 / 2 中 / 3 难），用于统计。

## 5. 完整示例

````markdown
---
title: 2026-08-15 时政每日一练
date: 2026-08-15
category: 时政
mode: quiz
source: AI生成
model: deepseek-v4-flash
---

# 2026-08-15 时政每日一练

> 本卷由 AI 依据近期时政自动归纳，仅供练习；提交后显示答案与解析。

## Q1
**题干**：2026 年中央一号文件聚焦的主题是？
- A. 乡村振兴与粮食安全
- B. 科技创新引领新质生产力
- C. 生态文明与绿色发展
- D. 扩大内需与消费升级
**题型**：单选
**答案**：A
**解析**：2026 年中央一号文件继续把推进乡村全面振兴作为主题，并把粮食安全摆在突出位置……
**知识点**：中央一号文件
**难度**：1

## Q2
**题干**：下列哪些属于 2026 年政府工作报告提出的重点工作任务？（多选）
- A. 因地制宜发展新质生产力
- B. 深入推进生态文明建设和绿色低碳发展
- C. 全面取消高考
- D. 扩大高水平对外开放
**题型**：多选
**答案**：ABD
**解析**：2026 年政府工作报告明确……C 项与事实不符，为干扰项。
**知识点**：政府工作报告
**难度**：2

## Q3
**题干**：《民法典》自 2021 年 1 月 1 日起施行。
- A. 正确
- B. 错误
**题型**：判断
**答案**：A
**解析**：《中华人民共和国民法典》确实于 2021 年 1 月 1 日施行，同时废止原有单行法。
**知识点**：民法典
**难度**：1
````

## 6. 解析器契约（软件侧实现要点）

输出结构（C++）：
```cpp
struct QuizOption { std::wstring key; std::wstring text; };   // key="A".."E"
struct QuizQuestion {
    int id; std::wstring type;        // "单选"|"多选"|"判断"
    std::wstring stem;
    std::vector<QuizOption> options;  // 按 A–E 顺序
    std::vector<std::wstring> answer; // 正确 key 集合，如 {"A"} 或 {"A","B","D"}
    std::wstring explain, point;
    int difficulty = 1;
};
struct QuizDoc {
    std::wmap<std::wstring,std::wstring> meta;  // title/date/category/mode/duration/...
    std::wstring title;
    std::vector<QuizQuestion> questions;
};
```

解析状态机：
1. 读 frontmatter（首个 `---` 到次个 `---`）。
2. 扫描正文，遇 `## Q<num>` 开新题；其余按行匹配：
   - 题干行 → `stem`
   - 选项行（正则 4.2）→ `options`
   - `题型` / `答案` / `解析` / `知识点` / `难度` → 对应字段（`解析` 允许多行累积）
3. 容错：缺选项或缺答案的题**跳过并记日志**；缺 `题型` 默认单选；`答案` 为空则标记"待批改"。

判分规则：
- 单选/判断：所选 == 答案集合 → 对。
- 多选：所选集合 == 答案集合（无序、去重）→ 对；少选/多选/错选 → 错。

## 7. AI 出题提示词模板（生成器使用）

> 把以下模板作为 system + user 拼给 OpenAI 兼容 `/chat/completions`，要求模型**只输出符合第 2–5 节的纯 Markdown，禁止外层代码围栏、禁止多余闲聊**。

```
你是一位考公（公务员/选调生考试）出题专家。请依据用户提供的「日期」与「近期时政摘要」，
生成一套 N 道题目的练习卷，严格按下面的 Markdown 规范输出，不要输出规范以外的任何内容。

【输出格式规范】
- 文件以两个 --- 包裹的 YAML 元数据开头：title/date/category/mode/duration/source/model。
- 元数据后写 # 卷标题，可加一句 > 卷首说明。
- 每题以 ## Q<序号> 开头（序号从1递增）。
- 题干用 **题干**：开头一行。
- 选项每行为 "- A. 文本" / "- B. 文本" …… 字母 A–E 必须连续无跳号。
- 题型行：**题型**：单选 / 多选 / 判断。
- 答案行：**答案**：单选填 A，多选填 ABD，判断填 A 或 B。
- 解析行：**解析**：给出简明依据（引政策/事实）。
- 知识点行：**知识点**：如 中央一号文件。
- 难度行：**难度**：1–3。

【质量要求】
- 题干贴近行测常识/时政真题风格，选项为 plausible 干扰项（基于真实易错点，不要荒诞填充）。
- 每题必须有解析、知识点、难度。
- 判断题型选项固定 "A. 正确" / "B. 错误"。
- 仅使用给定日期前可确认的事实；不确定则不出。
- 输出纯 Markdown，不要 ``` 代码块包裹，不要任何开场白/结尾备注。
```

user 部分示例：
```
日期：2026-08-15
近期时政摘要：（可选）[此处贴 RSS 抓取的当日要闻摘要，或留空由模型凭知识生成]
类别：时政
题量：10
```

---

## 8. 红线（与全局隐私一致）

- AI 请求体**只允许**包含：日期、类别、题量、可选的 RSS 时政摘要文本；**绝不**包含窗内文本、截图、路径、URL、用户私人数据。
- 生成的 `.md` 仅落本地指定文件夹，不自动上传；如需同步须经用户显式操作。
- 解析失败的题目不影响其它题，整体卷仍可打开。
