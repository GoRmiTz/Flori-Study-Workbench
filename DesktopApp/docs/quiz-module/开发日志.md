## 0. 总览与铁律（先读这段，避免踩雷）

### 0.1 模块目标
用 AI（OpenAI 兼容 API）**每日定时**搜集/归纳最新时政，按考公题目样式出卷（单选/多选/判断），编成符合《题目MD规范》的 `.md` 放入指定文件夹；软件读取后以「专栏详情式居中卡片 + 右侧答题卡」呈现，支持选答、提交判分、解析展开；引擎复用于**模考**（限时 + 倒计时 HUD + 收卷报告）；成绩/薄弱点落盘，形成「练→评→补」闭环。

### 0.2 技术栈
- 原生 Windows C++20（Win32 + D3D11/D2D1 自绘），**零第三方依赖**（练考不依赖任何第三方 SDK）。
- 真构建用 `build_obj/build_lj.sh`（**不是 cmake**）：遍历 `src/**/*.cpp` 逐个 `cl` 编译 → 链 `Flori.exe`。
- 落盘/JSON：`app/Json.h`（`lj::json` 命名空间，`Parser/JGet/JStr/ReadFileRaw/WriteFileRaw/JDump` 等，已提交可依赖）。
- 账户隔离：`app/AccountStore.h::CurrentRoot()` 返回 `<exe>/accounts/<账户>/`（尾分隔符，已提交）。

### 0.3 三条红线（违反即事故）
1. **提交纪律红线**：工作树除已提交历史外，叠了一层**未提交**看板娘实现（`src/kanban/`、`assets/kanban/`、`mods/`，及对 `Store.cpp/h`、`App.cpp`、`ExamMode.cpp`、`FloatLayer.cpp/h`、`Window.cpp`、`main.cpp` 的修改）。**绝不用 `git add -A`**；每次只 `git add` 我方明确文件，避免把整层卷进提交。
2. **隐私红线**：AI 出题请求体**仅含** 日期/类别/题量/可选 RSS 摘要；**绝不**喂窗内文本/文件路径/URL/私人数据；生成的 `.md` 仅落本地账户目录。
3. **解耦红线**：练考模块刻意**不耦合**未提交看板娘层——AI 凭据读 `kanban_ai.json` 本地文件（单一来源），不复用 `Store.h` 里未提交的 `AppSettings.kanban` 字段；成绩落盘走自包含 `QuizStore`，不依赖未提交 `ReviewEngine`/`CheckinStore`。

### 0.4 已知环境坑（headless 验证限制）
- `tools/regress.py --shot` 对**所有路由**（含 review 等既有路由）都 SHOT MISSING——截图路径被工作树未提交看板娘层破坏，故**无法跑像素 ZERO-REGRESSION**。练考模块仅经编译验证，外观/交互须真机 GUI 目视确认。

## 6. 通用构建 / 诊断技巧（沉淀，避免下次重踩）

- **编译失败先看 `build_obj/compile_failures.txt`**：`build_lj.sh` 把每个失败 .cpp 的 `error C` 行写进该文件（不含完整上下文）。若 LINK 报「无法解析的外部符号 `X::Y(void)`」，通常是因为该符号所在的 .cpp 编译失败、未产出 .obj → 先去 failures 文件找是哪个 .cpp 失败，再单文件重编定位。
- **单文件重编**：必须 `source tools/msvcenv.sh` 与 `cl` 在**同一条** Bash 命令里（Bash 不跨命令保留 INCLUDE/LIB/PATH）。完整 flags：
  ```
  source tools/msvcenv.sh
  B="R:/WorkBuddy/Study Plan/DesktopApp"
  cl /nologo /std:c++20 /EHsc /permissive- /utf-8 /Zc:__cplusplus /W3 /MD /Od /DNDEBUG /Zi /DUNICODE /D_UNICODE /DNOMINMAX /DWIN32_LEAN_AND_MEAN /DFLORI_SOURCE_DIR=\"$B\" -I"$B/src" /c "$B/src/<path>.cpp" /Fo"$B/build_obj/<path>.obj"
  ```
  ⚠️ 注意 `-I` 必须作为独立 token 传递，**不能塞进一个带内嵌引号的变量**再展开（会被词分割破坏，表现为 C1083 找不到头文件）。
- **命名空间**：`ReadFileRaw`/`WriteFileRaw`/`Parser`/`JGet`/`JStr`/`JDump` 都在 `lj::json`；从 `namespace lj` 里引用 `lj::quiz` 的类型（如 `QuizStore`）要写 `quiz::` 前缀。
- **始终只 `git add` 明确文件**，提交前 `git status --short -- <我方文件清单>` 复核，确认未提交看板娘层仍保持 ` M`/`??` 状态。
