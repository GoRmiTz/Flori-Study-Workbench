## 2. Godot版经验归纳.md — 跨技术栈经验

原 Godot 版（原生 C++ 壳 + Godot 4 子进程 + IPC）开发中沉淀的可复用原则：
IPC 三铁律、框架优先于游戏、视觉语言、信息可视化优先、动效铁律、帧率无关动效、
自动化验收套路、资产交付常见坑、概念原型管理纪律。**面向回归后的 C++ 零依赖桌面端直接复用。**
