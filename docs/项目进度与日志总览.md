## 0. 一句话现状

**芙洛理 = 原生 Windows C++ 桌面端（零第三方依赖）+ 自有零依赖 Node 服务端**，面向考公/考研备考的自律打卡应用。

## 6. 动代码前必知的坑（避坑精华，全文见 `DesktopApp/docs/任务清单.md` §三）

1. **ABI 陷阱（最致命）**：改了影响 `sizeof(App)` 的头（`App.h`/`TopBar.h` 等被 App 直接持有的）**必须 `touch src/main.cpp`** 强制重编，否则增量构建启动即段错误（139）。
2. **EDIT 是 GDI 子窗口**：主窗口须 `WS_CLIPCHILDREN`；禁每帧 `RedrawWindow(EDIT)`（频闪）；中文输入走隐藏 EDIT 代理 + IME 自绘 + `HideCaret`。
3. **swap chain 必须 `DXGI_SWAP_EFFECT_SEQUENTIAL`**（FLIP 不合成 GDI 子窗口）；D2D target 必须 `TARGET | CANNOT_DRAW`。
4. **转场只做位移 + 页面不透明**；禁整页 PushLayer 透明度、禁离屏位图（崩）。
5. **网络传输层**：WS 手写 RFC6455（勿用 WinHTTP WS）；UI 线程不碰网络 IO。
6. **更新三道闸**：拒明文 http / SHA-256 内存比对 / 落盘前二次校验；服务端必须回带 sha256。
7. **口令 PBKDF2**（60 万迭代，格式自带迭代数，旧 FNV-1a 登录时自动升级）；比较用定时安全比较。
8. **凭据红线**：API key/口令绝不硬编码、绝不入库；`kanban_ai.json` 本地独占、云端回写不可覆盖。
9. **零第三方依赖是架构红线**：新库一律先问；系统库白名单见 `CMakeLists.txt`。
10. **无 .git 的目录别用 `git check-ignore` 判断**（静默失败），直接读 `.gitignore` 原文。
11. **同一文件多次编辑勿并行**（工具链丢改教训，本次会话实测）。
12. **从现象出发诊断**：遇 Bug 先核实文件实际内容与真实报错，禁止猜测式改动。

# 17 路由无头自检（--at 1.5 必须，0 截到空帧）
./build/Flori.exe --shot build/shots/<route>.png --route <route> --at 1.5

# 视觉基线比对（基线各机生成、不入库）

node Server/tools/smoke.js     # 51 项冒烟
