    若按原样 `git add -A`，等于把授权 SDK 二进制与调试产物一起开源 → **授权违规**。现已全仓忽略。
  - `*.import` / `*.ctex` —— Godot 时代残留的导入描述文件（`shot.png.import` 的 `source_file` 指向

    `shot.png.import` 已删除。

### E. 构建缺陷修复（本轮顺带修复，非阻塞项但影响可编译性）

原仓库曾因看板娘层半接入第三方骨骼动画 SDK（默认关闭时仍引用其符号）导致**无法链接**；本轮已彻底删除该看板娘骨骼动画功能（源码/CMake/资源/工具/文档全清），仅保留 `PngBackend` 零依赖静态皮套。删除后原相关链接缺陷随之消除，仅余一处需保留的链接项：

1. **`LNK2019: __imp_GradientFill`** —— 看板娘 GDI 圆角渐变用了 `GradientFill`
   （`src/kanban/KanbanGfx.h` / `KanbanWindow.cpp`），属 `msimg32.dll`，但 `CMakeLists.txt`
   未链接 `msimg32.lib` → 已在 `target_link_libraries(Flori ...)` 补 `msimg32`。

修复后实测：**CONFIG_EXIT=0 / BUILD_EXIT=0**，产出 `DesktopApp/build/Flori.exe`（约 3.77 MB）。
