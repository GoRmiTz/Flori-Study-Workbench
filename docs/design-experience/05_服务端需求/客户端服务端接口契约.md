# 05-B · 客户端-服务端接口契约

> 继承自 `DesktopApp/docs/云端对接设计·客户端§3-§5.md` 与代码实现（`net/Http`、`net/Realtime`、`app/Cloud`）。本册为芙洛理定义**可直接实现的接口契约**。服务端零框架 Node（`Server/`），REST + 同源 WebSocket。

---

## 1. 传输与鉴权

- **REST**：`WinHTTP`（原生）/ Godot 侧用 `HTTPClient`；Bearer 鉴权，同端口同源。
- **WebSocket**：`Realtime` 手写 RFC6455 over Winsock+bcrypt（弃用 WinHTTP WS）；单后台线程，`On(type,cb)` 注册，回调只写受锁缓冲。
- **鉴权失效**：无效 token 服务端下发 `auth:err` → 客户端刷新并重连。
- **主机配置**：`accounts/cloud-config.json` `{"host","port":8787,"secure":false,"enabled":true}`；演示账户 `demo` 自动连 `127.0.0.1:8787`。

## 2. REST 端点（与需求清单对应）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/auth/register` | 注册（服务端哈希） |
| POST | `/auth/login` | 登录，返回 token |
| POST | `/auth/refresh` | 刷新 token |
| POST | `/auth/logout` | 退出 |
| GET | `/auth/me` | 当前用户 |
| GET/PUT | `/sync/checkin?date=` | 打卡块 |
| GET/POST | `/sync/focus` | 专注块 |
| GET/PUT | `/sync/items` | 打卡项 |
| GET/PUT | `/sync/journal?date=` | 日记 |
| GET/PUT | `/sync/rhythm?date=` | 作息 |
| GET/PUT | `/sync/settings` | 设置 |
| GET | `/columns` | 公共专栏列表 |
| GET | `/columns/:id/posts` | 专栏文章 |
| POST | `/posts` | 发布 |
| POST | `/posts/:id/like` | 点赞 |
| POST | `/posts/:id/comment` | 评论 |
| POST | `/media/upload` | 媒体上传（白名单） |
| GET | `/media/list` | 媒体列表 |
| GET | `/media/:id?sign=` | 媒体访问（签名 URL） |

> 同步载荷格式 = `*.flori.json`（见 `服务端需求清单.md` §0）。`PUT /sync/all?mode=merge` 推本地合并集，`GET /sync/all` 回拉。

## 3. WebSocket 事件（自习室/专栏/好友）

| 事件 | 方向 | 载荷 |
| --- | --- | --- |
| `room:join` | C→S | `{room,user}` |
| `room:leave` | C→S | `{room,user}` |
| `presence` | S→C | `{room,members:[...]}` |
| `chat:msg` | 双向 | `{room,user,text,ts}` |
| `music:meta` | S→C | `{title,url}` |
| `col:changed` | S→C | `{id,posts}`（专栏更新） |
| `auth:err` | S→C | 触发刷新重连 |

## 4. 数据 Schema（权威）

见 `服务端需求清单.md` §0 的 `*.flori.json` 结构：`checkin / focus / items / journal / rhythm / settings` 六块。所有同步接口复用同一结构，保证导出导入与云端同步零摩擦。

## 5. 芙洛理对接要点

- **原生壳保留** `Cloud`/`AccountStore`/`Http`/`Realtime` 对接逻辑。
- **Godot 子进程不直接联网**：经 IPC 向原生请求 deck、回传 `mark(known/weak)`（见 `01_架构设计` §3）；账户/同步/WS 全部在原生日侧。
- **演示账户/密钥**：绝不硬编码/入库；`FLORI_DEMO_PASS` 环境变量覆盖后对外分发（S0-3）。
