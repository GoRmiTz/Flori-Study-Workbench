# 芙洛理 Flori · 项目交接文档总包

> **本包目的**：把现有「芙洛理 Flori」桌面应用的全部功能、架构、代码、开发日志、设计红线、服务端需求、动效概念想法，**彻底梳理并重新组织**为一套结构清晰、足够详尽的多文件夹文档，供新成员**以 Godot 为核心从零重建「芙洛理」**。
> 文档全部基于 `DesktopApp/`（原生 C++ 客户端）与 `Server/`（Node 服务端）的真实代码与既有文档梳理而成，并非凭空设计。
> **动效概念原型（概念 18–29 等）仅作「想法库」存档，本次不开发**，待芙洛理架构就绪后由其他成员选材落地。

---

## 0. 一句话定位

**芙洛理 = 芙洛理的「重新设计 + 全面集成 Godot + 视觉升级」版本。**
- 继承芙洛理的全部功能逻辑（打卡 / 专注 / 复盘 / 练考 / 云端 / 看板娘）。
- 原生壳（C++ 数据/状态核心）保留，动效/游戏性体验层用 **Godot 4（MIT，桌面原生导出）** 重写。
- 视觉规范升级为「亮色纸底 + 墨线主导 + 零辉光 + 信息可视化优先 + 买点/价值闭环」。

## 2. 与原项目（芙洛理）的关系

| 维度 | 芙洛理（现状） | 芙洛理（目标） |
| --- | --- | --- |
| 渲染/动效 | D3D11 + D2D 自绘，手写游戏循环 | 原生壳保留数据层；动效/游戏性用 Godot 2D 承担 |
| 依赖 | 零第三方 C++ 依赖 | 原生壳仍零依赖；Godot 作为按需启动的外部子进程（MIT，无 royalty） |
| 视觉 | DOSSIER 暗/亮双主题，墨线 | 亮色纸底为主、墨线主导、零辉光、信息可视化优先 |
| 概念原型 | HTML 草图（18–29） | 想法库存档，定型后用 Godot 实现 |
| 买点 | 已有㉟铁律要求价值闭环 | 每个动效必须回传标记 → 原生侧落库 |

> ⚠️ **文档新鲜度提示**：芙洛理侧 `docs/架构速记.md`、`docs/协作与交接手册.md` 描述的是**早期 10–17 视图形态**，实际 `DesktopApp/src/views/` 已扩到 **21+ 视图**（新增 Advisor/Friend/ExamReport/Knowledge/Review/Quiz 等）。本包以**实际代码**（2026-08 状态，COMPILE_OK≈120）为准，并在 `03_源代码梳理/` 标注差异。
