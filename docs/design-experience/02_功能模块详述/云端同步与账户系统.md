# 02-E · 云端同步与账户系统

> 来源：`app/AccountStore`、`app/Cloud`、`app/Store`、`app/Updater`、`net/Http`、`net/Realtime`。数据/账户/云端是"零依赖核心"，芙洛理应完整继承并作为 IPC 数据底座。

## 1. AccountStore（账户/会话/口令）
- 账户列表/会话/口令哈希：`MakeHash`/`VerifyHash` 用 CNG `PBKDF2-HMAC-SHA256`（60 万次/16B 盐/32B 派生）。
- 按账户隔离根目录 `CurrentRoot()` → `<exe>/accounts/<name>/`（访客用 `__guest__`）。
- `Init()` 读 `session.json` 直接跳过 `QuickLogin` → **自动登录/补丁必须放 `Init` 而非 `QuickLogin`**（否则成死代码）。

## 2. CheckinStore（全部按账户落盘的 JSON）
数据块（统一 `AccountStore::CurrentRoot()` 前缀）：
`checkin.json` / `focus.json` / `items.json` / `settings.json` / `milestones.json` / `favorites.json` / `history.json` / `journal.json` / `rhythm.json` / `columns.json` / `knowledge.json` / `exam_reports.json`。

- 共享配置 `accounts/cloud-config.json`、`accounts/<name>/cloud-session.json`。
- `SaveSettings` 写 `settings.json`，同时把看板娘凭据另写本地段（覆盖云端回写，防 Key 失效）。
- 手写 UTF-8 JSON（共用 `app/Json.h` 极简解析器）；每次写盘末尾 `Cloud::MarkDirty()` 触发后台静默上推（防抖 2.5s）。

## 3. Cloud（云端对接）
- `Cloud::Init()`：`LoadConfig`→`LoadSession`→`EnsureWorker` 起后台线程→若 `m_enabled` 则置 `m_wantProbe` 且 `m_wantSync=LoggedIn()`。**"打开即自动连云端"语义**：启动即探测并在有令牌时自动同步一次。
- `SyncNow`：先 `PUT /sync/all?mode=merge` 推本地合并集（`BuildPayload(false)`），再 `GET /sync/all` 回拉 `ApplyPayload`。
- 同步块 `kBlocks`：checkin/focus/items/journal/rhythm/columns/milestones/favorites/history/settings（**不含看板娘凭据**）。
- 401 自动重试链（见 `net/Realtime` 鉴权无效 token 下发 `auth:err` → 刷新重连）。

## 4. Updater（HTTPS + SHA256，S0 安全）
- `Updater::CheckAsync`→`GET /version`→`CompareVersion`（`kAppVersion="1.0.0"`）。
- 三道闸：① 仅 `https://` 或回环 `http://`；② 缺 64 位 `sha256` 直接拒下载，下载后**内存内** `VerifyPackage`（长度+MZ头+Sha256Hex/BCrypt）再落盘 `Flori.next.exe`+`pending.json`；③ 交换前重读磁盘再验一次。`ApplyStartupPending` 开机自动交换。

## 5. 网络（net/）
- `Http`：`WinHTTP` 同步，`Response.transport/offline` 区分失败。
- `Realtime`：手写 RFC6455 WebSocket（Winsock+bcrypt）；单后台线程，`On(type,cb)` 注册，回调只写受锁缓冲。

## 6. 给芙洛理的关键提示
- **数据/状态核心留原生侧或服务端**：账户/口令/同步/更新逻辑是 Windows 专属 + 安全敏感，不宜搬进 Godot。
- **Godot 通过 IPC 向原生请求 deck、回传标记**（见 `01_架构设计`），不直接碰网络 IO 或账户。
- **接口契约以 `*.flori.json` schema 为权威**（见 `05_服务端需求/服务端需求清单.md` §0），保证导出导入与同步零摩擦。
- **凭据绝不入库**：看板娘/AI Key 本地文件，云端 payload 不携带。
