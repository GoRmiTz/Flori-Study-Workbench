# 02-F · 专注追踪与考场模式

> 来源：`core/FocusTracker`（F-D1）、`core/ExamMode`（F-D6）、`core/ReviewNudge`+`core/ReviewEngine`（F-D7）。这些是芙洛理"自律"内核，芙洛理应完整继承。

## 1. FocusTracker（F-D1 专注追踪）
- `core/FocusTracker.cpp`：后台线程**每秒**轮询 `GetForegroundWindow` + `QueryFullProcessImageNameW`（进程名）+ `GetLastInputInfo`（idle）。
- `FocusState{process,title,studying,idle,continuousSec,category}`；`FocusCat` 分 Study/Entertainment/Idle/Other。
- `SetUserApps`（#71 仅比进程名）、`SetEntApps` 降权。
- 满 60s 经 `CheckinStore::AddFocus` 落 `focus.json`。
- `Pause/Resume`（F-D3 全局热键）。

## 2. ExamMode（F-D6 考场模式）
- `core/ExamMode.cpp`：`Start(120)` 全屏顶部 HUD（`WS_EX_TOPMOST|TRANSPARENT|NOACTIVATE`，`CreateOverlay/Paint` 画倒计时+中断次数），1s 定时器。
- 复用 `FocusTracker::Snapshot().studying` 做**中断检测**（3s 宽限、`interrupts++`、弹气泡）。
- `Finish` 累计 `effectiveSec` 并 `AddExamReport`。**不锁系统**。

## 3. ReviewNudge + ReviewEngine（F-D7 本地复盘）
- `ReviewNudge.cpp`：默认 **21:00** 托盘气泡，点击 `App::NavigateTo("review")`；`ExamMode::Running()` 不打扰；`reviewNudgeLast` 跨重启去重。
- `ReviewEngine.cpp`：`Generate(dateKey)` 汇总打卡/专注/模考中断/复盘，按 `PlanTargetPct` 求薄弱项；`CommitWeakToJournal` 写"明日三要事"。

## 4. 给芙洛理的关键提示
- **逻辑核心留原生**：前台进程检测、中断检测、HUD 是系统级 Windows 交互，Godot 不直接做。
- **Godot 可做"专注/复盘可视化"**：例如把 `focus.json`/复盘结论用 Godot 2D 做成"墨显式"仪式呈现，回传仍走原生。
- **F-D6 不锁系统**：只 HUD + 中断计数，符合"确定可控"铁律。
- **21:00 nudge** 是"每日陪伴"关键触点，芙洛理应保留并可与看板娘联动。
