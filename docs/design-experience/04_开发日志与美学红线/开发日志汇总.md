## 三、反复踩坑与已固化结论（必记）

1. **WebGL 黑屏**：识渊(22) 真机连续两次全黑（WebGL2+多canvas 降级取 2d 上下文得 null 崩溃）。→ 结论：WebGL2/多canvas 无法被 headless 可靠验证；后续用单 canvas 纯 Canvas2D，WebGL 仅作受控背景（失败即 CSS 纸纹兜底）。
2. **ABI 段错误 139**：改 App 布局头未 `touch main.cpp`。→ 红线固化。
3. **窗口创建 1400**：`WM_NCCREATE` 漏 `m_hwnd=hwnd`。→ 模板固化。
4. **FloatLayer 7.1 bug**：`WS_EX_LAYERED` + `AW_BLEND` 对分层窗是 no-op → 去 LAYERED 用普通 WS_POPUP。
5. **git rm 删光 src/**：改用 `rm -f` + `git add -A`。
6. **云端覆盖 AI Key**：云端 payload 回写空 kanban 段把本地 Key 覆盖 → 用本地独占文件/段覆盖解决。
7. **视线头不转/悬停不浮现**：归一化分母过大 + AW_BLEND 失效，已修。
8. **缩放重影**：`SetDisplaySize` 未同比例重建超采样画布 → 强制重建。

## 四、给芙洛理的继承建议

- **继承**：数据核心（Store/Cloud/AccountStore/Quiz/Review）、零依赖红线、铁律㉘–㉟（注：芙洛理时期已由项目简报放宽，非绝对）、IPC 数据出口。
- **重构**：UI/动效用 Godot（根治 S2-1 重叠）、看板娘渲染用 Godot Sprite2D 重做（更轻）。
- **补缺口**：QuizStore 缺"标已会"掌握度反向衰减通道（IPC 须补齐，否则动效失数据驱动）。
- **规避**：WebGL 黑屏教训 → Godot 天然规避；但 IPC/状态契约须从 M1 起严格定义。
