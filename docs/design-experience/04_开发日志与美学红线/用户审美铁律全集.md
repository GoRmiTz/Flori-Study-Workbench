## 一、核心护栏（动工前参考，非绝对）

### ㉘ 避彩圆俗套 · 线条优先（共学舱被否后立，非绝对）
普通圆形、尤其彩色填充圆易显俗套。**优先**以线条/细结构为骨架，节点**偏好**小几何标记（菱形/方/短刻）而非实心圆；配色**克制为基调**，但**颜色标准可变**——鼓励多元素、个性化表达，"拒绝五颜六色"≠"拒绝色彩"。

### ㉛ 交互必须舒服 · 步距连续无长跳（识卷反馈后立）
凡"翻页/换段/换层/下潜"的视觉，相邻内容位移**必须连续、平滑、可缓动**，禁用离散大跳距。scroll 直接映射为连续位移 + 合理灵敏度 + ease。

### ㉜ 允许游戏化探索 · 深度精细玩法（用户明确放宽）
允许"可玩的 3D 探索"（下潜/转向/操控/追踪路径/空间导航），把可操作性藏进物理直觉；**禁止抽测/计分/赢输/对错的廉价小游戏机制**（活字印知死因），但**要求深度、精细的玩法设计**——玩法须有层次、有反馈、可沉浸，而非浅层装饰。要"可玩的 3D 探索 + 深玩法"，不要"答题闯关"与"空壳动效"。

### ㉝ 浅色纸底为主 · 颜色可变 · 允许适度辉光（2026-08-18 用户明确，已由简报放宽）
新概念**默认浅色纸底**（暖白纸感亮底）为主基调，弃用暗底霓虹；但**颜色标准可变**，并非锁定墨线/墨色主导——可视概念需要灵活取色。配色翻转逻辑（暗底明度=掌握度 → 亮纸墨色浓度=掌握度）仍可作参考之一。✅ **允许适当辉光/bloom**（非一律禁止），辉光须服务于信息层次与情绪，不喧宾夺主。

### ㉞ 交互范式宜丰富 · 轨道观察已允许（2026-08-18 再纠正，已由简报放宽）
前身曾禁止「拖拽轨道旋转 + 滚轮缩放 + 点击飞入聚焦」的观察式范式（防重复）。芙洛理简报**放宽**：轨道观察结构**可用**，不再禁用；同时仍鼓励探索「织/编/折叠/显影/生长/书写」等**制作·生成·转化类**动效以丰富范式库。可保留 3D 体量感，用户既可旋转观察、也可施加真实操作（织线/摇机/温习/展开）。

### ㉟ 拒绝花瓶 · 必须有买点/价值闭环（2026-08-18 核心批评，仍有效）
每个概念不能只是好看的动态展示（花瓶）。必须回答两件事：① **落在软件哪里**——接哪个真实模块/功能（练考题库/复盘系统/错题集）；② **买点/钩子是什么**——为何用户持续交互（抽取惊喜/收集/仪式感/进度可视化/自适应复习），且**每次交互都直接产生学习价值**（获取知识/复习/推进掌握度/入册入集）。核心闭环终点为**数据分析**。可借鉴「抽卡」范式：通过卡片/笺片获取知识 + 富有娱乐性。禁止"动效美但与学习功能脱节"的纯展示型概念。

## 二、早期铁律（仍作参考，摘要）

| 编号 | 铁律 | 要点 |
| --- | --- | --- |
| 1 | 创新第一、非大众化 | 拒 SaaS 蓝白渐变+圆角卡片 |
| 2 | 有意义 + 实用价值优先 | 不能为动效而动效 |
| 3 | 现代感、艺术现代化 | 弃用年轮/树/生长等古老有机形态 |
| 4 | 克制、避免过度廉价辉光 | 圆球辉光 cliché；但㉝已放宽，适当辉光允许 |
| 5 | **信息可视化优先、实用性优先** | 数据须直观可读（坐标轴+刻度+标签+可读几何先于风格层）；交互要能直接获取信息 |
| 6 | 真实操作驱动、确定可控、非游戏 | 动力学须阻尼收敛，不失控乱跑、不 idle 空浮 |
| 7 | 落真实界面 | 看得见加在哪（mock 真实 chrome/tabs） |
| 8 | 图表本体 + 风格层分离；形态优先于特效 | 慎用软圆辉光作主特效 |
| 9 | 先确认母题再动手 | 同母题连否 2 次就换 |
| 10 | 每次总结用户反馈与想法 | 防创意偏离 |
| 11 | 形态美感优先、告别方块堆叠 | 用细线/点阵/连续面/拓扑网 |
| 12 | 配色讲究（和谐、克制、有层次） | 单主色+灰度层次；维度靠明度/大小/位置区分 |
| 13 | 放弃时间轴/时序母题 | 转向空间关系/结构/拓扑/形态映射 |
| 14 | 通过的配方即新基线 | 概念 10 考点星图 |
| 15 | 信息载体须高密度离散 | 拒稀疏采样插值出大而空的场 |
| 16 | 形态边界须自然 | 拒硬长方形截断 |
| 17 | 数据着色豁免 | 仅当颜色系统性编码数据维度时允许多色相（辉光按㉝放宽） |
| 26 | 已认可版本勿堆新风格层 | 连续否定时优先回退上一认可版 |
| 27 | 旋转/惯性必须确定可控 | "拖哪跟哪"+惯性∝真实拖速、封顶、快速收敛 |
| 29 | 突破母题锁定 | 禁在「点-线-环-星」2D 词汇内打转 |

> 概念 12 卡片专项（18–25：抽卡稀有度光晕/去按钮/封面即封面/切角描边/翻转非旋转/棱镜层/图谱常驻/多变换拆独立 DOM 层）——因概念 12 当前定格 v2，这些仅作历史经验，勿在 v2 上叠加。

## 三、概念设计自检清单（开工前参考，非强制逐条过）

- [ ] 是否先确认了母题/方向，而非在错母题上打补丁？
- [ ] 是否突破了「点-线-环-星」母题锁定（29），且提供了真三维交互 + 二维浮层交互？
- [ ] 数据是否「直观可读」？（坐标轴/数值/标签/可读几何？能框选聚合？）
- [ ] 是否有明确意义与实用价值（接真实复习数据）？
- [ ] 是否现代、克制、**避免过度廉价辉光**（㉝ 已放宽，允许适度辉光）？
- [ ] 是否真实操作驱动、确定可控、非廉价小游戏机制、落真实界面？
- [ ] 是否非大众化、有辨识度？
- [ ] 交互是否舒服？步距连续无长跳（㉛）？
- [ ] **是否以浅色纸底为主（㉝，颜色标准可变）？交互范式是否丰富（㉞，轨道观察已允许）？是否有买点/价值闭环（㉟，终点=数据分析）？**
