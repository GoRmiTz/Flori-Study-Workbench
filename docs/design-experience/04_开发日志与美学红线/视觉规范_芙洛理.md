# 04-C · 芙洛理视觉规范（升级版 · 已被项目简报修正）

> 在芙洛理 DOSSIER 母题 + 用户护栏㉘–㉟ 基础上，为芙洛理制定的**可执行视觉规范**。Godot 2D 实现时以此为准（用 ColorRect/Line2D/Theme 落地）。
> ⚠️ **芙洛理项目简报修正声明**：本规范中「墨落于纸/零辉光/墨线主导/禁轨道」等前身口径**已被项目简报放宽**——视觉身份以「浅色纸底 + 多元素 + 独特设计 + 舒适度/游戏互动性」为准，**颜色标准可变**；㉝ 允许**适当辉光/bloom**；㉞ **可用轨道观察结构**。凡冲突以 `<项目简报路径>` 为准。

---

## 1. 设计语言：浅色纸底 + 多元素 + 独特设计（Light Paper + Multi-element）

- **浅色纸底**为**主基调**（落实㉝），弃用暗底霓虹；但**颜色标准可变**，鼓励个性化、多元素表达，不锁死墨线/墨色主导。
- 节点**偏好**小几何标记（菱形/方/短刻）而非实心圆（落实㉘，非绝对）——彩色填充圆易俗套，但仍可按需使用。
- 克制为主基调；**允许适当辉光/bloom**（㉝ 放宽），辉光服务于信息层次与情绪。

## 2. 调色板（Palette · 基准，颜色标准可变）

| 角色 | 取值 | 用途 |
| --- | --- | --- |
| 纸底 paper | `#F6F2E9`（暖白） | 全局背景（基准） |
| 纸高 paperHi | `#FBF9F3` | 卡片/浮层 |
| 纸低 paperLo | `#ECE7DB` | 分隔/凹陷 |
| 墨 ink900 | `#1A1714` | 主文字 |
| 墨 ink700 | `#3A352E` | 次级文字 |
| 墨 ink500 | `#6B6358` | 辅助 |
| 墨 ink300 | `#9A948A` | 禁用/占位 |
| 墨线 rule | `#C9C2B4` | 发丝线/网格 |
| 青绿 jade（基准强调色） | `#268678` | 薄弱描边 / 涟漪 / 按钮 / 进度 |
| 朱砂 seal（可选） | `#B0432E` | 印章/警示，用量极少 |

> **掌握度编码（基准方案，亮纸翻转）**：掌握=浓墨深（ink900）、薄弱=淡墨（ink300）+ 青绿描边。此为基准参考，**颜色标准可变**，可按概念需求取色。
> **辉光**：允许适度 glow/bloom（㉝ 放宽），须克制、服务于层次。

## 3. 字体（Typography）

- 标题/正文：衬线（宋体候选，如 `Songti SC`/`Source Han Serif`）——传承 DOSSIER 档案感。
- 数字/倒计时：等宽（Mono），tabular 对齐。
- 字号阶梯：H1 28 / H2 20 / Body 14 / Caption 12（DIP 逻辑像素，随 DPI 缩放）。

## 4. 形状与间距（Shape）

- 微圆角 `kEdge=4`；网格单元 `kGridUnit=8`；发丝线 `kHair=1`；内容最大宽 `kMaxWidth=1080`。
- 卡片：纸卡底 + 1px 发丝描边 + 底部重线（DOSSIER PaperCard）；**禁未来 HUD 装饰**（四角准星/扫描线/雷达）。

## 5. 动效与交互（Motion）

- **确定可控**（铁律㉜⑥）：弹簧+阻尼收敛；生成式元素仅交互时出现、离开即收；禁失控混沌与 idle 空浮。
- **真实操作驱动**：滚动/悬停/拖拽/点击/缩放 → 动效受控非自跑。
- **步距连续无长跳**（㉛）：所有位移 ease 缓动。
- **交互范式宜丰富**（㉞ 放宽）：既可用「织/编/显影/折叠/生长」等"制作·生成·转化"，**也可用轨道观察结构**（拖拽旋转+滚轮缩放+点击飞入聚焦已允许）。
- **深度精细玩法**（㉜ 强调）：鼓励有层次、有反馈、可沉浸的玩法设计，非浅层装饰。
- 缓动：`OutCubic`（入场）、`InOutCubic`（场景转场）、`OutElastic`（轻弹）；帧率无关 `LerpFactor`。

## 6. 信息可视化优先（铁律⑤）

- 图表本体（坐标轴 + 数值刻度 + 标签 + 可读几何）先于风格层。
- 交互能直接获取信息（框选→实时聚合；悬停→精确单点值）。
- 顶部 KPI 直接给覆盖率/掌握率/进度，不藏数据。

## 7. 买点护栏（铁律㉟，芙洛理核心 · 终点=数据分析）

每个动效/视图上线前必须能回答：
1. **落在软件哪里**？→ 接 QuizParser / ReviewEngine / 错题集 / 每日复习。
2. **买点/钩子**？→ 抽取惊喜 / 收集 / 仪式感 / 进度可视化 / 自适应复习。
3. **每次交互是否产生学习价值**？→ 获取知识 / 复习 / 推进掌握度 / 入册入集。
4. **回传机制**？→ 经 IPC 回传 `mark(known/weak)` → 原生落库（见 `01_架构设计` §3）。
5. **核心闭环终点**？→ **数据分析**（每次交互沉淀为可分析的学习数据）。

## 8. Godot 落地准则

- 用 `ColorRect`（纸底）+ `Line2D`（墨线）+ `Control`/`CanvasItem._draw` 对应 Canvas2D 原语。
- **辉光按㉝放宽**：`WorldEnvironment` 的 glow **允许适度使用**（非一律禁用），须克制。
- 布局用 `VBoxContainer`/`GridContainer` 根治 S2-1 重叠（勿手算锚点）。
- 透明/alpha 自由（Godot 无 CANNOT_DRAW 限制）；浅色纸底 + 多元素 + 独特设计身份须保留。
