# 03-A · 目录结构与关键文件索引

> 来源：`DesktopApp/src/`（153 个 cpp/h，2026-08 实测）。芙洛理原生壳侧可沿用此结构，Godot 动效层独立工程。

## 顶层结构
```
DesktopApp/
├─ CMakeLists.txt            # GLOB 自动纳入 src 下所有 cpp/h
├─ tools/msvcenv.sh          # Git Bash 装配 MSVC（导出 INCLUDE/LIB/PATH + LJ_CMAKE/LJ_NINJA）
├─ assets/                   # shaders/paper.hlsl, media/, kanban/
├─ build/Flori.exe            # 构建产物
└─ src/
   ├─ main.cpp               # WinMain 入口（单实例互斥 + 构造 App）
   ├─ app/                   # 账户/云端/数据/更新
   ├─ core/                  # 应用主体/窗口/专注/复盘/托盘/浮层/截图
   ├─ gfx/                   # 渲染底座 + 纸基着色器
   ├─ ui/                    # 自绘 UI 框架（Canvas/Widget/View/Router/TopBar/Theme/Motion）
   ├─ views/                 # 21 个用户视图
   ├─ kanban/                # 看板娘共享类型（运行时已归档 _attic/，仅留 KanbanTypes.h）
   ├─ quiz/                  # 练考（Parser/Store/Gen/Rss/Scheduler）
   ├─ net/                   # Http / Realtime(WS)
   └─ audio/                 # MusicPlayer
```

## Server 结构
```
Server/  (零框架 Node，不用 npm install)
├─ server.js              入口 0.0.0.0:8787，REST + 同源 WS
├─ src/routes/            auth / sync / columns / media / friends
├─ src/core/              users / sync / columns / friends / auth
├─ src/realtime/          ws.js (RFC6455) / gateway.js (事件网关)
├─ src/util/              fsjson / http
├─ tools/smoke.js         冒烟自检（51 项）
└─ data/                  本地 JSON 存储
```

## 给芙洛理的建议
- **原生壳沿用**：`app/ core/ net/ audio/ quiz/Store/Cloud/AccountStore` 是数据核心，直接复用或微改。
- **Godot 接管**：`ui/ gfx/ views/ 的视觉与动效` 用 Godot 重做；`kanban/` 的看板娘渲染用 Godot Sprite2D 重做（更轻）。
- **保留接口边界**：Store/Cloud/QuizParser/ReviewEngine 的公开方法即 IPC 数据出口。
