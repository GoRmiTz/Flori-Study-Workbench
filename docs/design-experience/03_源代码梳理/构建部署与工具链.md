# 03-B · 构建部署与工具链

> 来源：`协作与交接手册.md` §3–4、`架构速记.md` §8。芙洛理原生壳侧沿用同一工具链；Godot 侧独立用 Godot 编辑器导出。

## 1. 客户端构建（芙洛理原生壳，芙洛理沿用）

### 方式 A · Git Bash（推荐）
```bash
cd "R:/WorkBuddy/Study Plan/DesktopApp"
source tools/msvcenv.sh          # 装配 MSVC 环境
cmake --build build --target Flori # 增量构建，产物 build/Flori.exe
```
首次构建若 `build/` 不存在：
```bash
source tools/msvcenv.sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=RelWithDebInfo
cmake --build build --target Flori
```

### 方式 B · `build.bat`（cmd）
自动定位 VS/CMake/Ninja，可选 `build.bat RelWithDebInfo`。

### 契约回归测试（可选）
```bash
source tools/msvcenv.sh
cmake --build build --target ws_contract_test
./build/ws_contract_test.exe     # 连运行中的 Server，全绿通过
```

> ⚠️ **ABI 陷阱**：改了影响 `sizeof(App)` 的头（App.h/TopBar.h 等 App 直接持有的视图/成员头）→ 必须 `touch src/main.cpp && cmake --build build --target Flori`，否则启动段错误 139。只改 `.cpp` 或不被 App 直接持有布局的头（Store.h/FocusTracker.h/RoomView.h）则无此问题。

## 2. 截图自检（`--shot`）
```
Flori.exe --shot <png> [--route <id>] [--at <秒>] [--dark] [--scroll <px>]
```
- `--route` 直达该路由（immediate，跳过加载动画）；`--at` 达到 m_time 后存盘并退出（退出码 0=成功）。
- 自检块（如 `FLORI_TEST_*`）仅影响自检，生产构建无副作用。

- 跨机：建 `build/accounts/cloud-config.json` `{"host":"...","port":8787,"secure":false,"enabled":true}`。
- 纯单机：直接双击，无云端/社交。

## 5. 芙洛理构建规划（建议）
| 组件 | 构建 | 产物 |
| --- | --- | --- |
| 原生壳（沿用芙洛理 C++） | MSVC/CMake/Ninja（同上） | `flori.exe` |
| Godot 动效子进程 | Godot 编辑器 `Export` 或 `--headless --export-release` | `motion.exe` + `motion.pck` |
| 安装包 | 沿用 `tools/studyplan.iss/.nsi` | 安装器 |

- Godot 导出为**自包含** `motion.exe + motion.pck`，与 `flori.exe` 一起分发为"动效体验包"。
- Godot 二进制**不链接进**主程序（零依赖红线），只是随叫随到的外部二进制。
