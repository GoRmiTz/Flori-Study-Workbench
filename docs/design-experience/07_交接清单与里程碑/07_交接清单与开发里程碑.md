# 07 · 交接清单与开发里程碑

> 给**从零开发芙洛理**的新成员/团队的 checklist + 里程碑建议。基于本包全部内容（00–06）整理。

---

## 一、环境准备（Day 0–1）

- [ ] 装 Windows 10/11 + VS Build Tools（C++ 桌面开发）+ CMake≥3.21 + Ninja + MSVC C++20。
- [ ] 装 Node.js≥18（服务端零依赖，不用 npm install）。
- [ ] 装 **Godot 4.x**（动效/游戏性子体验）。
- [ ] 拉取 `DesktopApp/`（原生壳参考）+ `Server/`（服务端参考）+ 本包 `芙洛理/`。
- [ ] 跑通芙洛理构建：`source tools/msvcenv.sh && cmake --build build --target Flori`，双击 `build/Flori.exe` 验证。
- [ ] 起服务端：`node Server/server.js`，`node Server/tools/smoke.js` 全绿。

## 二、架构对齐（Day 1–2，必读）

- [ ] 读 `README.md` → `00_项目总览` → `01_架构设计`（IPC 分层是核心）。
- [ ] 确认分工：**原生壳（数据/状态核心）** vs **Godot 子进程（动效/游戏性）**。
- [ ] 定义 IPC 协议（以 `01_架构设计` §3 为基线，M1 细化）。
- [ ] 确认视觉规范：`04/视觉规范_芙洛理.md`（亮色纸底+墨线+零辉光）。

## 三、M0 · 原型验证（Godot 动效 spike）

- [ ] 选**一个**买点概念（建议 墨显(29) 或 抽笺(27)）做 Godot standalone。
- [ ] Godot 工程：亮色纸底 ColorRect + Line2D 墨线 + 禁用 glow + 统一主题 `.tres`。
- [ ] 硬编码题库，真机跑手感，验证"显影/抽卡"是否好玩。
- [ ] 对照 `04/用户审美铁律全集.md` ㉘–㉟ 自查。

## 四、M1 · IPC 接通（数据闭环）

- [ ] 原生侧：启动 `motion.exe --exp=<id> --uid=<令牌> --port=7821`。
- [ ] 实现最小 TCP/管道协议：握手 `ready` → 推 `deck` → 收 `result{m},{"t":"result","qid","mark":"known"|"weak"}`。
- [ ] 原生收 `result` → `QuizStore::RecordAttempt` → `ReviewEngine` 重算 → Dashboard KPI。
- [ ] **补缺口**：QuizStore 加"标已会"掌握度反向衰减通道（芙洛理原生缺失）。
- [ ] 写一份 JSON 日志验证闭环（ReviewEngine 能读）。

## 五、M2 · 融合（嵌入与回流）

- [ ] Godot borderless 窗口贴宿主区（或 `SetParent` 嵌入）。
- [ ] 标记真正进 ReviewEngine/错题集，KPI 实时涨。
- [ ] 三视图（Room/Roadmap/Media）"打开即自动连云端"语义沿用 `Cloud::Init`。

## 六、M3 · 扩场景（复用模板）

- [ ] 抽笺、舆图、织缕复用同一 IPC + 场景模板，加进 `motion.exe`。
- [ ] 看板娘：用 Godot Sprite2D 重做（轻、MIT 友好）；AI 对话走 Godot HTTPClient + 本地凭据。
- [ ] 焦点/信息可视化视图（Dash/Advisor/Knowledge）用 Godot 2D 重做，根治 S2-1 重叠。

## 七、M4 · 收尾（部署）

- [ ] Godot 导出自包含 `motion.exe + motion.pck`，与 `flori.exe` 一起分发为"动效体验包"。
- [ ] 安装器沿用 `tools/studyplan.iss/.nsi`。
- [ ] 服务端 §1 Auth + §2 Sync 优先落地（P0），其余 P1–P3 按需。

## 八、必守红线（全程）

- [ ] 数据/状态核心留原生侧或服务端；Godot 只"演+收+回传"。
- [ ] API 凭据本地文件、不入库、不硬编码。
- [ ] 零辉光、克制、信息可视化优先、真实操作驱动、确定可控。
- [ ] 每个动效必须过 ㉟ 买点四问 + ㉞ 换交互范式 + ㉝ 亮色背景。
- [ ] 原生壳零第三方依赖（Godot 作外部子进程，不算依赖）。
- [ ] 概念原型仅作想法，本次不开发。

## 九、风险登记

| 风险 | 对策 |
| --- | --- |
| 两进程焦点/层级跳 | Godot borderless 贴宿主区；必要时 SetParent |
| Godot 冷启动 1–2s | 墨韵加载过渡；或常驻 motion.exe 切场景 |
| 二进制体积 50–100MB | 可选体验包独立分发 |
| 美学漂移 | 统一 Godot 主题 .tres + 禁用 glow + code review |
| IPC 不可靠 | 行分隔 JSON + 超时重连 + 本地缓存重试 |
| WebGL 黑屏（历史教训） | Godot 天然规避；但状态契约须从 M1 严定义 |
