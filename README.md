## 它是什么

一句话：**打卡 → 专注 → 复盘 → 练考 → 数据分析**，一天的学习在同一个窗口里闭环。

- **本地优先**：不登录也能完整使用；服务端可选，只做同步与自习室实时。
- **常驻后台**：托盘最小化、全局热键、到点提醒——它是陪你学习的，不是要你伺候它。
- **原生 C++（D3D11 / D2D / DirectWrite）**：零第三方依赖，安装包小、启动快。
- **信息可视化优先**：动效只为传达信息服务，克制、可读、无装饰性噪音。

### 架构原则

- C++ 壳持有全部业务状态与判分权；表现层只「演 + 收 + 回传」。
- 视觉基线：浅色纸底 `#F6F2E9` + 青绿 `#268678`，衬线标题 / 等宽数字，8px 栅格。

## 功能总览（已实现）

| 模块 | 说明 |
|---|---|
| 打卡 | 每日打卡；自定义打卡项（工作日 / 周末专项）、关键倒计时、标签与排序 |
| 专注 | 自习室（公共 / 邃静 / 冲刺）：番茄钟 + 自由计时、实时在场与公共聊天、专注白名单联动（切走自动暂停）、静默专注覆盖层 |
| 复盘 | 每日复盘（今日小结 + 明日三件事）、历史回顾、到点托盘提醒 |
| 练考 | 每日定时出题（题量 / 时刻 / 类别可配）、RSS 资讯、判分在本地完成 |
| 数据 | 专注热力图、累计统计、成就徽章、连续里程碑、年度回顾、一键导出 |
| 专栏 | 私有专栏（富文本编辑）+ 公共专栏（浏览 / 点赞 / 收藏 / 评论） |
| 知识库 | 文字或 `.md` / `.txt` 文件拖入窗口即收集成卡，支持检索 |
| 数据管理 | 多账户本地存档、访客模式、整账户导出 / 导入备份（含回滚快照） |
| 桌面集成 | 托盘常驻 + 右键菜单、全局热键、单实例、拖拽收集 |
| 云同步（可选） | 零依赖 Node 服务端：账户中心、数据同步、实时自习室、公共专栏 |

## 构建

### 客户端（Windows）

需要 **Visual Studio Build Tools（C++ 桌面开发）+ CMake + Ninja**：

```bat
DesktopApp\build.bat
```

### 服务端（可选）

Node.js ≥ 18，零 npm 依赖：

```bat
Server\启动服务端.bat
```

> 默认监听 `0.0.0.0:8787`；个人使用建议改回 `127.0.0.1`（加固在 Roadmap 中）。
> 客户端不连服务端时，全部本地功能照常可用。
